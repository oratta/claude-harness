# #1853 Codex に共通ルールを配布する

`sync.sh --codex` の明示操作で、公開 rules・許可済み個人 rules と適用範囲付きの harness AGENTS 全文を Codex ホームへ届ける。公開生成物は追跡し、個人版はローカルだけに生成する。readable 要点は既存の communication-style 正本を使い、手書き要約の二重管理を避けた。リンクによる案内だけでは新規セッションへの供給を確認しにくいため、全文生成を採った。

容量の共通最低値は128 KiB。裁定時の本文実測は公開 rules 18,201、個人 rules 3,910、既存ホーム1,054、harness AGENTS 4,126、flatmate CLAUDE 19,471、ponta CLAUDE 26,107 bytes。固定入力は生成見出し込みで73,832 bytesとなる。32 KiBの維持は不足し、無制限の引上げは増大を検知できないため、UTF-8の固定入力・境界・実物検査を併設した。

従来の同期は Codex ホームを変更しない。明示同期は既存 AGENTS の区画外バイト列と、認証・MCP 等の設定を保持する。管理区画破損・override・管理外リンクは拒否し、適用前に対象ファイルを退避して復旧可能にする。worker は配布済み管理区画だけを引き継ぎ、未配布時は同期を案内して起動前に止まる。親AGENTS/configの丸ごとコピーによる一時指示・MCP混入を避ける。

自動メモリは別プロジェクトや住人の記憶を混ぜないため取り込まない。必要な知識は依頼で明示できる。`tests/injection-budget.txt` は変更しない。#1850 の develop 手順移植、genetta-inc/flatmate#2160 の規約生成・配置には手を広げない。

実ホームへの適用と実機の三規則・人格末尾・日本語commit検証は、本体の適用権限確認後の残作業。手順と復旧方法は [Codex 共通指示](../codex-shared-instructions.md) を参照する。
