# README の聖域の案内に、親の判断でも外れないマージ条件のパス（MERGE_CONDITION）を足す（#1057）

`README.md` の auto-merge 配線の案内を、金・DB・法務のパスを `SACRED` と `MERGE_CONDITION` の両方に足す形に直した。親の判断の印があると、`SACRED` にだけ足したパスの PR は `human-merge` が外れて自動マージされうる（#1030）。必ず人間がマージするパスにしたい場合は `MERGE_CONDITION` にも足す。

- 「常に人間がマージするパス」の言い回しを削除した
- must-match リストの案内を、`SACRED` 用と `MERGE_CONDITION` 用の 2 つに触れる形にした
