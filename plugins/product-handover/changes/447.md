# 版番号を撤去し、変更の記録を PR ごとの別ファイルにする（#447）

`plugin.json` と `.claude-plugin/marketplace.json` から `version` を撤去した。版は Claude Code がマーケットプレイス clone の HEAD の commit SHA から決めるので、マージのたびに利用者へ更新が届く。

- 変更の記録は `plugins/product-handover/changes/<番号>.md`（記録先の issue 番号、無ければ PR 番号）に 1 PR 1 ファイルで書く。`CHANGELOG.md` は凍結し、追記しない
- `tests/plugin-structure.bats` は `plugin.json` に `version` が無いことを確かめる形に変えた
