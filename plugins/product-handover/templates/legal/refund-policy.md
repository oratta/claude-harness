# 返金ポリシー（ドラフト）

> **この文書は LLM が生成したドラフトであり、法務・専門家のレビュー前である。**
> 金銭に直接触れるため、公開前のレビューは他の2文書より優先度が高い。

## 使い方

課金のないプロダクトでは本文書ごと不要。課金があるなら、下の「決めること」を先に埋めてから
条文を書く。埋めた結果は利用規約の返金条と食い違わないようにし、**条件の正本は本文書に置く**。

## 決めること（先に埋める）

| 項目 | 値 | 備考 |
|---|---|---|
| 課金モデル | | サブスク / 買い切り / 従量 |
| 解約時の扱い | | 契約期間満了まで利用可 / 即時失効 |
| 途中解約の日割り返金 | | あり / なし |
| 補償の手段と順序 | | 例: サービス内クレジット → 翌月無料 → 現金返金 |
| 現金返金の上限 | | 例: 当月支払い分まで |
| クーリングオフの扱い | | 通信販売には法定のクーリングオフが無い点を踏まえて決める |

## 設計上の注意

**「いかなる時も返金しない」は採用しない。** 消費者契約法8条により事業者の責任を全部免除する
条項は無効となるリスクがあり、無効になれば返金の上限すら主張できなくなる。段階的な補償を
定めて上限を置く形にする。

**サービス内クレジットを配るなら資金決済法を確認する。** 有効期限・払戻しの可否・発行残高に
よっては前払式支払手段の規制対象になる。有効期限を6か月以内にする等の設計で対象外に
できる場合があるので、配り方を決める前に確認する。
