# AI自動運営の教訓ログ

> このプロジェクトは「開発エージェント + マーケティングエージェントが有料プロダクトを自動運営する仕組み」の実践場である。この文書は、その試行錯誤で「何が重要だったか」を後から振り返れるように記録する教訓ログ。**大きな設計判断・実弾で発見したバグ・人間ゲートの発火実績が出るたびに、日付つきで追記する PR を出す。**

## 記録の様式

- 1教訓 = 見出し1つ。「何が起きたか → 何が本質か → どう改善したか」の3点で書く
- 根拠となる PR / issue / run へのリンクを必ず添える
- 確定していない論点は「検討中」と明記する
