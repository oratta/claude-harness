# accounts.json で enabled が false のアカウントを off の 1 行で描く（#976）

`accounts.json` の各スロットに `enabled`（真偽値、省略時はオン）が足された（定義と、自動選択・使用量の取得での扱いは `plugins/dev-workflow/changes/976.md`）。ステータスラインは登録簿を自前で読んでいるので、同じ意味で読むようにした。

- `scripts/statusline.sh`: `enabled` が JSON の `false` のスロット（オフ）のうち、いま使っていないものは、レートリミットの行の代わりに `  B  off` の 1 行を出す（label も `off` も DIM）。snapshot やセッション記録に値が残っていても描かず、値が 1 つも無くても行は出す。行の位置は宣言順のまま
- オフのスロットも label 列の幅と「スロットが複数かどうか」の判定に数える。セッション記録との突き合わせには載せない
- いま使っているスロットがオフのとき（`CLAUDE_SECURESTORAGE_CONFIG_DIR` を手で設定してオフのアカウントで起動したセッション）は、`off` を出さずライブ値で描く。1 スロットだけの登録簿は、そのスロットがオフでも出力は変わらない
- `enabled` を書いていない登録簿、および `false` 以外の値（`true`・`"false"`・`0`・`null`）を書いた登録簿では、出力は 1 バイトも変わらない
- `README.md` のフィールド表に `enabled` を足し、「使っていないアカウントをオフにする」の節を足した
- 戻し方: 利用者側は `enabled` の行を消す。コードはこの PR の差分を戻す
