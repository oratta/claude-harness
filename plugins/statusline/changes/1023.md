# 「codex off」のテストを、オフ判定を消すと落ちる条件にする（#1023）

#978 で足した statusline.bats の「codex off: the Codex row is the label followed by off only」は、auth.json を置いていなかったため、オフ判定を消しても `identity()` が None で止まり、キャッシュとスタブの未作成の検査が落ちなかった。実行時の振る舞いは変えていない（テストだけの変更）。

- `plugins/statusline/tests/statusline.bats`: `codex_with_login` を足し、このテストで auth.json（`tokens` あり）を置く。取得は `main()` が切り離した背景の子プロセスで走り、描画の終了後に完了するため、検査の前に `statusline-codex.py --refresh` を同期で走らせる。オフ判定を外すとここで `.statusline-codex` が作られて落ちる（スタブは `echo` の前に打ち切られるので `codex-calls` は当てにしない）
- 他の「codex off」のテストは auth.json を置かないまま（オンのときに Codex 行が出てしまい、出力比較が成り立たなくなるため）
- 戻し方: この PR の差分を戻す
