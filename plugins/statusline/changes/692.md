# 692: 本体のセッションコストをセッションごとに書き残す

`statusline.sh` が、描画のたびに Claude Code 本体から渡されるセッションコスト（`cost.total_cost_usd`）を `${CLAUDE_CONFIG_DIR:-~/.claude}/.session-cost/<セッション ID>` に書き残すようにした。1 セッション 1 ファイル・1 行で、最初の観測と、最後に値が変わった観測の時刻と値を持つ。cost-ledger プラグインがこの記録を読み、自前の単価表で計算した額と比べて単価表のずれを `/cost` で知らせる。

- 表示（標準出力）は変えていない。`STATUSLINE_SESSION_COST=0` で表示を消していても記録は書く
- 値が前回と同じ描画では外部コマンドを起動せず、ファイルにも触らない。値が変わった描画だけ一時ファイルと `mv` で書き換える
- 400 日より古い記録は、新しい記録ファイルを作る描画で消す
- 書けない・読めない・`session_id` がファイル名に使えない形、のどれでも標準出力・標準エラー・終了コードは変わらない
- 仕様: `openspec/specs/session-cost-record/spec.md`（新規）
- テスト: `plugins/statusline/tests/statusline-session-cost-record.bats`（14 件）
- 注意: 記録はコピー先の `~/.claude/statusline.sh` が書くので、プラグインを更新したあと `/statusline:setup` を再実行するまで始まらない
