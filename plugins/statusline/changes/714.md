# 714: 2 行目にプロンプトキャッシュのヒット率を出す

`statusline.sh` の 2 行目、`Context` の直後に `Cache 82%` の区画を足した。Claude Code 本体が stdin に渡す `prompt_cache.hit_ratio`（0〜1）を四捨五入した百分率で、セッション累計の値。直近のミスの原因（`prompt_cache.last_miss_cause.causes` の先頭）があれば `Cache 82% miss:tools` のように短い名前で添える（`tools`・`system`・`ttl5m`・`server`。複数あれば `+1` で残りの件数）。

- `prompt_cache` を渡さない版、`hit_ratio` が `null`・範囲外・数値でない入力では区画を出さず、標準出力は従来と 1 バイトも変わらない
- `STATUSLINE_PROMPT_CACHE=0` で消せる（既定は表示）
- 入力は stdin の JSON だけを見る。ファイルにもネットワークにも触らず、型が想定外でも終了コードと標準エラーは変わらない
- 仕様: `openspec/changes/statusline-prompt-cache-segment/specs/`（archive 後は `openspec/specs/` 側）
- テスト: `plugins/statusline/tests/statusline-prompt-cache.bats`（19 件）
- 注意: 動いているのはコピー先の `~/.claude/statusline.sh` なので、プラグインを更新したあと `/statusline:setup` を再実行するまで表示されない
