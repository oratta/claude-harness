# writer G のテストが秒の切れ目で落ちるのを直す（#641）

- `tests/statusline-rate-snapshot.bats` の payload の `resets_at` を `NOW+9000` / `NOW+302400` から 30 秒ずらした。ちょうど分の切れ目だと、NOW と同じ秒に描いた行は「~2h 30m」、次の秒に描いた行は「~2h 29m」になり、2 回描いて比べる writer G が秒をまたいだ回だけ落ちていた
- statusline 本体と表示は変更なし。テストは HOME・CLAUDE_CONFIG_DIR・共有先設定をすべて一時ディレクトリに向けており、実在の共有ディレクトリは触っていない
