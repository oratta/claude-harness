# Claude のアカウントの行にリセット権の残数と最短期限を出す（#1115）

snapshot の `accounts.<id>.reset_grants`（`plugins/dev-workflow/changes/1115.md` で足した欄）を読み、各 Claude アカウントの最後の行（7d の行、無ければ 5h の行）の末尾に `│  リセット2回・最短あと3日21h` を足す。

- 色: 期限まで 3 日以内は黄、24 時間以内は赤
