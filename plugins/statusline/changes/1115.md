# Claude のアカウントの行にリセット権の残数と最短期限を出す（#1115）

snapshot の `accounts.<id>.reset_grants`（`plugins/dev-workflow/changes/1115.md` で足した欄）を読み、各 Claude アカウントの最後の行（7d の行、無ければ 5h の行）の末尾に `│  リセット2回・最短あと3日21h` を足す。

- `scripts/statusline.sh`: Codex 行の残数・期限の整形を関数 `fmt_reset_credits` に切り出し、Claude の行と共用した。Codex 行の出力は変えていない（変更前のスクリプトとの出力比較をテストにした）。snapshot を読む jq に 2 列（有効な束の残数の和、最短期限の epoch）を足し、`render_slot` に引数を 2 つ足した
- 数えない束: `paused` が真偽値の `true`、`resets_left` が 0。欄が無い・配列でない・束がすべて読めないときは区画を出さず、出力は 1 バイトも変わらない。空配列は `リセット0回`
- 色: 期限まで 3 日以内は黄、24 時間以内は赤
- 新しいテストは `tests/statusline-reset-grants.bats`。`README.md` の「リセット権の有効期限」を Codex と Claude の両方の説明にした
- 戻し方: この PR の差分を戻す
- PR のゲートの指摘で直したこと: 束はあるが数えられる束が 1 つも無い配列（`paused: true` の束だけ・残数 0 の束だけ・その両方）は、`リセット0回` ではなく区画を出さないようにした（仕様「数えられる束が 1 つも無ければ区画を出さない」に合わせた。元から空の配列は従来どおり `リセット0回`）。`ends_at` は `Z` に加えて `+00:00`・`+09:00` などの時差付きの ISO 8601 も読むようにした（同じ瞬間なら同じ表示と色になる）。null・読めない文字列は従来どおり `期限不明`
