# 共有先の環境変数に中立の名前を足し、旧名を互換で読む（#1168）

公開版から flatmate の名前を外すため、枠の共有先の名前を変えた。

- 共有先は `CLAUDE_RATE_SHARE_DIR` → 旧名 `FLATMATE_RATE_SHARE_DIR` → `CLAUDE_RATE_SHARE_CONF`（既定 `$HOME/.claude/rate-share`）→ 旧名 `FLATMATE_RATE_SHARE_CONF`（既定 `$HOME/.claude/flatmate-rate-share`）の順で最初に定まったものを使う。旧名は互換で、設定が残っていれば今までどおり効く
- 空文字・空白だけの定義で共有を無効にする規則は、新名・旧名とも同じ
- 連携先の reader が旧名だけを読む間に新名だけへ移すと reader が追従できないので、新旧を同じ共有先に揃える（README に移行の手順を書いた）
- `README.md:6`: 表示例の workspace のパスとアカウント名を `example` に直した
