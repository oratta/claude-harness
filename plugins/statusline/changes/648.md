# `rate_limits` の無い描画では、セッションの前回値のハッシュを取らない（#648）

セッション記録の前回値のファイル名を決めるハッシュ（`shasum -a 256`、無ければ `sha256sum`、続けて `cut`）を、`session_id` があれば `rate_limits.five_hour.used_percentage` の無い描画でも取っていた。その描画は記録を書かないので、結果はどこにも使われない。

- `scripts/statusline.sh`: ハッシュを取る条件に「5 時間枠の使用率がある」を足した。`rate_limits` のある描画の出力・記録・前回値のファイルは変わらない
- `tests/statusline-session-records.bats`: `shasum` と `sha256sum` を呼び出しを記録するスタブに差し替え、`rate_limits` が無く `session_id` がある描画でどちらも起動されないことと、`rate_limits` がある描画では今までどおり起動されることを見るテストを足した

規範（`openspec/specs/usage-session-records`）の変更と版の更新は無い。
