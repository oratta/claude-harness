# rate snapshot writer を statusline に移す（#517）

flatmate の未配線 writer が持っていた rate snapshot の保存契約を、実際に描画される harness の statusline に移した。

- 既定アカウントの 5h 枠と空でない `session_id` があるとき、観測時刻・書込時刻・出所・任意の `account_id` を含む JSON を原子的に保存する。同じ枠値と出所の再表示では観測時刻を維持する
- `FLATMATE_RATE_SHARE_DIR` または `FLATMATE_RATE_SHARE_CONF` で共有先を設定すると、ホスト別ファイルにローカルと同じ本文を書き、共有先の失敗は描画とローカル保存に影響させない
- flatmate の writer A〜I と integration の writer ケースを隔離された bats / pytest に移し、既存の snapshot fixture を新形式に更新した。表示行は変更しない
