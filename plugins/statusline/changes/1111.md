# ステータスラインのアカウント名を Claude A / Claude B / Codex A に揃える（#1111）

左端の名前が「どのサービスの・どのアカウントか」で揃うようにした。親のエピックは genetta-inc/flatmate#1656（ダッシュボード側の同じ名前への変更は別 issue）。

- `scripts/statusline.sh`: Claude のスロットの名前を `Claude <登録簿の label>` にした。アカウント名の部分だけを表示幅 8 で切り、`Claude ` は切らない。名前の最大幅は 7 + 8 = 15 桁で、名前の列の幅は表示される名前の最大幅で揃う
- Codex の行の名前を `Codex <label>` にした。`<label>` は `accounts.json` のトップレベル `codex.label`（空でない文字列で制御文字を含まないもの。表示幅 8 に切る。無い・不正なら `A`）。登録簿を読む既存の Python 片が `@codex` を先頭に置いた専用の行で渡し、スロットには数えない。`schema` は `1` のまま
- 影響を受ける表示: Codex がオフのときの行は `  Codex A  off` になる（行の有無と `off` の文言は変えていない）
- 変えていないもの: スロットが 1 つ以下で Codex の行が無いときの出力（バイト単位で同一）、Codex の行の有無・取得・オフの扱い（#1112 の範囲）、リセット権（#1115 の範囲）
- テスト: 複数スロットの出力を旧版と比べるテストは、前置された `Claude ` を除いて比べる形にした。スロット 1 つ以下の退行ガードは無改変で通る
- 戻し方: この PR の差分を戻す。登録簿の形は変えていない（`codex.label` は古い読み手が読み飛ばす未知のキー）ので移行は要らない
