# 706: daily-report の集計役 2 つから、無視される `permissionMode: bypassPermissions` を外す

`voice-compactor` と `llm-log-compactor` の frontmatter にあった `permissionMode: bypassPermissions` を削除した。プラグイン同梱のサブエージェントでは `permissionMode` が無視され、親セッションの permission mode を引き継いで動くため、書かれていた強い権限は効いておらず、読む人に「bypass で動く」と誤解させていた。

- `agents/voice-compactor.md` と `agents/llm-log-compactor.md` から 1 行ずつ削除（`model:` などほかの行は変えていない）
- テスト: `voice-compactor.bats` の frontmatter 検査を「`permissionMode` が無い」ことの検査に反転し、`llm-log-compactor.bats` に同じ検査を 1 件足した
- 実行時の権限は変わらない（元から親セッションのものを引き継いでいた）。README の `permissions.allow` の例は、実行で確認画面が出なかったため足していない
- 戻し方: 削除した 1 行を 2 ファイルに戻し、テストを元の検査に戻す
