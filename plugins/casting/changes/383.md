# casting-check: 閉じフェンス末尾判定をロケール非依存にする（#383）

- `plugins/casting/scripts/casting-check.sh` の `strip_html_comments`: 閉じフェンス行の末尾判定を `[[:blank:]]*` から、スペースとタブを明示した `$'[ \t]*'`（変数 `fence_trail_re`）に変えた。`[[:blank:]]` はロケール依存の文字クラスで、ロケール次第で全角スペース等を含みうるため、CommonMark の「スペースとタブのみ」からずれる可能性があった
- 実測: macOS（bash 3.2）の C / en_US.UTF-8 / ja_JP.UTF-8 では全角スペース・NBSP・CR・FF は `[[:blank:]]` に一致せず、依存は再現しなかった。Linux（glibc）は未検証。再現の有無にかかわらず、書き換えは挙動を変えない（スペースとタブのみ）ので予防として入れる
- version は上げない
