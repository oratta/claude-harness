# casting-check: 末尾改行ガードを固定するテストを足す（#306）

- `plugins/casting/tests/casting-check.bats` に 2 件足した。既存の 2 件（#186）は、前処理 `stripped_copy` が出力を必ず改行で終わらせるため、read ループの `|| [ -n "$line" ]` を外しても pass していた
  - `strip_html_comments` の関数定義だけを取り出し、末尾改行の無い入力を直接食わせて最終行が残ることを確かめる（196 行のガード）
  - `stripped_copy` だけを「末尾改行を削る」版に差し替えたスクリプトの複製で、経路が最終行の台帳を検査する（判例ブロック分割ループ 662 行のガード）
- 実測: 2 つのガードを別々に外した複製で、対応する新規テストがそれぞれ `not ok` になる。スクリプト本体は変えていない
- 戻し方: 追加した 2 件のテストと `extract_fn` を消す
