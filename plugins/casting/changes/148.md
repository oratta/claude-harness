# casting-check の起案シグナルを終了コードから外す（#148）

`casting-check.sh`（check モード）の検出8項目を「欠陥」と「起案シグナル」に分け、終了コードの意味を変えた。

- 起案シグナル: 「カタログ外」判例（`catalog-external-precedent`）と、同一観点の「論点じゃなかった」2件以上（`repeated-not-issue`）
- 欠陥: それ以外の6項目（`malformed-row` / `unclosed-comment` / `unclosed-fence` / `unknown-vocab` / `version-mismatch` / `consultation-missing-element`）
- 既定: 欠陥があれば exit 1。欠陥が無く起案シグナルだけなら、一覧は出したうえで exit 0（従来は exit 1）
- `--strict`（新設・check 専用）: 欠陥が無く起案シグナルだけなら exit 4。resolve に付けると exit 2
- 欠陥の判定は「シグナル2カテゴリ以外の報告が1行でもあるか」。新しい検出カテゴリは既定で止める側に入る

理由: flatmate の burn 論点ゲートは `casting-check.sh <repoルート>` の exit 0 を必須にしており、判例を正しく積んで起案シグナルが出ただけで、その repo の burn 候補が全件スキップされていた。resolve は既に「起案シグナルで止めない」と決めており（#136）、check もそれに揃えた。flatmate 側の呼び出しは変えずに済む。

緩むもの: 起案シグナルに強制力が無くなる（exit 0 のまま一覧に出るだけ）。止めたい呼び出し側は `--strict` を付ける。

version は上げない。
