# 返信前チェックの言い換えと、レビュー依頼リンクの裸 URL 既定化（#505）

`rules/perspective-casting.md`・`plugins/casting/skills/casting/SKILL.md`・`plugins/casting/README.md` の3箇所にあった「過剰エスカレーション（下限違反）は過小と同格以上のプロセス違反（として扱う）」という言い回しを、「過剰エスカレーション（下限違反）は、上げ漏れと同じかそれ以上に主の時間を奪う」に統一した。

- 「下限違反」はカタログで使う用語なので残す
- 3ファイルとも同じ文言なので、揃えて直す（正本は SKILL.md、rules/ はその短い版）
- `rules/perspective-casting.md` の『必ず』を削除した。5 手順を通す指示は維持する（正本 SKILL.md は『必ず通す』のまま）
- version は上げない

`rules/link-when-requesting-review.md` は、リンクの既定を Markdown リンクから裸 URL（説明行の次の行に 1 行 1 本で置く）に変更した。理由は、主の表示環境では Markdown リンクがリンクテキストだけ表示されて URL が隠れるため。括弧・鉤括弧で囲まない／直後に句読点を続けない、という既存の注意はそのまま残した。rules/ はどのプラグインにも属さないため、この変更の記録先は決まっていなかったが、同じ PR #505 の記録先である本ファイルに一本化した（`docs/worktree-recovery.md` が定める「1 PR 1 ファイル」の規約に合わせる）。
