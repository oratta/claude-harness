# /casting:init が、自分と同じ版の雛形を読む（#793）

コマンド本文の Bash 実行には環境変数 `CLAUDE_PLUGIN_ROOT` が渡らない。探索ループの先頭候補 `"${CLAUDE_PLUGIN_ROOT:+${CLAUDE_PLUGIN_ROOT}/...}"` は、Claude Code が本文の読み込み時に内側だけを絶対パスへ置換し、外側の `:+` が残るため、実行時に空になって marketplace の自動更新コピー（版の違う旧コピー）が選ばれていた。

- `commands/init.md` の先頭候補を、#774（cost.md）と同じ `"${CLAUDE_PLUGIN_ROOT}/..."` に直した。置換されない環境では変数が空になり、ルート直下の `/skills/...` などを指す。そこに同名ファイルがあれば誤って選ぶため、この点は #808 で直した（空のときは先頭候補を検査しない）
- 検査は dev-workflow の 793.md に書いた共通テスト（`tests/command-plugin-root.bats`）が持つ
- 戻し方: 該当行を `:+` の形に戻す
