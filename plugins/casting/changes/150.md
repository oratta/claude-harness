# casting-check: エスケープされたパイプ `\|` と、複数行コメントの閉じ行に同居する閉じたコメントを正しく扱う（#150）

issue #150 の 3 件のうち、1 件目（同一行で閉じたコメントが以降を飲み込む）と 2 件目（本文の `-->` の誤検出）は PR #145 の `strip_html_comments` で既に塞がっていた。この変更は残りを直す。

- `plugins/casting/scripts/casting-check.sh`: エスケープされたパイプ `\|` を列区切りとして数えない。`pipe_count` と `table_rows` / `check_malformed_rows` の列切り出しの前に `\|` を制御文字へ畳み、出力時に `\|` へ戻す。正当な 5 列の行が `malformed-row` になる・担い手が別のセルにずれる、の両方が消える。エスケープ無しの余分な `|` は従来どおり `malformed-row` で、メッセージに `\|` でエスケープする旨を足した
- 同ファイル `strip_html_comments`: 複数行コメントを閉じた行に閉じたコメントがもう 1 つ同居する形（`途中 --> <!-- b --> 続き`）を閉じ忘れと誤判定して止まっていたのを直した。コメント中ブランチとコメント外ブランチが同じ `comment_tail_open` を使う
- `openspec/specs/casting-project-files/spec.md`: ⓪ の Requirement に上の 2 点を足し、Scenario を 2 つ追加し、守備範囲（出どころ・拾う誤り・通す入力・守らないもの・塞ぎ切りを完了条件にしない）の段落を足した
- `plugins/casting/tests/casting-check.bats`: 修正前なら落ちる退行テストを 4 件追加（修正前の実測で 3 件が落ち、閉じ忘れが残る側の 1 件は修正前後とも通る対の検査）
- version は上げない
