# State 規約（state-convention）

プロアクティブ/長期ループは、セッションをまたいで進捗を引き継ぐために **State ファイル**を使う。

## 設計原則

> **エージェントは忘れるが、リポジトリは記憶する。**

セッションのコンテキストは揮発する。したがってセッションをまたぐ記憶（現在地・前回の試行と結果・人間への引き継ぎ・
繰り越し）は、エージェントの記憶ではなく**ファイルに永続化する**。次サイクルはこのファイルを読んで前回の続きから再開する。
これは harnesses 論文の progress notes、および公式プロアクティブ合成例（翌日 state から再開）と整合する。

## 配置と形式

State ファイルは利用側リポジトリの `loops/state/<name>.state.md` に置く（`<name>` はループ/レシピ名に対応）。
以下の **4 節**を必須構成とする:

### 1. 現在の作業

いま何に取り組んでいるか。中断した場合に「どこまでやったか」が分かる粒度で書く。

### 2. 前回の試行と結果

直近サイクルで何を試し、どうなったか（成功 / 失敗 / evidence）。同一タスクの連続失敗回数もここで追跡し、
2 連続失敗は凍結してエスカレーションする判断材料にする。

### 3. 人間への引き継ぎ待ち

エージェントが判断できず人間の決定を待っている項目（マージ可否・不可逆操作・方針判断など）。

### 4. 繰り越しタスク

discovery で拾ったが今サイクルで処理しなかったタスク。**silent drop（黙って捨てる）は禁止**。
拾ったものは必ずここに繰り越しとして記録し、次サイクルの候補に残す。

## テンプレート

雛形は `templates/state-template.md` を参照。新しい State ファイルはこれをコピーして作る。
