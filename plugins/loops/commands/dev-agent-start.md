loop-dev-agent レシピ（`${CLAUDE_PLUGIN_ROOT}/recipes/loop-dev-agent.md`）の正規起動コマンドを、
コピペなしで起動するランチャー。**実行系はネイティブプリミティブ `/loop` のみ**であり、
このコマンドは /loop に渡す文字列の組み立てと事前チェックだけを行う
（常駐スクリプト・ラッパー CLI ではない。レシピの「独自 CLI やラッパースクリプトは作らない」に抵触しない）。

## 引数

```
/loops:dev-agent-start [間隔]
```

- **間隔**（省略可、デフォルト `1h`）: `/loop` の実行間隔。例 `2h`、`90m`
- レシピの頻度最小化ルールにより **30 分より短い間隔は拒否する**（`30m` 未満が指定されたら
  起動せず「30m 以上を指定してください（デフォルト 1h 推奨）」と案内して終了する）

## Step 1: 事前チェック

1. **憲法ファイルの存在確認**: cwd の git root 直下に `docs/agent-loop.md` があるか確認する。
   無ければ起動せず「`/loops:dev-agent-install` で導入してから再実行してください」と案内して終了する。
2. **権限モードの確認**: 現在の権限モードが `acceptEdits` 未満なら、無人サイクルが権限プロンプトで
   止まる旨を警告する（Shift+Tab で切り替えを案内。警告のみで起動は続行してよい）。
3. **レートスナップショットの確認**: `~/.claude/.rate-limit-snapshot` が無ければ
   「レートガードが効かない状態で起動します（statusline が snapshot を書く設定になっているか確認を推奨）」と
   1 行警告する（起動は続行してよい）。

## Step 2: /loop の起動

Skill ツールで `loop` スキルを起動する。`args` は以下の 1 行（`<間隔>` を引数の値で置換。
プロンプト部分は一字一句このままにする — レシピの正規起動コマンドと同一文字列であること）:

```
<間隔> docs/agent-loop.md を読み、そこに定義された1サイクルを厳密に実行して。結果（実行モード、対象の issue/PR 番号、スキップ・提案の場合はその理由）を必ず報告して
```

## Step 3: 起動報告

以下を 1 行ずつ報告して終了する:

1. 起動した間隔と対象リポジトリ（git root）
2. 停止方法: `/loop` のキャンセル操作で止まること、7 日で自然失効すること
3. 人間側の日常運用は「`agent-proposed` のトリアージ」「`agent-review:passed` のマージ」の 2 点だけであること

## してはならないこと

- プロンプト文字列を言い換えない・要約しない（憲法ファイル駆動の 1 行に固定。変えると
  レシピ・install スキルの正規コマンドと挙動が分岐する）
- /loop を経由せずこのセッションで直接サイクルを実行しない（このコマンドはランチャーであり実行系ではない）
- 事前チェックの失敗を握りつぶして起動しない
