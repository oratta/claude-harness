# 子のターン状態フックを対象セッションに限定

同じ worktree で別セッションや `claude -p` を動かしても、本来の子の `turn_input`・`turn_state`・更新時刻を上書きしない。対象外 Stop は状態行を求めず、既存の番号・URL 検査の結果を返す。対象外の識別は詳細検査・ログ読取・ロック待ちより先に行い、入力のロック内でも再確認する。

初回登録と別 ID への切替は、記録の子・親・エピックのリポジトリと一致する既存 launcher の起動指示に限る。初回は世代1、切替は旧世代+1。同 ID の通常入力と Stop は従来どおり扱う。

未登録の旧記録や誤った ID が保存された記録には、本来の子のセッションへ一致する `/develop #<子> （エピック #<親> の子。…）` を送り直す。任意入力や Stop では登録しない。起動形は認証ではなく、別セッションへの意図的な一致起動指示も切替として受理する。

schema=1・親の読取項目・launcher の API・フック配線・版は変更しない。戻す場合はこの実装と後続の仕様反映を revert する。記録の手動移行や任意拡張の削除は不要だが、別セッションの誤更新も戻る。
