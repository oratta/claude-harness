# エピックの親が主に出す発言の 1 行目を「主がすること」にする（#1089）

2026-10-18、エピック #1038 の親セッションで、主から「各やり取りで具体的にこっちが何をすればいいかがわからない」と言われた。子の完了報告には 1 行目 `主がこのセッションで次にすること:` があるが、親の発言には無く、操作が経緯に埋もれていた。返事の場所（親のタブ）を主が聞き返し、親経由のリスク許容の確認が `not-direct` になって報告を出し直した。

- develop の SKILL.md「エピックの扱い」→「回し方」の Orca 経路の導入部に、親がターンを終えるときに主に出す発言すべて（手順 2 の待ちに入る通知、手順 4 の見送り、手順 5 の `timeout`、手順 6 の `error`・`failed`、手順 8 の止まった子の報告）の 1 行目を `主がすること: なし` か `主がすること: <どの画面・入力欄で> <何を打つ・押す>` にする規定を足した。手順 2〜6 はこれを参照する
- 手順 8 に、親経由のリスク許容の依頼の 1 行目は `主がすること: 親のタブで ... を、この報告の直後に別の発言を挟まずに打つ`、`--locate` で主の発言を引けなかったときの連絡は子のタブ、`reply` の `failed` の報告も `主がすること:` で始める、と足した
- 子の完了報告の `主がこのセッションで次にすること:` は変えていない（子のタブを開いた主向け）。親の発言は `主がすること:` で書き分ける
- `plugins/dev-workflow/tests/epic-dispatch.bats` に、導入部の規定と手順 2〜6・8 の文面を確かめるテストを足した
- 常時注入の対象（rules・CLAUDE.md・output-styles・description）は動かしていないので `tests/injection-budget.txt` は変えない
