# dev-workflow: エピックの子のアイドル時のコンパクトを切り、60 分以上止まった子は起動し直す（#1323）

エピックの子（別セッション方式の子セッション）が、待っている間の自動コンパクト（アイドル時のコンパクト）のあと develop の `SKILL.md` の中身を持たないまま、要約だけを頼りにゲートの実行まで進んでいた（2026-10-23 の issue-1244 の子のログ）。子ではアイドル時のコンパクトを切り、60 分以上止まった子には返事をそのまま送らず起動し直す。

- `epic-dispatch.sh launch`（と、端末が無い子・`--relaunch` の子を起動し直す `reply`）が作る子の起動コマンドを `EPIC_DISPATCH_PARENT_EPIC=<epic> <cmd> --settings '{"idleCompaction":false}' --model '<model>'` にした。`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS=<値>` の前置きは付けない。`--settings` はそのプロセスだけに効き、通常の自動コンパクト（会話が上限に近づいたときのもの）は止めない
- `wait --resolve` が通す返事は、子の最後のリクエストから 60 分（`EPIC_DISPATCH_RELAUNCH_IDLE_SEC`）以上なら、`compact_boundary` の有無と会話量によらず起動し直す。トランスクリプトが無い・2 本以上・時刻を読めないときは、今までどおりそのまま送る
- 環境変数 `EPIC_DISPATCH_IDLE_COMPACT_MIN_TOKENS` と `EPIC_DISPATCH_RELAUNCH_MIN_TOKENS` を消した。設定されていても値を検査せず無視する（誤った値でも exit 1 にならない）。設定している呼び出し元は外してよい
- `references/reply-after-idle.md` を、子の表（端末が無い → 起動し直す／60 分未満 → そのまま送る／60 分以上 → 起動し直す）と親の表（今までの 4 行。閾値 120,000 のまま）に分けた。親を残すのは、親の監視の `wait` はコンパクトのあとも動き続け、起動し直すと監視が途切れるため
- `SKILL.md` ではなく `references/epic.md` の子の起動コマンドの記述を直した。子の起動コマンドの形と「`epic-dispatch.sh` が足すもの」の記述は #1219 で `SKILL.md` から `references/epic.md` へ移っていて、`SKILL.md` には残っていないため
- #1039 の決定（子の閾値を 120,000 にし、コンパクトされた子にはそのまま返事を送る）を覆した理由: コンパクトされた子は `SKILL.md` の中身を持たずに進み、手順を守る前提と合わない。起動し直しとの費用の差は 1 回あたり Opus 5.5 で約 $0.5、1 時間以上たってから返事が来る止まり方は子全体の 3.2% で小さい
- 設定キーの確かめ方: 手元の Claude Code の本体を `strings` で読み、設定の型定義に `idleCompaction`（false でアイドル時のコンパクトを止める）があること、アイドル時のコンパクトの判定だけがこのキーを見て通常の自動コンパクトの判定は見ないこと、同梱の変更履歴に v2.1.290 以降が要るとあることを確かめた。記録: https://github.com/oratta/claude-harness/issues/1323#issuecomment-6409563111
- 要る Claude Code の版: v2.1.290 以降。古い版では `idleCompaction` が効かない
- マージ後の実機での確かめ方: エピックを `launch` で回し、子の端末で `ps` 等で起動コマンドに `--settings '{"idleCompaction":false}'` が付いていることを見る。子を 1 時間以上止めたあと、そのトランスクリプト（`~/.claude/projects/` 配下の jsonl）に `compact_boundary` の行が増えていないことを見る
- 受け入れること: この変更より前に起動された子は、従来の閾値でコンパクトされうる（60 分以上なら起動し直す側に入る）。`EPIC_DISPATCH_CLAUDE_CMD` が `--settings` を `claude` に渡さない形のときは指定が効かない
- 戻し方: この PR の差分を戻す
