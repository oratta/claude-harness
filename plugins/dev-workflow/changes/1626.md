# develop の仕様: depleted の scenario 見出しを、中位が上限で最安の役はそのままという規則に合わせる（#1626）

`openspec/specs/dev-workflow-develop/spec.md` の要件「本体は role profile から executor を選ぶ」にある scenario 見出しを、「depleted はすべての要求を Sonnet に固定する」から「depleted は中位を上限にし、最安の役はそのままにする」に直した。#614 の規則（depleted は中位が上限で、最安の役は上げない）と同じ言い方にそろえた。

- THEN の中身（decider の要求 `fable` が `sonnet` になり、`tier_reason` が `SHARED_BUDGET_MODE=depleted` になる）は変えていない。見出しだけを読むと最安（haiku）の役も sonnet に上げると読めた点を直した
- openspec の change は作っていない。openspec は MODIFIED での scenario 見出しの変更を「旧 scenario を落として新しい scenario を足した」と読み、`validate --strict` も archive も止まるため。仕様化判断は `しない`（https://github.com/oratta/claude-harness/issues/1626#issuecomment-6791004901）で、spec.md を直接 1 行直した
- `tests/openspec-specs-format.bats` に、旧見出しが無く新見出しがあることを確かめる検査を 1 件足した
- 戻し方: この PR の差分を戻す。移行は要らない
