# agent 定義に役ごとの effort を持たせる（#711）

effort（推論の深さ）は親セッションの値を継ぐだけで、役ごとに決めていなかった。dev-workflow の agent 定義に `effort` を足し、`model-tiers.md` に対応表と上書き方法を書いた。

- `plugins/dev-workflow/agents/worker.md` / `gate-runner.md` に `effort: medium`、`reviewer.md` / `decider.md` に `effort: high` を足した
- `plugins/dev-workflow/references/model-tiers.md` に節「役ごとの effort」を足した（既存の表は変えていない）。環境変数 `CLAUDE_CODE_EFFORT_LEVEL` があるときは frontmatter より環境変数が勝つ点、Agent の `effort` 引数と環境変数の関係は公式文書に記載なしである点も書いた
- `plugins/dev-workflow/tests/agent-effort.bats` を足した（frontmatter 内の `effort:` 行数と役ごとの値）
- 版は上げない。初期値は仮置きで、変更前後の `/cost` を PR に記録して調整する
