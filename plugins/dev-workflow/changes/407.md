# review-hit-set.py の補助表見出し・主表重複・エラー文言を直す（#407, #408, #409）

- 見出し付きの補助表（#407）: `--head` 付きで、見出し `### 書き換えた該当しない行` が無いのに 3 列の補助表（`| ファイル | 行（修正前 SHA） | 修正後の本文 |`）がある入力は、補助表が無い入力と同じ `unmatched:` にせず、`contract: rewritten-rows table requires the heading ### 書き換えた該当しない行` で exit 1 にする。見出しが `### 書き換えた「該当しない」行` や `## ` レベルだった場合に原因が分かる。補助表が無い入力の挙動は変えていない
- 主表の重複（#408）: `--head` 付きで主表に同じ (ファイル, 行) が 2 行あると、`contract: main table row is duplicated: <path>:<line>` を他の順 3 違反と一緒に蓄積して exit 1 にする（2 段目は走らない）。spec の「ちょうど 1 つ指す」の前提を守るための検査で、仕様の文面は変えていない
- エラー文言（#409）: 記録で済ませず旧文言に戻した。`--head` 無しの主表の契約エラーは #377 より前と同じ `every hit row must have four columns` と `hit rows require path, numeric line, and body`。呼び出し側（スキル文面・既存テスト）にこの文言を期待する箇所は無かったが、spec が「`--head` 無しは現行の出力を変えてはならない」と定めているので、変更を記録するより戻すほうが仕様と一致する。補助表の列数・行の検査の文言（`every row must have 3 columns` / `rows require path and numeric line`）は #377 で新設したものなので変えていない
