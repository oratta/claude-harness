# push-guard-setup に、リポジトリローカルのフックを有効にする手順を書く（kg-recruit#126 / PR #298）

git がフックを探すのは `core.hooksPath` が指す 1 か所だけなので、グローバルに `core.hooksPath` がある PC では、リポジトリが `.githooks/pre-push` を追跡していても clone のローカル設定が無ければ一度も走らない。`skills/push-guard-setup/SKILL.md` に次を足した。

- 層の構成の節に、優先関係が成り立つ条件（その clone のローカル設定に `core.hooksPath` が入っているときだけ）と、ローカル設定は `git clone` では入らないことを明記した。
- 「PR 運用リポジトリでリポジトリローカルのフックを有効にする」の節を追加した（`git config --local core.hooksPath .githooks`、確認コマンド、過去の事故例）。
- ローカルの pre-push からグローバルの pre-push を呼ぶ例を追加した。

`tests/push-guard-setup.bats` に文言の検査 2 本と、例を実際に動かす 3 本を足した。グローバルのフックのテンプレート本体は変更なし。版は上げない（version を書かない運用）。
