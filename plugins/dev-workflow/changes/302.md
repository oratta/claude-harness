# subagent-context.sh: 利用上限エラーで止まったサブエージェントのコンテキスト量を 0 と報告しない（#302）

サブエージェントが利用上限で止まると、トランスクリプトの最後は `isApiErrorMessage: true` のエラー行（usage はトークンが全部 0）になる。`scripts/subagent-context.sh` はこれを最後の usage として採り、`context_tokens: 0`・`over_cap: false` と報告していたため、上限超のサブエージェントを超過に気づかず再開しかねなかった。

- `scripts/subagent-context.sh`: `isApiErrorMessage` / `error` を持つレコード、または usage のトークンが全部 0 のレコードを読み飛ばし、その手前の正常な usage を採る。`error` は値の真偽ではなく値があるか（`null` 以外か）で見て、usage の有無より先に判定する（usage の無いエラーレコードでも印を出す）
- 末尾のエラーレコードを読み飛ばしたときは、出力に `"last_record": "api_error"` を足す。それ以外の出力の形・exit code（0 / 2 / 3）は変えていない
- usage が 1 件も無いとき（エラーレコードしか無い場合を含む）は従来どおり `no assistant usage yet`（exit 1）。fail-open の扱いも変えていない
- `tests/subagent-context.bats`: 合計 160000 + エラー行 1 行（exit 2）、合計 100000 + エラー行（exit 0）、エラー行 3 行連続、エラー行のみ、の 4 件に加え、偽の値の `error`（`{}`・`""`）を持つ非ゼロ usage のレコード、usage の無いエラーレコード、の計 6 件を追加
- version は上げていない（plugin-editing ルール）
- 戻し方: この PR の差分を戻す
