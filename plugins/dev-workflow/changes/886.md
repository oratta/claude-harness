# pr-review-gate: 照合の手順で `--repo <repo>` がリポジトリルートのパスだと明記する（#886）

`stages/triage.md` は冒頭で `<owner>/<repo>` を GitHub のリポジトリ名として使っているため、照合の手順（`review-hit-set.py --head ... --repo <repo> <table-file>`）の `<repo>` を同じものと取り違える余地があった。取り違えると `contract: --repo must be a Git repository root` で exit 1 になる。

- `stages/triage.md` の照合の手順の括弧内に「`<repo>` はリポジトリルートのパスで、GitHub のリポジトリ名 `<owner>/<repo>` ではない」を足した
- `--head <HEAD の 40 桁 SHA>` の書き方は変えていない
- 戻し方: この PR の差分を戻す
