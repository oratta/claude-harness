# dev-workflow: CI やり直し直後の古い失敗を待つ（#536）

`pr-state.sh decide` は、CI のやり直しを決めたときに失敗したジョブ ID の並びを `reran_jobs` に保存する。同じ HEAD で同じジョブ ID の失敗を再び観測したら、古い結果として `none` を返し、前回の状態を保つ。やり直し直後の反映待ちで修正回数を増やしたり、上限時間の打ち切りをオーナーに上げたりするのを防ぐ。

受け入れること: ジョブ ID の並びが同じ間は待ち続ける。新しいジョブ ID の失敗には従来どおり `fix` または `escalate` を返す。`reran_jobs` が無い旧状態・空の並び・`null` を含む並びは待ちの対象にせず、従来の判定を続ける。

戻し方: #536 の `pr-state.sh`・対応テスト・`dev-workflow-pr-state` の仕様差分を戻す。保存済み状態の `reran_jobs` は旧実装では未知のキーとして引き継がれるだけなので、状態ファイルの移行は不要。
