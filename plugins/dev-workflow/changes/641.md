# context-tripwire の実行時間テストを負荷に強くする（#641）

- `tests/context-tripwire.bats` の「5MB のトランスクリプトで 100ms 未満」: 計時を 1 つの python3 の perf_counter に移し、hook の起動から終了までだけを測る。以前は計時用の python3 の起動と `bash -c` の起動が計測値に混ざり、CPU が混んでいると 100ms を超えていた
- 判定は最大 10 回の最小値（100ms を切った時点で打ち切り）。閾値 100ms は spec の MUST なので変えていない。hook 本体・spec は変更なし
