# Codex 組み込み profile のレビュー 3 役を Astra から Sol に替える（#474）

`references/codex-role-profiles.json` の `codex-standard`・`codex-economy`・`claude-write-codex-review` で、`spec-review`・`impl-review`・`review` の model を `astra` から `sol` に替えた。Codex の利用枠の消費が速すぎるのが理由で、呼ばれる回数が最も多い高単価の役を Astra の 1/5 の単価の Sol にする。Claude がオーケストレーターを担う構成では、Astra の強み（長い自律的な多段作業）はオーケストレーター側と重なる。

- effort は `high` のまま。「レビューで effort を上げる」は公式の推奨ではないため据え置いた
- `decider` は `astra` のまま。呼ばれる回数が少なく、判断が一点に集中する役なので単価を下げる効きが小さい
- `hybrid-standard` は変えない（レビュー役はもともと Claude）
- 受け入れたリスク: Sol のレビューが Astra より見落としを増やす可能性がある（比較データは無い）。Claude 側の R1 と pr-review-gate のレビュアーとの二重レビューで補う。戻すときはこの 3 役を `astra` に戻す

進行中の run は init で解決済み設定を固定しているので、レビュー役は途中で変わらない。
