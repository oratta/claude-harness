# usage-probe-multi-account.bats: 空の USAGE_PROBE_RESPONSE_FILE のテストを HOME・security 隔離の足場に載せる（#1503）

- `plugins/dev-workflow/tests/usage-probe-multi-account.bats`: このテストで `setup_keychain_stubs` を呼び、PATH の先頭に足場の `bin`、HOME を `${WORK}/home` にして実行する。足場の `security` は認証なし（終了コード 44）に差し替え、snapshot が書かれないことに加えて、足場の `security` が引かれたこと（本番経路に入った証拠）も確かめる
- 確認: PATH の先頭に呼び出しを記録する代役の `security` を置いて同ファイルを走らせると、直す前は 1 回（`find-generic-password -s Claude Code-credentials -w`）呼ばれ、直した後は 0 回。他のテストのすり抜けは無かった
