# 作業待ちの子への声かけの受信基盤を共通定義に足す（#1792）

作業待ち（背景タスクの完了待ち）の子に送る声かけ用に、停止済み子向けとは別の固定文と返事の型を、共通定義 `references/child-cache-keepalive.json` の `background` に追加した。受信側の 2 経路（会話ログの読み取りと状態フック）だけがこれを理解する。

- `references/child-cache-keepalive.json`: 旧 4 項目（`request_template`・`reply_prefix`・`fields`・`separator`）はそのまま。`background` に同じ 4 項目を足した（接頭辞 `[child-background-cache-keepalive]`、欄 `待ち:`・`次:`、区切り ` | `）
- `scripts/child-log-read.py`: `--keepalive-text` は従来と同じバイト列を出す。`--keepalive-text background` で新しい固定文を出す。会話ログの読み取りは新旧の固定文を認識し、その種類の一行返事だけを子の発言から除外する。交差した種類・接頭辞だけ・複数行・固定文に一文字足した入力・本当の user の割込みは通常の会話として出す。固定文が背景タスクを完了扱いにすることはない。JSON 出力の形は変えていない
- `scripts/epic-child-state.sh`: 予約文の判定（UserPromptSubmit の除外、未登録通知の除外、Stop の最新 user の照合）を新旧の固定文の集合に広げた。予約文の往復では `作業報告`・`dependency_wait: true` を含む記録全体と更新時刻を変えない。返事が逸脱しても同じ。予約文の読み取りに失敗したときは従来どおり「予約文を読めません」のエラー
- 受け入れること: 主が固定文を一字一句そのまま打つと声かけとして扱う（従来と同じ限界）
- ゲート指摘 F1・F2・F4: テストの単独アサーションに失敗ガードを追加し、予約文集合を初期化して非 JSON の同名環境変数が通常 Stop の保存を妨げない回帰テストを追加した。
- design.md の固定文全文の複写を共通 JSON の正本への参照に置き換えた。

## 境界（この変更でやらないこと）

- 子が背景待ちの声かけを受けたときの手順の接続（`epic-keepalive.md`・`child-background-wait.md` とその bats）は #1793
- 親からの送信の有効化と、#1743 の自己タイマーの撤去は #1777。親は旧経路のまま新しい固定文を送らないので、この変更だけでは新形式の送信は起きず、稼働済みとも宣言しない
- 戻し方: この PR の差分を戻す。状態ファイルの形は変えていないので移行は要らない

## 場面の予算

共通定義に `background` を足して JSON が 654 バイト増え、それを読む `nested-stop`・`nested-delegated` の 2 場面だけを実測値（59711・66167）に上げた（`tests/develop-epic-scene-budget.txt`）。固定文は design.md で確定済みで削る対象は無い。ほかの場面と `tests/injection-budget.txt` は変えていない。
