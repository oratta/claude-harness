# サブエージェントの停止確認が返らないときの終端を決める（#266）

PR #253 で定めた「停止を指示 → 停止確認を受け取る → 手渡し先を spawn」には、停止確認が返らないままの終端が無かった。即興が生まれる場所を閉じた。

- `skills/develop/references/decision-criteria.md`（正本）: 終端を観測できる 2 条件で定義した。停止指示からの経過時間が `DEV_WORKFLOW_STOP_CONFIRM_TIMEOUT` 以上、かつ前任のトランスクリプトの無更新時間が `DEV_WORKFLOW_STOP_CONFIRM_STALL` 以上。本体のターン数は条件に使わない。帰結は「手渡し先を spawn せず作業を止めて人間に報告する」で、手渡しの許可（①`工程完了:` return ②停止確認）は 2 つのまま。人間の返事も経過時間も停止確認の代わりにならない。既定値は環境変数の表にだけ置いた
- `scripts/subagent-context.sh`: `--stop-since <epoch秒>` を追加。終端に達したら exit 3（この指定時は上限超過で exit 2 にしない）
- `tests/handoff-declaration.bats` / `tests/subagent-context.bats`: 帰結を「前任を放置して spawn してよい」側に書き換えると落ちる検査と、2 条件・exit 3 の検査を追加
