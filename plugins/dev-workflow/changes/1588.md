# dev-workflow: 文言合わせの通し方を「軽い通し方」と呼んでいた見出しとコメントを直す（PR #1588）

仕様の文言合わせの通し方を足したときの変更の記録（`changes/986.md`）の見出しと、そのテスト（`tests/spec-wording-sync-light-path.bats`）の冒頭コメントが、この通し方を「軽い通し方」の語を入れた名前で呼んでいた。「軽い通し方」は今は、本体が作業者を起こさずに直す別の通し方の名前なので、読んだ人が二つを取り違える。

- 2 か所の呼び名から「軽い」を外し「文言合わせの通し方」に言い換えた。見出しとコメントだけで、挙動は変わらない
- 戻し方: この PR の差分を戻す
