# #1388: idle compaction の実機観測手順と受動的な収集部品

[観測手順書](../skills/develop/references/idle-compaction-observation.md) に、主が実行時に記入する承認欄（本数・消費上限・設定適用先・停止条件）、役割別の設定確認、親/子の待機と別区間の通常 compact/hook 観測、metadata の全項目と fixture 例を追加した。

`python3 <plugin>/scripts/idle-compaction-observation.py --transcript <jsonl> --metadata <json>` は指定区間だけを受動的に収集する。開始時の会話量は既存 `subagent-context.sh --file` を再利用し、境界は JSON の type/subtype で数える。条件不足は理由付き unverified、条件成立時の境界は unexpected-boundary として保存する。exit 0 は保存成功であり、実機合格を意味しない。

保存先は主が指定する repo 外の `LLM_LOG_DIR` のみ。未設定なら停止して確認を案内する。既知の観測項目だけを保存し、本文・tool 出力・未知キーを転記しない。既存の設定・起動・再読み込み hook は変更していない。

受け入れ項目の正本は [#1385 の変更記録](1385.md)、設定操作と戻し方の正本は [reply-after-idle.md](../skills/develop/references/reply-after-idle.md)。今回の検証は外部 fixture の Bats のみ。実機セッションの起動・実設定変更・実機観測は未実施で、#1385 を完了扱いにしない。実機結果は主が承認範囲内で別途記録する。
