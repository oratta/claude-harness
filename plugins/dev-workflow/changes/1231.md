# subagent-context / pr-token-budget: 会話記録の既定の探索先で CLAUDE_CONFIG_DIR を見る（#1231）

`subagent-context.sh` と `pr-token-budget.sh` は `CLAUDE_CONFIG_DIR` を見ていなかった。`~/.claude` 以外の設定で動くセッションでは、前者が `transcript not found`（exit 1）で失敗し、後者が Claude 側の消費を 0 と数えるので、コンテキスト上限の手渡しと PR トークン上限の判定がどちらも効いていなかった。

- `scripts/subagent-context.sh`、`scripts/pr-token-budget.sh`: 既定の探索先を `${CLAUDE_PROJECTS_DIR:-${CLAUDE_CONFIG_DIR:-$HOME/.claude}/projects}` にした。`--projects` が最優先なのは変えていない
- 探索先は 1 か所のまま。別の `CLAUDE_CONFIG_DIR` の下の会話記録は探さない
- 既定の `~/.claude` だけを使う環境の動きは変わらない
- 同じ書き方の `subagent-context-audit.sh` と `epic-launch-tmux.sh` は変えていない（#1481 で直す）
- 受け入れること: `CLAUDE_CONFIG_DIR` を使うセッションでは PR トークン上限の exit 2 が初めて出るようになる。1 つの記録先を別々の `CLAUDE_CONFIG_DIR` のセッションで進めると、実行中のセッションの設定の分しか数えず、`~/.claude` の分と混在する記録先では修正前より合計が小さくなることもある
- 戻し方: この PR の差分を戻す。保存する状態を変えていないので移行は要らない
