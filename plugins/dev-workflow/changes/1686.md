# PR トークン計測の 1 コマンド化と epic-dispatch.sh --help（#1686）

develop の手順書にあった「決まった入力から決まった出力が出る処理」の文章と埋め込みの bash のうち、2 つをスクリプトに出した。Claude Code は scripts を読まずに実行するので、その分の文章が手順書（コンテキスト）から消える。

- `scripts/pr-token-measure.sh`（新規）: `codex-records.sh` と `pr-token-budget.sh` を同じ順でつなぐ。`--repo`・`--cap`・`--codex-home`（繰り返し可）・記録先番号を受け、`${CODEX_HOME:-$HOME/.codex}` を足し、`pr-token-budget.sh` の stdout と exit code（0 / 2 / 1）をそのまま返す。取得に失敗したら集計を呼ばず exit 1。`references/pr-token-budget.md` の計測の bash はこの 1 コマンドの呼び方に置き換えた
- `scripts/epic-dispatch.sh --help`（`-h`）: 全サブコマンドの書式・終了コード・出力語の意味・`child-log` の列・同時上限の既定値・子の起動コマンドの組み立てを stdout に出す。`gh`・`orca`・`git` を呼ばず状態の記録に触れない。既存の使い方（stderr・exit 1）と各サブコマンドの出力語・終了コードは変えていない。`tests/epic-dispatch.bats` が、固定リストの全語が `--help` に載ることと、スクリプトが `echo` する結果行の語頭がすべて固定リストにあることを突き合わせる
- `references/epic-loop.md`: 出力語の定義文を消し、`--help` への参照と「進む／止まって主に報告する」の分類表にした。動作指示（`kept` の確かめ方、`not-done`、`reaped`・`gone` の扱い、推定 `done` の条件、`notify-closed` の `unrecorded`・`failed` の扱い、手順 7 の復元など）は残した
- `epic-dispatch.sh` 3 行目のコメントが指す `epic.md「回し方」`（分割で無くなった節）を `epic-loop.md` に直した
