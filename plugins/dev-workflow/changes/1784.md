# dev-workflow-epic-state spec: 旧記録の Scenario を起動指示だけの登録に合わせる（#1784）

`openspec/specs/dev-workflow-epic-state/spec.md` の Scenario「旧記録と変更前の親を維持する」の THEN が「旧記録への通常入力で従来どおりターン情報を作る」と書いていて、同じ spec の要件「一致する起動指示の入力だけで初回登録する（MUST）。任意の通常入力や Stop から登録してはならない（MUST NOT）」（#1756 / PR #1766）と食い違っていた。THEN を「旧記録への一致する起動指示の入力でターン情報を作る」に直した。

- 実装と試験は既に要件側に合っているので変えていない。spec の文だけの修正
- 戻し方: この差分を戻す
