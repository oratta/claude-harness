# 長い一時パスでも残留プロセスのコマンド末尾を報告する（#1724）

`scripts/test.sh` が残留プロセスを報告するとき、1 行を 160 字で切っていたため、長い `TMPDIR` / `BATS_TMPDIR` 配下の実行ファイル名や引数が欠け、残留検査のテストも失敗していた。

- 残留報告を `ps -ww` で取得し、160 字の切り詰めを外した。原因の実行ファイル名・引数を残すための変更であることをコードコメントに記録した
- `tests/test-sh-residual-guard.bats` の bats に似た名前の残留を検出するケースに長いパスを組み込み、既定の一時パスが短い環境でも切り詰めの再発を検出する
