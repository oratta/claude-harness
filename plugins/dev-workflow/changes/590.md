# subagent-context: metadata の名前からトランスクリプトを探す（#590）

`subagent-context.sh <agent-name>` は、ファイル名に担当名が含まれないログも、隣の `agent-*.meta.json` の `name` が指定名と完全一致すれば計測できるようになった。

- metadata に対応する実在の JSONL と、従来のファイル名 glob の候補を統合し、重複を除く。cwd が現在のディレクトリと一致するログを優先し、その中でログ自体の更新時刻が新しいものを選ぶ。一致が無ければ全候補で最新を選ぶ
- metadata の欠落・名前の不一致・壊れた JSON・非オブジェクト・name 欠落・対応ログの欠落は探索を妨げない。従来のファイル名でも候補が無ければ `transcript not found` / exit 1 を返す
- `--file` の直接指定、usage の計測式、上限判定と停止確認の判定は従来どおり
- bats に metadata 探索・従来のファイル名探索・複数候補の選択・fallback の回帰テストを追加した。候補選択のテストはログと metadata の mtime を明示し、待ち時間に依存しない

新しい依存関係や設定、既存ログの書き換えは不要。version は変更していない。取り消す場合はこの変更を通常の PR で戻す。
