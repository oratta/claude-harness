# usage-probe: PATH に claude が無くても版を取り、固定値に落ちたら警告する（#1170）

- `scripts/usage-probe.sh`: User-Agent に入れる claude の版を取るとき、PATH に claude が無ければ `$HOME/.local/bin/claude` も探す。cron・hook・launchd のように PATH が最小の環境で、固定値 2.1.0 に落ちて UA が実際の版とずれるのを防ぐ。
- 版が取れず固定値 2.1.0 に落ちたときは、stderr に 1 行の警告を出す（動作は変えない。`USAGE_PROBE_USER_AGENT` 指定時は出さない）。
- `tests/usage-probe-multi-account.bats`: 上記 2 点の bats を追加。
