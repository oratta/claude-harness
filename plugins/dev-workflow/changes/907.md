# epic-dispatch.bats: 「経路の決め方」の子 0 件の文と件数の下限なしを固定する（#907）

`tests/epic-dispatch.bats` の「epic run section states the routing conditions and the subagent fallback」で、「経路の決め方」の段落に `件以上` が無いこと（`2 件以上` だけでなく、`3 件以上` などの下限も見る）と、`0 件` と `subagent` を含む文があること（子 0 件なら Orca 管理下でも `subagent`）を検査するようにした。段落に件数の下限を足した変形でも、子 0 件の文を消した変形でも、このテストが落ちる。

実装の変更と版の更新は無い。
