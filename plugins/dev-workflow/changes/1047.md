# エピックの子を片付けたとき、子のローカルブランチも消える（#1047）

`epic-dispatch.sh reap` は `orca worktree rm` が exit 0 で返った直後に `git branch -D` を呼んでいたが、Orca はワークツリーを非同期で消すため、git の一覧にまだ残っていて `Cannot delete branch ... checked out at ...` で失敗し、`reaped <N> branch-kept` になっていた。

- ブランチが残っていて先端が HEAD と同じときだけ、`git worktree list --porcelain` に `worktree <子のパス>` の行が無くなるまで待ってから `git branch -D` を呼ぶ。先端が違う子・ブランチが無い子は待たない
- 上限は `EPIC_DISPATCH_REAP_DETACH_TIMEOUT`（秒、既定 30）、間隔は `EPIC_DISPATCH_REAP_DETACH_INTERVAL`（秒、既定 1）。数値でなければ既定、間隔 0 は既定に戻す。上限を超えたら今までどおり `reaped <N> branch-kept`。`git worktree list` が非 0 のときは残っている扱い
- 待ちは `TIMEOUT / INTERVAL + 1` 回の確認と、`SECONDS` の経過秒数が `TIMEOUT` に達したことのどちらか早い方で止まる（`sleep` をスタブにして時計が進まないテストでも回数で止まり、1 回の確認が遅いときは経過秒数で止まる）。待ったあとは、ブランチの先端を読み直して HEAD と同じときだけ `git branch -D` を呼ぶ
- 戻し方: この PR を revert する
