# epic-dispatch.sh 冒頭コメントの引数エラー説明を実装に合わせる（#432）

`epic-dispatch.sh` 冒頭のスクリプトコメントにあった「引数の誤り（子が 0 件・番号が数字でない・フラグ値の誤り）は stderr に使い方を出して exit 1。」は全サブコマンド共通のように読めたが、`cmd_route` は子 0 件でも `check_children` の数字検査だけを通して `subagent` を出し exit 0 で終わる（`[ "$#" -ge 2 ]` は orca 経路の判定条件であって引数検査ではない）。件数を検査して usage で落ちるのは `launch`（`[ "$#" -ge 2 ]` で epic か子が無ければ exit 1）と `wait`（`[ "$#" -ge 1 ]` で子が 0 件なら exit 1）だけだった。

- コメントを「引数の誤り（`launch` は epic か子が無い、`wait` は子が 0 件、番号が数字でない、フラグ値の誤り）は stderr に使い方を出して exit 1。`route` は子 0 件でも `subagent`」に置き換えた。コード本体・bats・他のコメントは変えていない
- `openspec/specs/dev-workflow-develop/spec.md` の該当箇所（`route` は「子の番号が数字でなければ」とだけ書き、件数条件を書いていない／`wait` の件数条件は `wait` 自身の MUST 文にのみ書かれている）は元から今回のコメントのような全コマンド共通の誤記になっておらず、直す必要はなかった
- コメント修正のみで振る舞い不変のため仕様化しない（コード直行）と判定した
