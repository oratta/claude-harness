# synced-skills-slim: claude.ai から同期されたスキルを name-only にする設定コマンドを足す（#1470）

同期スキルの名前と説明は、使わないセッションでも毎回の最初のリクエストに載る。`/dev-workflow:synced-skills-slim` は、その環境の同期スキルを `settings.json` の `skillOverrides` に `name-only` で足す。実測（Claude Code 2.1.314、同期スキル 13 本）で最初のリクエストが 9,282 バイト減った。

- 新規: `commands/synced-skills-slim.md`（`plugin.json` の `commands` に登録）、`scripts/synced-skills-name-only.sh`
- キーは `anthropic-skills:<スキルのディレクトリ名>`。名前は `<config>/skills/synced/<バケット>/<名>/SKILL.md` から取る。足すのはキーが無いものだけで、既存の値と他の設定は変えない。足すものが無ければ書かない
- 書く前に `--dry-run` の結果を見せて確認を取る。足すときは `settings.json` の隣に `settings.json.bak-<日時>` を作る（symlink でも同じ）。`settings.json` が symlink なら指す先を書き換え、権限は保つ
- 引数と `jq` の検査を列挙より先に行う。同期スキルが無ければ `settings.json` を読まずに exit 0
- hook からは呼ばない（確認なしに `settings.json` を書き換えない）
- 戻し方: コマンドの案内にあるとおり、バックアップを戻すか、足したキーだけを `jq` で消す。この変更自体は差分を戻せば消える
- 常時注入の予算: 新しいコマンドの description が 38 バイト増える分を、同じ変更で `commands/work-issue.md` の description を `/develop のエイリアス（旧名）` に縮めて（51 バイト減、振る舞いは変えない）相殺した。`tests/injection-budget.txt`（40905）は動かしていない。実測は 40942 から 40891 になった
- 手動で確かめる項目が残っている: (1) `manifest.json` の `staleDirs` が残る環境で、余分なキーが足されても無害か（この環境の `manifest.json` に `staleDirs` が無く再現できなかった。実在しないキーが無害なことは `claude -p --settings` で確かめ済み）、(2) 実際のセッションで `/dev-workflow:synced-skills-slim` を起動して、確認の質問が出ることと、書き込み後の次のセッションで同期スキルの説明が出なくなること（コマンド文書の構造とスクリプトの動作は bats で確かめたが、スラッシュコマンドとしての起動は未実施）
