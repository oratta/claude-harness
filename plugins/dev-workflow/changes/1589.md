# #1589 軽い通し方の CI 修正から通常経路へ戻す

## 変更

軽い通し方で G が passed を返したあと、CI の見張りが `ci-fail` または `conflict` の `fix` を返した場合は、同じ worktree に新しい W を `段: spec` で起こす。
PR・記録先・失敗したチェックや run などの修正材料を渡し、W が同じ記録先へ `通し方:` の行の無い仕様化判断を投稿し直す。
仕様化するなら artifact 一式と R1 の APPROVE を経て実装し、仕様化しない場合もテストを書いて同じ PR に修正を積む。

通常経路に既存 W がいる場合は `段: implement` で再開し、必要な手渡しは既存の許可条件に従う。
軽い通し方から通常へ戻った後の再 fix もこの分岐を使い、CI の fix だけを理由に spec 段へ戻したり、仕様化判断を投稿し直したりしない。

修正 push 後は passed を外したまま、同じ PR・同じ状態ファイルで `wait` → `next` を続ける。
`ready` 後に前提確認と重さ判定から新しい G でゲートを取り直す。差分と無関係な失敗は共有手順どおり修正・push せず返す。
