# injection-budget: 禁止句の被覆テストの references 除外を相対パスで判定する（#861）

`tests/injection-budget.bats` の「the phrase check covers plugin skills and the generated .claude and .agents files」は、対象一覧の絶対パス全体に `/references/` が無いことを検査していたため、checkout 先のパスに `/references/` があると一覧が正しくても落ちた。

- 判定を `${output//$REPO_ROOT/}` の後の相対パスに対して行い、`/plugins/` 配下の `references/` だけを除外する形にした。`.claude/skills` 配下の `references/` は spec どおり検査対象のまま
- 規範（spec）と、プラグインの実行時の挙動は変えていない。テストの書き方だけの修正
- 確認: 通常の場所と、パスに `references/` を含む場所へコピーした repo の両方で `scripts/test.sh injection-budget` が exit 0
