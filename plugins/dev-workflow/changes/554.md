# develop の G を段ごとに新しく起こし、SendMessage での再開をやめる（#554）

develop のマージ前の検査担当（G）は名前付きで 1 体起こされ、段が進むたびに本体から SendMessage で再開されていた（前提確認と重さ判定 → レビュー担当の要約を受けて照合と振り分け → 合格処理）。再開のたびに前の段の履歴が残るため、1 体目が 2 段目の途中でコンテキスト上限 150K に当たって後任に交代し、後任は指示書を読み直して同じ量を払い直していた。直近 10 日で G の半数が上限を超えていた。#553 で段ごとに読むファイルを小さくしたので、段ごとに新しい G を起こしても 1 体あたりの固定分は抑えられる。

- `skills/develop/SKILL.md` の (4) を、段ごとに新しい G を spawn する形にした。G は 4 つの段（前提確認と重さ判定・照合と振り分け・合格処理・保留の解除）のどれか 1 つだけを担当し、起動指示に `段: <段の名前>` と前の段の `## Gate Result` ブロックを貼る。G を SendMessage で再開する記述を消した。failed のあとは Gate Result の `次の段:` どおりに起こす
- `skills/develop/references/roles/gate-runner.md` の Gate Result の共通欄に `段:`（従来経路は `一括（従来経路）`）と `次の段:` を足し、Status に `次の段へ` を足した。本体は `次の段:` を読んで次の G を起こすだけにし、段の判断は G 側に置く。「再開」節は「段ごとの起動と入力」節に書き換えた。`レビュー経路: adapter` で起動済みの同一 G が adapter 経路を保つ規則は、再開が無くなるので消した（`references/codex-develop.md` も同じ）
- 段と段の間の受け渡しは PR コメントを正とした。`stages/prepare.md` の `レビュー重量:` コメントに `固定 HEAD: <SHA>` の行を足し、照合と振り分けの G がレビューの三表を 1 行目 `レビュー三表:` のコメントとして投稿する（`stages/triage.md`）。「レビュー実行者:」コメントの段落は `stages/prepare.md` から `stages/triage.md` へ移した。`stages/hold.md`・`stages/pass.md` の再開の小節は、その段で起こされたときの入力に書き換えた
- G が `工程中断:` で返したら同じ段の新しい G を起こす。G の名前は `G-<PR>-<prepare|triage|pass|hold>-<n>`、description は `G: <段> for PR #N (#issue)` にした
- G を起こす前の `subagent-context.sh` による計測は W だけに残した（`references/decision-criteria.md`・`templates/escalation-tripwires.md`・`scripts/session-tripwires.sh`）
- 既存要件の本文は書き換えず、`dev-workflow-develop`・`dev-workflow-pr-review-gate` に読み替えの要件を足した（#553 と同じやり方）。auto-merge workflow と `対象 HEAD:` 規約の文言は変えていない
- `tests/develop-roles.bats` に、段ごとの起動があり G を SendMessage で再開する記述が無いことの検査を足し、G の再開を前提にした既存の bats のアサーションを段ごとの G に付け替えた
- 受け入れ条件 3「develop で通した PR 5 本で G の上限超えの割合が 15% 以下」は、マージ後にエピック #511 で測る
- PR #581 のゲートの指摘で 3 件を直した。保留の解除のあとの合格処理は、今の HEAD の `対象 HEAD:` を持つ `## リスク宣言` があれば手順 5 から、無ければ `declarations.md` の手順 3 から入る（照合と振り分けのあとの入口は `段: 照合と振り分け` で見分ける。#582）。順 3 だけの修正のあとの照合と振り分けの G は `stages/prepare.md` の手順 1 で新しい HEAD を固め、`固定 HEAD: <新しい HEAD>` 付きの `レビュー重量:` を投稿してから照合する（#583）。補足の `needs-reviewer` の前に投稿する `レビュー三表:` には `補足済み回数: 1` と書く（#584）
