# develop: Orca 経路の手順 6 を、`--watch-stopped` 付きの `wait` が Orca から読めず終わる場合にも広げる（#1043）

- `skills/develop/SKILL.md` 手順 6: 「`--watch-done` 付きの `wait` が…」を「`--watch-done` か `--watch-stopped` を付けた `wait` が stdout に何も出さず exit 1 で終わった」に広げた。報告は同じく「親ワークツリーで開き直す」
- `openspec/specs/dev-workflow-develop/spec.md`: 要件「Orca 経路の本体は印が付いた子のワークスペースを片付ける」の同じ文を広げ、シナリオを 1 件足した
- `tests/epic-dispatch.bats`: 手順 6 の文が `--watch-done` と `--watch-stopped` の両方を挙げていることを確かめる検査を 1 行足した
