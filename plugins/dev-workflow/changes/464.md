# codex-records.sh 計測手順まわりの残指摘 7 件を直す（#464）

PR #462 のレビューで残った指摘 7 件を、すべて反映した（いずれも origin/main で未修正だったことを確認済みで、除外した項目は無い）。

- 計測手順（`skills/develop/SKILL.md`）の `if ... fi` を `&&` 連結にした。収集に失敗した回、コードブロック全体の終了コードが 0 ではなく `codex-records.sh` の 1 になる。`develop-skill.bats` の検査も `&& scripts/pr-token-budget.sh` に合わせた
- `codex-records.sh --help` の出力から `set -uo pipefail` の行を外した（`sed -n '2,12p'`）
- 引数不足テストの 4 回目の前に記録ファイルを作り直し、`[ ! -e "$OUT" ]` が実際に検証になるようにした
- `gh` が無いテストは「gh not found」のメッセージまで検査する。PATH は bash と rm だけを置いた一時ディレクトリにし、`/usr/bin` に gh があっても結果が変わらない
- `jq` が無い場合の Scenario を `openspec/specs/dev-workflow-pr-token-budget/spec.md` に足し、対応するテストを 1 件足した
- `develop-skill.bats` の理由の検査を、exit 1 の列挙行（`**exit 1（…Codex 消費コメントを取得できなかった）**`）に限定した
- `codex-records.sh` に EXIT・INT・TERM の trap を置き、中断時にも一時ディレクトリを消す。SIGTERM を送るテストを足した（macOS の `mktemp -d` は TMPDIR を見ないため、作った場所を記録する mktemp スタブで確認する）
- `codex-records.bats` の `setup()` に `export LC_ALL=C.UTF-8` を足した

`gh` と `jq` の不在分岐のメッセージを一時的に変えると、新しい 2 件のテストが落ちることを確認した。
