# 分割後に残った旧所在の参照を、移動先を直接指すように直す（#1723）

develop と pr-review-gate の本文を分けたあと、移動前の所在を指したままの参照が残っていた。G や本体がそれを辿ると、必要な節に直接着かず場面外の本文を余計に読むか、そのファイルに無い節を探すことになる。参照先を直すだけで、動き・ルール・判定条件は変えていない（エピック #1682 の子）。

- `skills/pr-review-gate/stages/carryover-judge.md`: 「下の『G として動くとき（develop）』節」（そのファイルに無い節）を、実在する `hold.md` の同名の節を明示する参照に直した（「返す欄は `hold.md` の「G として動くとき（develop）」節」）
