# sync.sh で Codex marketplace と導入済みキャッシュを更新する（#1865）

`scripts/sync.sh` は、実行元 manifest と同名で登録済みの Codex Git marketplace に限定して `codex plugin marketplace upgrade <name> --json` を実行する。snapshot、導入済み dev-workflow キャッシュ、移行済み command skill の更新・削除は CLI に任せる。登録元・ref・有効無効設定を保持し、未登録 marketplace の追加やプラグインの有効化は行わない。

- `--no-pull` は実行元と overlay の pull を省略する。Codex の別 snapshot とキャッシュの更新は行う。
- CLI 不在・対象なし・local 登録のみなら更新を省略する。jq 不在、manifest/CLI JSON 不正、list/upgrade の非0終了、upgrade の errors 非空は警告して非0で終え、rules/output-styles の配線は続行する。
- エラー文の marketplace 名は `${codex_name}` と区切り、全角括弧に続く変数が `set -u` で未定義変数扱いされて配線前に終了する問題も修正した。
- 一時 HOME / CODEX_HOME / CLAUDE_CONFIG_DIR とローカル Git main を使った `bats tests/codex-sync.bats tests/rules-sync.bats tests/marketplace-sync.bats` は70件成功（exit 0）。実 CLI 0.163.0 の2件も skip なしで成功し、snapshot/cache の native develop のバイト一致、移行 command の本文更新・削除、繰り返しと設定保持を確認した。
- 実ホーム（`~/.codex`・`~/.claude`）の更新と main/cache の一致確認は未実施。マージ後に運用側で実行し、issue #1865 に結果を記録する。

plugin.json に version は追加しない。戻す場合はこの変更を revert する。
