# auto-merge がマージ失敗時に gh の理由文をログへ出す（#157）

auto-merge workflow は、マージに失敗したとき gh の理由文をログへ出し、認証失効（401）と HEAD 不一致などの拒否（409）を分けて表示する。PAT の節から調べ方（項目 7）へのリンクも直した。変更したのは `.github/workflows/auto-merge.yml`、同名のテンプレート `plugins/dev-workflow/templates/auto-merge/`、`docs/auto-merge.md`、`scripts/test-auto-merge-workflow.sh`。

版は上げない（plugin.json に version を書かない運用）。
