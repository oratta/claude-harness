# spec-reviewer の守備範囲の欠落を要素ごとに重さ分けし、退行検査を複数行に強くする（#389）

PR #388 の独立レビューで出た 2 件の直し。

- `references/roles/spec-reviewer.md` の観点 6（守備範囲の明記）に、どの要素が欠けたら BLOCKER かを書いた。「何から守るか」（想定する入力の出どころ・拾いたい誤り）か「何は守らないか」（通ることを許す入力の具体例）の片方が無ければ BLOCKER、「穴を塞ぎ切ることを完了条件にしない」の一文だけが無いときは SHOULD_FIX に留める。仕様 `dev-workflow-spec-review` は変えない（仕様は両側が揃うことを求めるだけで、要素ごとの重さは書いていない）。
- `tests/develop-roles.bats` の該当検査は、節を 1 行に潰してから grep する。段落に改行を入れても、内容が揃っていれば落ちない。あわせて setup で `LC_ALL=C.UTF-8` を設定した。
