# accounts.sh add が全角の id と --help を登録しないようにする（#1007 #977 のレビュー指摘）

`accounts.sh add ｂ`（全角）が macOS の `/bin/bash` 3.2 と UTF-8 ロケールで exit 0 になり、`add --help` / `add -h` / `add --label` が `--help` などの id のスロットとディレクトリを作っていた。登録を消すコマンドが無いので、残ると登録簿の手編集でしか直せなかった。

- `scripts/accounts.sh`: `check_id()` の先頭に `local LC_ALL=C` を足し、全角の id を exit 2 にした。`add` は id の前で `-h|--help` なら usage を出して exit 0（登録簿もディレクトリも変えない）、`--label` なら exit 2 にする
- usage の出力先: `-h` / `--help` のときだけ stdout（`accounts.sh --help 2>/dev/null` でも読める）。引数の誤りのときの usage は従来どおり stderr。`accounts-init.sh` は変えていない（同じ検査の行は別に扱う）
- `tests/accounts-command.bats`: 全角 id（`LC_ALL=en_US.UTF-8` の `/bin/bash` で実行。macOS の /bin/bash 3.2 でだけ修正前に落ちる。CI の ubuntu では再現しない）、`add --help` / `-h`、`add --label`、`--help` の stdout を足した。既存のテストは変えていない
- 仕様化しなかった: `usage-account-registry` の id は英数字とハイフンという要件に実装を合わせただけ
- 戻し方: この PR の差分を戻す。登録簿の形は変えていないので移行は要らない
