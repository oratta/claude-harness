# accounts-init: id の検査を accounts.sh の check_id() と同じ LC_ALL=C 固定にする（#1496）

macOS の `/bin/bash` 3.2 と UTF-8 ロケールでは、`accounts-init.sh --id ｂ`（全角）の `[!A-Za-z0-9-]` が照合順で評価されて通り、読み手（`usage_view.py`）に捨てられるスロットが登録簿に残っていた。

- `scripts/accounts-init.sh`: id の文字検査を、関数内で `LC_ALL=C` に固定して行う（`accounts.sh` の `check_id()` と同じ）。全角の id は exit 2 で、登録簿は変わらない。label の検査と長さの数え方は従来のロケールのまま
- `tests/accounts-command.bats`: 全角 id の拒否と、`b`・`work-2` が通ることを 1 件足した（`/bin/bash` と UTF-8 ロケールで走らせる）
- 要件の文（`usage-account-registry`）は変えていない。実装を既存の要件に合わせた
- 戻し方: この PR の差分を戻す。登録簿の形は変えていない
