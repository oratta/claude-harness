# レビューの指摘から同じ場所を直す open の issue を探すスクリプトを足す（#984。エピック #973 の子）

- `plugins/dev-workflow/scripts/review-issue-candidates.sh` を足した。指摘が指すファイルのパスごとに open の issue を 1 回検索し、番号と題名を最大 15 件返す。本文は返さない。`--exclude` で候補から外す番号、`--epic` で各行に子かどうか（`child` / `other`）、`--epic` と `--children-only` で子だけに絞る指定を受け取る。検索の失敗は終了コード 1、引数の不備は 2 で、「候補なし」（終了コード 0）と区別できる
- `plugins/dev-workflow/tests/review-issue-candidates.bats` を足した。`gh` を偽物に差し替えて、検索語・`--limit`・呼び出しの回数・終了コードを確かめる
- このスクリプトを呼ぶ箇所はまだ無い。手順書（`stages/triage.md` など）からの呼び出しは #973 の子 issue #985（止めない指摘を 5 段の振り分けに通す）で入れる。版は上げていない
