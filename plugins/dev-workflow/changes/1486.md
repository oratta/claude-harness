# pr-review-gate: 周の終わりに残った止める指摘の条件を先に確かめ、成り立つ予定が無いものを閉じる（#1486）

段 B は止めない指摘にだけ掛かるので、2 周目以降の周の終わりに残った止める指摘は、運用上起きない場面への指摘でも、順 6 の裁定・直し方の判定・主への確認に進んでいた（#1121 の follow-up）。

- `stages/triage.md`: 周の終わりの段落の直後に段落「周の終わりの止める指摘の条件」を足した。G は順 6・直し方の判定・順 5 の振り分けより先に、段 B の表の分け方で条件を決める。閉じるのは「成り立つ予定が無い」の指摘だけで、仕分けの PR コメントに条件と理由を 1 行残し、仕分け欄に URL を書く。全件を閉じたら「止める指摘が残らなかったとき」と同じに扱う
- 閉じない指摘: 受け入れ条件、またはこの PR が触れる openspec の spec（delta spec を含む）の文がその場面の振る舞いを求めている指摘と、主が順 5 で「この PR で直す」と答えた指摘。根拠は段 B と同じで、change の artifact の想定は根拠にしない
- G が決められないときは閉じずに既存の仕分けへ進める。新しい質問も保留も足さない
- `stages/triage.md` の周の終わりの段落の書き出しと手順 3 を、新しい段落を通したあとの形にそろえた
- `stages/pass.md`: 合格処理の前提の除外に、周の終わりの条件で閉じた指摘を足した
- `references/fix-check.md`: PR のレビューの文を、本体の手順は当てず G が確かめる形に直した
- 変えていないこと: マージを止めるかの判定、1 周目の扱い、順 3・順 4 からの落とし込みの順 6、「直し方の判定の受領」、`hold.md`、段 C・候補探し・順 5 の切り出しの置き場所
- 受け入れること: G が根拠を読み違えて成り立つ指摘を閉じることは完全には防がない。閉じた理由は PR コメントで後から見える
- 重なり: #1436（#580）が `triage.md` を分割し、`pass.md` の同じ文も書き換える。後から入る側が、段落「周の終わりの止める指摘の条件」・周の終わりの書き出し・手順 3・`pass.md` の除外を再適用する
- 戻し方: この PR の差分を戻す。保存する状態は増えていないので移行は要らない
