# agents / 指示書: 一時ファイルは `cd` とワイルドカードを組み合わせず絶対パスで消す（#1136）

サブエージェントが `cd <dir>; rm -f tbl/*` の形で一時ファイルを消すと、削除先が `cd` 後の場所になり、Claude Code 本体が静的に読めず確認画面（Dangerous rm operation on statically-unresolvable target）で止まった（flatmate #701）。

- `agents/reviewer.md`・`worker.md`・`gate-runner.md`: 本文に「一時ファイルを消すときは `cd` とワイルドカードを組み合わせず、絶対パスで書く。」を 1 文足した（`description` は触らず、常時注入の予算は動かない）
- `skills/develop/references/roles/worker/common.md`: 「一時ファイルを消すときの書き方」の節を正本として足した
- `roles/gate-runner.md`・`skills/pr-review-gate/stages/reviewer-brief.md`: 正本を指す 1 文を足した
- 戻し方: この PR の差分を戻す
- #1132 の実機確認の結果: bypass permissions では、削除先を絶対パスで書けば確認が出ない。ただし作業ディレクトリ・その親・ホーム・`/` 直下を指す glob は絶対パスでも確認が出るので、避けられるのは作業ディレクトリの外の一時領域を消すときに限る。この限定を `worker/common.md` の正本の節に足した（agents 本文の 1 文は変えていない）
