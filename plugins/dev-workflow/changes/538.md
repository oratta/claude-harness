# pr-state.sh: 形の崩れた --hints を読み込み時点で弾く（#538）

`pr-state.sh observe --hints <file>` に、`annotations_by_job` がオブジェクトでない JSON、その値が配列でない JSON、最上位が配列の JSON、JSON が 2 つ入ったファイルを渡すと、読み込みは通り `observe` の本体で落ちていた。終了コードは非 0 だがメッセージが「cannot read gh pr view JSON from stdin」になり、原因を取り違えた（PR #534 のレビュー指摘 F4）。

- `scripts/pr-state.sh observe`: `--hints` の読み込みで、ファイルが JSON 1 文書で、最上位がオブジェクトで、`annotations_by_job`（無ければ `{}` 扱い）もオブジェクトで、その値がすべて配列（または null）のときだけ通す。それ以外は `pr-state.sh: cannot read --hints file: <path>` で非 0 終了する
- 正常な hints（`{}`、`{"annotations_by_job":{}}`、従来の形）の動きは変えていない
- `tests/pr-state.bats`: 上の 4 種類の崩れた入力が hints のメッセージで弾かれるテストと、空のオブジェクトが通るテストを足した
- 戻し方: この PR の差分を戻す。状態ファイルの形は変えていない
