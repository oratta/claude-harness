# 完了報告だけの子に wait --resolve が返事を送り返さない（#1761）

子の最後の発言の先頭行が `主がこのセッションで次にすること: なし` または `主がすること: なし` で、今回の停止記録・未回答の問い・止まった印・行頭の `止まった理由: ` が無いとき、`stop-judge.sh` はモデルを呼ばず `判断: 問いではない` を返す。

`wait --resolve` は既存の dismiss と共通の処理で停止状態を resumed に戻し、stop_uuid・stop_at を保持する。子への返事も issue への `親の判断:` の投稿も行わないので、待つという返事と完了報告を繰り返さない。停止記録や理由行などがある止まりは従来どおりモデルに判断を渡す。

両先頭行の回帰テストと停止記録・問い・印・理由行の保護を追加し、実際の stop-judge を通す wait --resolve のテストで無送信・無投稿・resumed 復帰を検証する。epic-dispatch.sh の復帰処理とプラグインの版は変更しない。
