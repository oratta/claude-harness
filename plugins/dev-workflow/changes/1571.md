# pr-review-gate: 分けたコメントの親の見出しの行を、種類ごとの要件の行に揃える（#1571）

三表が 65,536 バイトを超えて分けられたとき、spec の要件「コメント長の上限を超える本文は親と部分のコメントに分ける」は「親の 1 行目と見出しの行は分けないときと同じ」と書いていた。一方で、分けない `レビュー三表:` のコメントの定義には `固定 HEAD:` の行が無く、要件「三表の親と部分」は親に `固定 HEAD:` の行を必須にしていた。前者だけを根拠に親を書くと、親に `固定 HEAD:` の行が入らず、次の G が部分の 2 行目と照らす相手を見つけられない（PR #1530 のレビュー指摘 P1-F1・P2-F1）。

- spec（本体とアーカイブ済みの #1249 の delta spec）: 「親のコメント:」の箇条を、1 行目は分けないときと同じにし、続けて要件「三表の親と部分」「順 3 の一覧の親と部分」が種類ごとに定める見出しの行を置く形に直した
- `stages/triage.md` の「レビュアーの要約受領」と `references/roles/gate-runner.md` の補足の段落・段の入力の表: 分けない `レビュー三表:` のコメントの行を、分けるときの親と同じ `固定 HEAD: <40 桁>`・`一周目の区画: <なし | n>`・`補足済み回数:` の 3 行に揃えた
- 分けない三表の読み手は固定 HEAD を `レビュー重量:` のコメントから読むので、行が 1 つ増えても読み手の動きは変わらない
- 戻し方: この PR の差分を戻す
