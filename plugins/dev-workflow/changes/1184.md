# UserPromptSubmit hook: 主が「わからん」と返したら、正本の型で言い直すよう差し込む（#1184）

主が「意味わからん」「説明して」と返しても、同じ言葉のまま説明し直して言い直しが続いていた（親エピック #1176 の調べで、過去 90 日に 9 場面）。主の発言に、説明が伝わっていないことを示す語があるときだけ、正本（`~/.claude/output-styles/readable.md` の節 3）の型で、子の作業の言葉を使わずに言い直すよう促す文を差し込む。

- `scripts/unclear-reply-rephrase.sh` を足し、`hooks/hooks.json` の `UserPromptSubmit` の 2 件目に登録した（1 件目の `prompt-tripwires-refresh.sh` は変えていない。matcher と timeout は付けない）
- 語の一覧はスクリプトの `WORDS` の 1 か所にある（意味わから・意味分から・意味がわから・意味が分から・意味不明・わからん・分からん・解らん・わかんない・分かんない・説明して・読みにくい・読み難い・伝わらない・伝わってない・何言って・なに言って）。複数に当たったら一覧の順で最初の語を示す。逆引用符 3 つのブロック（閉じが無ければ発言の終わりまで）と `>` の引用の行は探さない
- 差し込む文は正本の場所と節を指すだけで、型の中身を写さない。最後に「主の発言が新しい依頼なら、その依頼に答える」を置き、「この関数を説明して」のような誤検出の害を抑える
- 語が無い発言では python3 を起動せずに終わる。壊れた入力・python3 が無い環境でも、無出力・exit 0 で発言を止めない。状態ファイルは持たない
- 受け入れること: 「は？」「どういうこと」「原因がわからない、調べて」は拾わない。新しい依頼の「説明して」「わからん」でも差し込みが出る（1 文、約 500 バイト）
- 常時注入の固定分（rules・CLAUDE.md・output-styles・description）は変えていない
- hooks は聖域（人の承認なしに変えてはならない設定）なので、PR のマージは主が行う
- 戻し方: この PR の差分を戻す（hooks.json のエントリとスクリプトを消す）。後片付けは要らない
