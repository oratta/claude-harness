# pr-review-gate: `usage_view.py --codex-enabled` の出力が `on` でも `off` でもないときは `on` と同じに扱う（#1020）

`stages/review-run.md` の「Codex がオフのとき」は、`usage_view.py --codex-enabled` の出力が `on` か `off` のときの分岐だけを書いていた。`<plugin>` のパス解決の誤りや `python3` 不在で出力が空やエラー文になると、G がオフと推測して Codex を飛ばすか止まるかを独自に決めることになり、usage-account-registry の「読めないときはオンとする」方針と食い違う動きが起こりえた（PR #1003 のゲートの should 指摘）。

- `stages/review-run.md`: 「`on` なら表の既定どおり Codex から試す。」のあとに、出力が `on` でも `off` でもない（コマンドが失敗した）ときは `on` と同じに扱い、その出力を `実行コマンド` の証拠に書く、の 1 文を足した
- `tests/pr-review-gate-skill.bats`: 足した 1 文を段落に持つことを確かめるテストを足した
- 戻し方: この PR の差分を戻す
