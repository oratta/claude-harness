pass/legacy の risk-delegated とその和集合で、必読の `skills/develop/references/epic-delegation.md` が計測から漏れていた。計測パスに Plugin root 相対パスを許し、gate 外の共有正本も inventory と参照検査に含める。増加・欠落・参照欠落・重複排除・非委任 profile への非波及を回帰テストで確認する。
