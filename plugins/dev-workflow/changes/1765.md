# 投稿前の照合表の自己検査と補足前の未被覆ハンク一覧（#1765）

最終の語ごとの照合表そのものを投稿前に既存の review-hit-set.py で検査し、非 0 なら書式を直して再実行する指示を追加した。抜粋、列名変更、零件のプレースホルダ、パスのバッククォートを具体化し、固定 SHA の全文への復元と結果記録を要求する。全ヒット要約も既存契約の最終形で検査する。実行不可を成功扱いしない。

G は固定 diff の全ハンクと全区画の実際の被覆行を比較し、補足前に未被覆のファイルと正確なヘッダーを全件示す。文章だけの他区画への参照や「新規」は被覆に数えない。補足回数と review-incomplete の規則は維持する。意味の判定や区画レビュアーの読む範囲・トークン消費（#1692）は対象外。

## 採用方式と予算の判断

「載せる前の自己検出」を採用した。抜粋から失われた本文は正規化だけでは復元できず、自動補完では実際の食い違いを隠す恐れがあるため、既存の厳密なスクリプトと許容形式を維持した。合成 Git fixture の回帰テストと指示の契約テストを追加している（前任の TDD Red は新規契約2件失敗、Green は preflight 7件成功）。

決める役の承認に従い、投稿前の自己検査指示から、既存の全ヒット要約契約と重複する説明を削除した。四種の書式違反の検出と未被覆ハンクの列挙に必要な追加指示による超過分について、該当プロファイルの予算を圧縮後の実測 bytes に合わせ、余裕枠は追加していない。

`python3 -B tests/gate_reading_budget.py measure .` — exit 0。第2値（UTF-8 bytes）が現予算を超える116行だけ更新した。圧縮で102 bytes減り、claude/review は65,298 bytes（旧予算64,243）。計測ロジック・計測対象・超過しない行は変更していない。この理由は finish の PR 本文にも転記する。
