# epic-dispatch.sh launch の epic 番号が数字でないときの検査を bats に足す（#433）

PR #428 のレビューで見つかった nit 指摘（F5）の follow-up。`plugins/dev-workflow/tests/epic-dispatch.bats` には `route` と `wait` の非数字検査を確かめるテストがあるが、`launch` の `<epic>`（`is_num "$epic"`）と `<child>` を確かめるテストが無く、この検査を落としてもテストが緑のまま通ってしまう状態だった。

- `launch: without orca on PATH nothing is called` の直後に `launch: a non-numeric epic or child is rejected before anything is called` を追加し、epic に `'#400'` を渡したケースと child に `'#11'` を渡したケースの両方で `status -eq 1` と、何も呼ばれない（前者は `output` が空、後者は `STUB_LOG` が空）ことを確かめる
- TDD の確認として、`cmd_launch` の `is_num "$epic"` の行を一時的に外すと追加したテストが red になることを確認してから元に戻した（`epic-dispatch.sh` 自体に差分は無い）
- テスト追加のみで振る舞い不変のため仕様化しない（コード直行）と判定した
