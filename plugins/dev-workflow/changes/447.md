# 版番号を撤去し、変更の記録を PR ごとの別ファイルにする（#447）

`plugin.json` と `.claude-plugin/marketplace.json` から `version` を撤去した。版は Claude Code がマーケットプレイス clone の HEAD の commit SHA から決めるので、マージのたびに利用者へ更新が届く。並行する PR が同じ版の行と `CHANGELOG.md` の先頭を書き換えて衝突し続けていたのが理由。

- 変更の記録は `plugins/<name>/changes/<番号>.md`（記録先の issue 番号、無ければ PR 番号）に 1 PR 1 ファイルで書く。同じ issue の 2 本目の PR は PR 番号を使う。`CHANGELOG.md` は凍結し、追記しない
- 版を上げない。`version` を書くとその値で版が固定され、上げない限り更新が届かなくなる（`tests/marketplace-sync.bats` の S130・S131 が CI で落とす）
- `scripts/prompt-tripwires-refresh.sh` は、セッション途中のプラグイン更新を `plugin.json` の `version` ではなく `CLAUDE_PLUGIN_ROOT`（キャッシュの版名を含むパス）の変化で検知する。旧方式の版番号が状態に残ったセッションは 1 回だけ再注入して移行する

移行作業: 開いている PR は main を取り込み、自分の版の変更を消し、`CHANGELOG.md` への追記を `changes/<番号>.md` に移す。
