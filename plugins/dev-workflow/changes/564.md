# 担当別コンテキスト監査の手渡し接頭辞とプロジェクト別集計を修正（#564）

`subagent-context-audit.sh --by-role` は、手渡し番号付きの `W2:` などを unknown に数え、別プロジェクトの同じ issue / PR 番号を読み直し率の同一グループに混ぜていた。

- description の先頭トークンを `^(W|R1|G|Reviewer)\d*$` で判定し、グループ1を担当名にする。`W2:` / `R12:` / `G3:` / `Reviewer1:` はそれぞれ `W` / `R1` / `G` / `Reviewer`。`R1:` 自体も引き続き `R1`。agentType による decider / Reviewer の優先分類は維持する
- `reread_pct` はトランスクリプトパスのプロジェクト識別子（slug）と description の最も左の `#N` の組でグループ化する。別 slug の同じ番号は混ざらず、同じ slug・番号ならセッションをまたいでも同じグループになる
- python3 を含まない PATH での fail-open（exit 0、`by_role` なし、note は `python3 not found`）と、既定呼び出しの count / first_median / last_median を回帰テストで固定する
- 仕様に、`--by-role` の全体キー・担当別の最終判定にも全文走査の値を使い、部分読みの既定呼び出しと値が僅かにずれうることを明記する
- 観測専用・キャッシュ・既定呼び出しの走査方式と出力形式・起動フック・強制停止は変更していない。version は上げない
