# review-hit-set: バッククォートで囲んだ修正前 SHA を受け付ける（#728）

`scripts/review-hit-set.py` の照合表で、`修正前 SHA:` の値をバッククォートで囲むと、正しい 40 桁の SHA でも契約違反として拒否されていた。

- 値の両側にバッククォートがある場合だけ 1 個ずつ取り除いてから、従来の SHA 検査と照合を行う。囲まない場合と出力・終了コードは同じ
- 片側だけのバッククォート、桁数違い、16 進数でない値は引き続き契約違反として exit 1 で拒否する
- `tests/review-hit-set.bats` に、照合成功時・差分検出時の同等性と、不正な値の拒否を確認する回帰テストを追加した
