# pr-review-gate: 候補探しの --exclude にエピック番号を足し、打ち切り時に子だけ再実行する（#1012）

`stages/triage.md` の候補探しの呼び方を 2 点直した。

- エピックに属する PR では `--exclude <エピック番号>` を足す。エピックの本文に指摘のファイル名が書かれていると、エピック自身が `other` の候補として返り、G が段 C の相手に選べてしまっていた
- 結果に `(15 件で打ち切り。ほかにも一致あり)` が出たパスがあり、エピックに属する PR のときは、そのパスだけ `--epic <番号> --children-only` で 1 回再実行して子の候補を足す。再実行が失敗したら走らせ直さず、打ち切られたパスの指摘は既存 issue に相乗りしない。再実行でも打ち切られたら出た候補だけで振り分ける
- main の spec の要件「候補探しのスクリプトは 1 回だけ走らせ、失敗を候補なしと読まない」も同じ commit で直した
- スクリプト `review-issue-candidates.sh` は変えていない。`develop/SKILL.md` と `dev-workflow-develop` の spec にある同じ欠陥は今回直さない
- 戻し方: この PR の差分を戻す。移行は要らない
