# injection-budget: paths: の型検証と除外の対象を rules に限定する（#293）

`tests/injection-budget.bats` の常時注入の集計が `paths:` を読む部分を直した。

- 行末コメント付きの glob（`- "**" # scope`）はコメントを除いて検査する。`paths: null` などリストでない値は glob 0 件の違反になり、常時注入の合計からも除外しない
- `paths:` の要素は非空の文字列であることを検証する。数値・null・真偽値・空の要素・入れ子を含むリストは 1 件も glob として読まず、違反として常時注入の除外にも使わない（部分抽出しない）。フロー表記の閉じ括弧の後の空白も読める
- `paths:` による除外は rules だけに掛ける。output-styles は `paths:` の有無にかかわらず全文を計上する
- `openspec/specs/always-on-injection-scope` に上記を追記した
