# develop-skill.bats: 日本語のテスト名 4 件を ASCII にして、Bats 1.11 以降の unknown test name を直す（#1340）

`tests/develop-skill.bats` の「delegated reply (#1293): ...」で始まる 4 件は、テスト名に日本語を含んでいた。Bats 1.11 以降は、関数名に変えたテスト名を `printf %q` で引用して照合する。macOS の bash 3.2（UTF-8 ロケール）の `%q` は一部の多バイト文字（例: `任せる`。`段` や絵文字は壊れない）を壊すので、照合が食い違い、`unknown test name` で 4 件が実行されず、「Executed 126 instead of expected 130 tests」で exit 1 になっていた（Bats 1.10.0 はこの引用を通さないので起きない）。

- 4 件のテスト名から日本語を外し、ASCII の英語にした。検査対象の日本語の固定文字列とテスト本体は変えていない
- 確かめたこと: Bats 1.10.0・1.11.0・1.13.0 のどれでも `bats plugins/dev-workflow/tests/develop-skill.bats` が 130 件実行で exit 0
- Bats の版の方針: CI は `ci.yml` の `bats=1.10.0-1` 固定のまま。手元は 3 版のどれでも、このファイルは通る
- 同じ原因で `plugins/cost-ledger/tests/cost-command.bats` の 1 件が Bats 1.11 以降で実行されない件は、別 issue（#1346）で扱う
- 戻し方: この PR の差分を戻す
