# reply auto のテスト fixture を時刻・ホスト環境から独立させる（#1773）

- 曖昧ログ 2 本には同じ固定 timestamp を渡す。fixture の時計が秒境界をまたぐケースを制御し、最終 timestamp の一致と通常送信への分岐を検査する
- `FORCE_TOKENS=0` は会話量 100000 で検査し、既定閾値では通常送信、0 では起動し直しになることを両方の送信者で確かめる
- missing-log の検査前から `CLAUDE_PROJECTS_DIR` をテスト用ディレクトリに固定し、ホストの会話ログの有無に依存させない
- 製品の判定処理とバージョンは変更しない
