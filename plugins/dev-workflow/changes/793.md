# dev-workflow のコマンドが、自分と同じ版のファイルを読む（#793）

コマンド本文の Bash 実行には環境変数 `CLAUDE_PLUGIN_ROOT` が渡らない。探索ループの先頭候補 `"${CLAUDE_PLUGIN_ROOT:+${CLAUDE_PLUGIN_ROOT}/...}"` は、Claude Code が本文の読み込み時に内側だけを絶対パスへ置換し、外側の `:+` が残るため、実行時に空になって marketplace の自動更新コピー（版の違う旧コピー）が選ばれていた。

- `commands/memory-refresh.md`・`commands/develop.md`（2 か所）・`commands/ci-watch.md` の先頭候補を、#774（cost.md）と同じ `"${CLAUDE_PLUGIN_ROOT}/..."` に直した。置換されない環境では、memory-refresh・develop は変数が空になってルート直下の `/skills/...` を指し、そこに同名ファイルがあれば誤って選ぶ（#808 で直した）。ci-watch は先頭候補が空文字列になって `[ -n "$dir" ]` で飛ばされ、後続の候補に落ちる
- #523 で `:-` から `:+` に直した形は外側が残るため、この形に更新した（523.md の記録は当時のまま）
- `tests/command-plugin-root.bats` に `plugins/*/commands/*.md` の `CLAUDE_PLUGIN_ROOT:+` が 0 件であることの検査を足した（3 プラグイン共通）
- `statusline/commands/setup.md` の `${CLAUDE_PLUGIN_ROOT:-}` は `:+` ではないため今回は触っていない
- 戻し方: 該当行を `:+` の形に戻す
