# 主への依頼の書き方を、項目を 4 つのまとまりに分けた形と使う場所の表に直す（#1671）

主に頼みごとをするときの正本（`output-styles/readable.md` の節 3）は、質問に「OK すると何が起きるか」を埋め込み Yes か No で答える形で、目的・緊急度・答えを待って止まっている作業の欄が無く、どこで出しても同じ長さだった。2026-11-18 にオーナーと決めた形（https://github.com/oratta/claude-harness/issues/1671 ）を正本にした。

- `output-styles/readable.md` の節 3: 6 段の順（質問 → 主に聞く理由 → いま困っていること → 推奨と根拠 → 受け入れるリスク → 答え方）を、項目（題名・アクション／目的・詳細・論点・推奨と根拠・リスク／緊急度・ブロック／アクションに付けるリンク）を 4 つのまとまりに分けた表と、使う場所 5 つ（対話のセッション・チャットで 1 件ずつ出す依頼・チャットで何件かまとめて出す一覧・依頼を並べる画面の行と詳細）の表に置き換えた。主に聞く理由の 3 つと論点の定義は表の前に残し、論点の有無は論点の項目に書く。1 行目は題名（依頼の形。質問にしない）、2 行目は `アクション:` の行にした。論点なしの依頼を短く省くのは対話のセッションだけ（4 行、目的を足せば 5 行）で、チャットの 1 件ずつの依頼と画面の詳細では論点なしでも全部の項目を書く。例 3 つを新しい形に書き直した
- `rules/communication-style.md` の 3: 正本と食い違わない要点に書き直した（使う場所の表と例は正本にあると案内する）
- pr-review-gate の `declarations.md`・`stages/hold.md`・`stages/pass.md`: 旧い型の語（`答え方`・`3〜4 行`・`OK すると何が起きるかを中身で書いた質問`）を消し、論点なしの依頼の行数は正本の節 3 を指す形にした
- 聖域に触れる: 常時注入の予算（`tests/injection-budget.txt`）を 42300 → 43300 に上げた。節 3 に 2 つの表（まとまりの表と使う場所の表）を足した分で 965 バイト増え、旧い 6 段の説明を消した分と前置き・例を詰めた分では収まらなかったため。主の承認: https://github.com/oratta/claude-harness/issues/1671#issuecomment-6967017151
- 予算を詰めるため、正本の節 3 の「ほかの決まり」から「この文書だけを読んで答えられる状態にする」を外した（同じ趣旨が readable.md の冒頭の段落にある。戻すと 43300 を超える）。短い版の「他の資料を見に行かないと判断できない書き方はしない」と「読み手の側にしかない情報」は、常時注入に残す指示の目印（`tests/always-on-injection-scope.bats`）なので残した
- 受け入れること: 親と channel の発言の文面と番号検査の hook は、同じ PR の後続の変更が入るまで旧い 1 行目の形のまま
- 戻し方: この PR の差分を戻す。記録の書式は変えていないので移行は要らない
