# pr-review-gate: 段と条件ごとに読む本文を分ける（#1687、親 #1682）

G が前提確認・照合・合格・保留のどの段でも無関係な本文まで読む状態を改めた。共通の Gate Result・経路・停止の規則は gate-runner に残し、段の入口から条件の成立時に詳細へ接続する。宣言・return・Status・コマンド・停止条件・守備範囲は保存する。develop/SKILL.md と関連手順書の変更は移動した節への参照の付け替えに限る。

Codex の phase gate は起動指示の `レビュー経路: adapter` と `段:` から4段の正本を選ぶ。前の Gate Result と引用内の段は選択に使わない。phase review は既存の正本集合を保つ。モデルの起動は計測・検査に不要。

## 残した分岐と検査の限界

従来経路・行無しの一括、Codexオフ／不可／light、区画なし、補足1回、持ち越しの各exit、真正性4形、issue承認・論点なし、各Statusのreturnを残した。現行の呼出元を廃止できる証拠が無いためであり、今回の段分けを理由に削っていない。

文言checkerは全体から消えた規則を拾う。別段に移しても通ること、全体削除で落ちることを実checkerのファイルfixtureで確認した。参照なしで別段にだけ残る規則、必要な文と逆指示が併存する入力は文言検査を通ることも明示した。量の予算・条件と到達の関係テスト・意味のレビューと混同しない。

予算は正常・境界ちょうど・予算+1バイト・1.1倍超・不在・未知／欠落／重複profile・不正な数値・条件詳細の増加を検査する。実生成promptの正本集合・本文・sha256を検査し、欠落・余分・重複・本文改変・hash不一致を拒否するfixtureも通した。同じ字数の本文入替や自然文の誤条件は予算だけで保証しない。既存 injection-budget は変更していない。gate-reading-budget.txt の全 156 profile は、ゲート一周目の修正（移動で欠けた G の節・停止条件・参照の戻し）で読む本文が増えたため、修正後の実測ちょうど（1.0倍）に取り直した（例: claude/prepare 41,368→41,440、claude/triage 47,567→47,838、claude/pass 65,114→65,210、claude/hold 37,045→37,196 バイト）。検査を緩めて合わせていない。 develop-startup-budget.txt の SKILL.md 枠だけは94,916から95,075バイトへ更新した。必要な参照先への付け替えで実測が95,056バイトになり、ゲート一周目の修正で移した詳細への参照（carryover.md と hold.md への分け書き等）を足して95,075バイトになったためで、規則本文の削除や検査の緩和で合わせず、実測ちょうど（1.0倍）に置いた。他の起動時の枠は変えていない。 Wの段別予算も実測に合わせ、spec 38,514→38,522、implement 26,001→26,008、finish 42,181→31,076バイトへ更新した。前2つは参照先の付け替えによる8／7バイトの増加、finishは宣言の条件付き詳細の切り出しで読込が減ったための引き下げで、いずれも実測の1.0倍。

## 検査

検査コマンドは `.github/workflows/ci.yml`（pull_request / push）の shellcheck / bats shard から収集した。セットアップのapt-get等は検査として実行しない。全体テストも今回の明示依頼に従い手元で実行する。

結果は最終の実装returnと #1687 の実装コメントを参照。Claude呼出禁止のため `./scripts/lint.sh` と `claude plugin validate` は未実行で、完全なlintを合格扱いしない。shellcheck部分のみを実行する。画面確認は不要。

関係テストの探索: `rg -l 'pr-review-gate/(stages/|declarations)|roles/gate-runner.md' plugins/dev-workflow/tests tests --glob '*.bats'`。T1・T2・T3・新しい予算検査に加え、指定の全体テスト・auto-merge workflow invariants・shellcheck・OpenSpec strict・diff --checkを実施し、各exit codeをreturnに残す。
