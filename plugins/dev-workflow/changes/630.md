# 213.md の配備済みリポへの伝播方針を README と揃える（#630）

`changes/213.md` は配備済みリポへの伝播を「テンプレ本体の改修ではないので必須ではない」と書いていたが、
テンプレ README の「配備済みリポ一覧」は、テンプレ改修時に配備先の記録にある全リポへの展開を求めており、
`staging-smoke.yml` の追加もその対象に入る。どちらを読むかで伝播するかどうかの判断が逆になっていた。

- `changes/213.md` の該当段落を、配備先の記録（個人版が入っていればその展開の記録、無ければ利用者自身の記録）を確認し、
  `staging-smoke.yml` は staging を持つリポへ、deny は各リポの既存設定を確認して不足分を配る、という書き方に置き換えた。
- #1129 で個人版に移った `docs/auto-merge-deployments.md` への参照を外した。
- README の「配備済みリポ一覧」節は手順 6・7 と矛盾しないため変更していない（具体的なリポ名も書かない方針のまま）。

配備先ごとの確認と記録は個人版の oratta/claude-harness-oratta#7 で扱う。
