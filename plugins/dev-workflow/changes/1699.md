# develop: エピックの参照検査の表記変種を補う（#1699）

場面ごとの手順書検査で、親の手順を別の表記で子に読ませる指示と、箇条書きで通常進行に戻したマージ待ちの本文を検出する。規範本文と注入量の予算は変えていない。

- 子から親を読む指示は、全角数字・「先に読む」・複数の手順番号・手順名のかぎ括弧も検出する。
- epic-loop.md の「マージ待ちの子」は箇条書きの接頭辞が付いていても検出する。
- epic-stop.md では「references/epic-loop.md『主への報告』を先に読む」指示を必須にする。一般の文章規則への参照だけではエピック固有の報告規則を読む経路を確認できないため、代替として扱わない。

実ファイルの一時コピーに各表記を加える変異と、報告の参照指示だけを消す変異の回帰テストを追加した。戻す場合はこの変更の差分を戻す。保存済み記録の移行は要らない。
