# develop-idle-compaction: apply が共有 info/exclude へ設定ファイルを足し、完了した子の worktree が dirty にならないようにする（#1471）

develop は開始時に `develop-idle-compaction.py --apply` で worktree の `.claude/settings.local.json` を書くが、そのファイルは git の無視対象に入っておらず、`git status --porcelain` に `??` で出ていた。`epic-dispatch.sh reap` は porcelain が空でなければ `kept <N> dirty` を返すので、マージ済みの子の worktree が片付かなかった（エピック #1237 の子 #1235・#1236）。

- `scripts/develop-idle-compaction.py --apply`: 設定ファイルを書く前に、`git rev-parse --git-common-dir` の下の `info/exclude` へ `.claude/settings.local.json` を 1 行足す。完全一致の行が既にあれば足さない。exclude を書けないときは設定ファイルも書かず exit 1
- `--check` と、false 済みで何も書かない `--apply` は exclude に触れない。`.gitignore` と追跡状態は変えない（追跡済みのファイルは追跡のまま）
- `skills/develop/references/reply-after-idle.md`: 継続適用の範囲に、共有 `info/exclude` への 1 行の追記を明記した
- `reap` 側は変えていない。別の未コミットファイルがある子は今までどおり `kept <N> dirty` で残る
- 受け入れること: 既に false で exclude に無い worktree は `--apply` が呼ばれないので直らない（新しい develop 開始のみ直る）。exclude は同じリポジトリの全 worktree に効く
- 戻し方: この PR の差分を戻す。足された 1 行は各リポジトリの `.git/info/exclude`（common dir）から手で消す
