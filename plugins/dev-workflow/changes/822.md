# git-destructive-guard: Unicode エスケープを含む入力のテストを足す（#822）

破壊的 git 操作を止める hook のテストに、JSON の `\uXXXX` エスケープを生で渡すケースを足した。これまでの「unicode-escaped payload」テストは名前に反して素の JSON を渡しており、エスケープの経路は検査されていなかった。hook 本体は変えていない（現状で全ケースが期待どおり判定される）。

- `tests/git-destructive-guard.bats` に、生の JSON を渡す補助関数 `raw_command` と 5 ケースを足し、名前だけのテストを置き換えた
- ケース: エスケープされた `--hard` と `git` の 1 文字、`\u000a` による改行区切り、サロゲートペアを前置した `&&` は ask になる。引用符内の日本語エスケープは無出力
