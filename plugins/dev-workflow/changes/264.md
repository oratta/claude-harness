# 背景タスクを残したまま終わろうとするサブエージェントの停止を SubagentStop hook で拒否する（#264）

待ち方の正本 `references/subagent-waiting.md` は「完了を待つ目的でターンを終えてはならない」と定めているが、守らせていたのは指示書の文言検査（`tests/subagent-waiting.bats`）だけで、禁止語を使わずに言い換えた違反は素通りしていた。名前付き background サブエージェントは自分の背景タスクの完了では再起動されないので、違反すると親が SendMessage を送るまで止まる。実測 (e) では、拒否しないと背景タスクの完了から 60 秒たってもサブエージェントは再開しなかった（実測記録 https://github.com/oratta/claude-harness/issues/264#issuecomment-5851334276 ）。

- `scripts/subagent-stop-guard.sh` を `hooks/hooks.json` の `SubagentStop` に登録した。停止しようとしているサブエージェント自身のトランスクリプトから、Bash の tool_result 本文 `Command running in background with ID: <id>.` で自分が背景起動したタスクの ID を集め、SubagentStop の payload `background_tasks` にその ID が `status: "running"` で残っていれば `{"decision":"block","reason":…}` で停止を拒否する。`background_tasks` は親セッション全体の台帳なので、自分の起動記録が無い ID（本体の `ci-watch.sh wait` など）は数えない
- 拒否理由には、未完了のタスク ID と出力ファイルのパス・前景の待ちループで完了を確認すること・上限まで待ったか結果を使わないなら TaskStop で停止してから終えること・正本の絶対パス・拒否の回数（例 `1/3`）を入れる。待ち値や完了マーカーの雛形は入れない
- 拒否は同じ `session_id` と `agent_id` の組に 3 回まで（正本の総待ちの上限回数と同じ。定数の一致は bats で突き合わせる）。回数は `${TMPDIR:-/tmp}/dev-workflow-stop-guard/<session_id>-<agent_id>.count` に数え、上限を超えて通すときに消す。`stop_hook_active` は判定に使わない（1 回拒否したあとは常に真になるため）
- 判定できないときは通す。`agent_id` が無い（メインセッション）・`DEV_WORKFLOW_STOP_GUARD=off`・python3 が無い・payload が壊れているときは何も出さない。`background_tasks` が無い・トランスクリプトが見つからない・カウンタが作れないか読めないときは stderr に 1 行出して通す
- 対象トランスクリプトは payload の `agent_transcript_path` を使い、それが無いか存在しなければ `context-tripwire.sh` と同じ導出と上限付きの探索に落とす。探索は `context-tripwire.sh` と共通化せず hook 側に複製した
- 正本 `references/subagent-waiting.md` に、待ちをやめて return する前（上限到達・結果の放棄）に TaskStop で背景タスクを停止する規則と、実行時の検査の節（見るもの・止めるもの・通すもの・守らないもの・後詰めとしての回数上限・全解除）を足した。指示書（W / R1 / G・pr-review-gate の SKILL.md）には再掲していない
- `tests/subagent-stop-guard.bats`（34 件）を足した。言い換えた違反を複製したプラグインの `worker.md` に差し込んで既存の `subagent-waiting.bats` が exit 0 で素通りすることと、同じ違反どおりのトランスクリプトを hook が拒否することを対で検査する。実セッションの payload を fixture にして形式をピン留めし、5MB のトランスクリプトで 200ms 未満（3 回の最良値）も見る
- 守らないもの: Bash の中で `nohup … &` や `setsid` で起こしたプロセス・`codex-companion.mjs` の job・正本と食い違う待ち値や完了シグナル・理由を無視して上限回数まで停止を繰り返したサブエージェント・payload に `background_tasks` を持たない版の Claude Code
- この issue に残っていた宿題 4 件は 3 本に分けて起票した: 正本の手順 2・3 の実行時検査と `$RANDOM` 版の実測（#557）、雛形を抽出して実行する検査の横展開（#558）、companion 経路のジョブ同一性の検査が要るかの評価（#559）
