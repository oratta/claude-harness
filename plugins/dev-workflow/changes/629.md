## 照合の方法と限界

2026-10-30 に次の公式資料を確認した。

- https://code.claude.com/docs/en/permissions#wildcard-patterns
- https://code.claude.com/docs/en/permissions#bash
- https://code.claude.com/docs/en/cli-reference

**公式仕様の再現で検証、実測は未。公式仕様に基づく照合の再現、実マッチャー未実測。**
公開 CLI reference に任意の Bash 入力をオフラインで permission 判定する専用コマンドは確認できなかった。
`claude` および `claude -p` は起動していない。再現結果を製品の実測や permission 全体での許可の保証とは扱わない。

Bats 内の Python 標準ライブラリで、全体一致・`*` の任意文字列・末尾 `:*` の正規化・
唯一の末尾 ` *` の引数無し一致を再現する。正規表現の他のメタ文字は escape する。
公式例を基にしたモデル対照 10 件と、旧 7 件の固定配列／実際の JSON 配列によるコマンド 50 件の前後比較を行う。
対象は空白で引数を区切った単純コマンド。引用符・タブ・変数展開・URL・オプション値の内部
（列挙した値付き lease を除く）・複合 shell・wrapper・global Git オプション・短いオプションの
結合形や省略形・`+` refspec は対象外。オプション値 `x:main` への一致等もありうるため、全面封鎖を主張しない。

| 例 | 旧 7 件 | 追加後 25 件（いずれも再現モデル） |
|---|---|---|
| `git push origin feature --force` / `git push origin --no-verify feature` | 非一致 | 一致 |
| `git push origin HEAD:main` / `git push origin HEAD:refs/heads/master --porcelain` | 非一致 | 一致 |
| `git push origin feature:main other:feature/bar` / `git push -u origin HEAD:master` | 非一致 | 一致 |
| `git push origin feature --force-with-lease=refs/heads/feature:abc123` | 非一致 | 一致 |
| `git push origin feature/foo` / `git push -u origin feature/foo` | 非一致 | 非一致 |
| `git push origin feature:main-fix` / `git push origin HEAD:master-fix` | 非一致 | 非一致 |
| `git push origin main` / `gh pr merge 123` / 単独オプションの前置形 | 一致 | 一致 |

`*:main*` / `*:master*` は似た名前の宛先を拒否するため棄却した。
`--force*` / `-f*` / `--force-with-lease*` / `--no-verify*` も別の引数への部分一致を増やすため棄却した。
複数 wildcard の末尾 ` *` は引数無しの形を含まないので、末尾と空白区切りの後続引数ありを対にした。
