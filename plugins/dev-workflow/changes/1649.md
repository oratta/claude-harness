# レビューの投げ先を一時ディレクトリへの書き込みが要るテスト全般で選ぶ（#1649）

読み取り専用レビュアーで再実行できないテストは bats に限らない。再実行に書き込める一時ディレクトリが要るテストを、Claude のレビュアーに回す条件にした。

- `references/codex-develop.md` と `skills/pr-review-gate/stages/reviewer-brief.md` 2-1: bats に加えて、`mktemp` を使う bash テスト、`BATS_TMPDIR` / `TMPDIR` に書くテスト、`pytest` のように一時ファイルを書くテストを例に挙げた。bats を含むレビューも引き続き Claude のレビュアーに回す
- Claude のレビュアーへ書き込める一時ディレクトリを `TMPDIR` / `BATS_TMPDIR` として渡す手順、同じ固定 HEAD で取り直す扱い（補足済み回数を増やさず、`review-incomplete` で止めない）、read-only role に `writableRoots` を与えない規則は据え置いた
- `tests/develop-adapter-review-routing.bats`: 両段落の対象が一時ディレクトリへの書き込みが要るテスト全般であることと、bats の扱い・既存の手順が残ることを検査する
- 戻し方: この変更の差分を戻す。状態や設定の移行は要らない
