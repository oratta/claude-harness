# 警告 hook の matcher に resume を足し、再開したセッションでも警告する（#789）

チーム機能が無効なときに始めたセッションを、設定が有効に戻った後で `claude --resume` で再開すると、SessionStart の種類が `resume` になり、`team-mode-warning.sh` が動かず警告が出なかった。別の PC で再開した場合も同じ。

- `hooks/hooks.json` の `team-mode-warning.sh` のエントリだけ、matcher を `startup|resume|clear|compact` にした。`session-tripwires.sh` のエントリは変えていない（あちらは注入済みテキストが resume で残るため重複を避ける。この警告は有効なときしか出ないので当てはまらない）
- `dev-workflow-role-agent-types` の Scenario「hook に登録されている」と `tests/team-mode-warning.bats` の比較値を同じ値に揃えた
