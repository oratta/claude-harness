# 承認記録の投稿者名を人間の判別材料にしない（#242）

- `rules/destructive-git-guard.md`: 「承認の記録と確認」を要点だけ足した（投稿者名を承認の根拠にしない・エージェントの記録には `記録者: エージェント（<名前>）` を書く）。常時読み込みの合計がサイズ上限を超えるため、手順と実測は `plugins/dev-workflow/references/approval-provenance.md` に移した（これが詳細の正本）
- `pr-review-gate` の `stages/authenticity.md`: author の一致を必要条件に下げ、リンク先に `記録者: エージェント` の行が無いことの実測を足した。`stages/pass.md` の `主の回答: 許容` の追記と `stages/carryover.md` の引き継ぎの追記に `記録者:` 行を足し、再確認に「エージェントの記録でないこと」を足した
- 注入予算の値は変えない
