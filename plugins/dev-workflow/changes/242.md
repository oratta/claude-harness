# 承認記録の投稿者名を人間の判別材料にしない（#242）

- `rules/destructive-git-guard.md`: 「承認の記録と確認」を足した。GitHub の投稿者名（`oratta` / `OWNER`）は人間かエージェントかの判別材料にならず承認確認の根拠にしないこと、主の判断を記録するエージェントは `記録者: エージェント（<名前>）` の行と出どころを書くこと、この表記のある記録と表記の無い伝聞の承認記録はどちらも承認済みとみなさず主本人の発言を確かめられなければ主に確認を上げること。この 3 点の正本はここ 1 か所
- `pr-review-gate` の `stages/pass.md`: 真正性確認で author の一致を必要条件に下げ、リンク先に `記録者: エージェント` の行が無いことの実測を足した。`主の回答: 許容` の追記に `記録者:` 行を足す
- `pr-review-gate` の `stages/hold.md`: 3-c の引き継ぎの追記にも `記録者:` 行を足し、再確認の中身に「エージェントの記録でないこと」を足した
- 注入予算は据え置き（実測が予算内）
