# openspec: エピックの親が待ちをやめる条件の仕様を references/epic.md の手順に合わせる（#1263）

`openspec/specs/dev-workflow-develop/spec.md` の要件「Orca 経路の本体は印が付いた子のワークスペースを片付ける」に、「片付け待ちの `wait` が `timeout` で終わったら、残っている子の番号を報告して待ちをやめる（SHALL）」という古い規則が残っていた。PR #1258 で `references/epic.md` は条件付きの手順に改めており、仕様がそれと食い違っていた。

- 要件の箇条を、`timeout` で終わっただけでは待ちをやめない（MUST NOT）、やめてよいのは `references/epic.md` の「待ちをやめてよい条件」(a)〜(e) のときだけ、という規定に直した
- (a)〜(d) でやめる直前に、開いた子に主の返事待ちで止まった子が無いことを `wait --watch-stopped`・`pending-owner`・`needs-approval` ラベルで確かめることを規定した
- Scenario「Orca 経路に片付けの手順が書かれている」の THEN を、同じ内容に直した
- プラグインの動作（スクリプト・指示書）は変えていない。仕様の文言だけの変更
