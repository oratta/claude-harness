# dev-workflow: Claude / Codex の更新時に互換性を確かめて追従する手順を docs に足す（#325）

Claude Code や Codex CLI の版が上がったときに、develop の手順が両方で動き続けることを確かめる手順を `plugins/dev-workflow/docs/provider-compat-update.md` に足した。エピック genetta-inc/flatmate#698 の子。

- 共通ルールと provider 固有部分の責任範囲、更新時に確かめる代表ワークフロー、確認結果の記録の形式、失敗時の行き先、不要になった補助処理の見直し手順を 1 本の文書にした
- 一覧表（`docs/codex-delegation-inventory.md`）と各正本は複製せず参照する。`references/codex-develop.md` と常時注入の対象には足していない（起動ごとの読み込み量は変わらない）
- 新しい文書は Codex の呼び出しの語を含むので、一覧表 `docs/codex-delegation-inventory.md` に「言及のみ」の行を 1 行足した（#324 の突き合わせの検査が求める）
- 新しいスクリプトや検査は作っていない。自動で更新を検知して追従することの保証もしない
