# 個人版の部品を個人版のリポジトリへ移し、公開版から消す（#1129）

`docs/public-private-split.md` の仕分けの表で「個人版」に決めた部品を、個人版のリポジトリ `oratta/claude-harness-oratta`（marketplace の名前は `claude-harness-oratta`）へ写し、公開版から消した。写し元の公開版の commit は `647caaf088409abc68cc8c45587b1310e31e34f7`。同じ issue の前半の記録（保留の 5 行の確定）は `changes/1129.md` にあり、ここは PR #1218 の分。

移した部品と移した先（個人版のリポジトリの中のパス）:

- `rules/plugin-editing.md` → `rules/plugin-editing.md`
- プラグイン `weekly-report`・`daily-report` → `plugins/weekly-report/`・`plugins/daily-report/`（同じ名前。`changes/`・`tests/` を含む丸ごと）
- `plugins/dev-workflow/docs/auto-merge-deployments.md` → `docs/auto-merge-deployments.md`
- capability-registry の個人版の部品 → プラグイン `capability-registry-oratta`（記録は `plugins/capability-registry/changes/1129.md`）
- 仕様 `openspec/specs/` の `weekly-report-jsonl-direct`・`report-command-hygiene`・`report-noninteractive-mode`・`capability-registry-fmtoken` → 個人版の `openspec/specs/` の同名（公開版からは archive の直前に消す）

公開版で消したもの・直したもの:

- `.claude-plugin/marketplace.json` の `weekly-report`・`daily-report` の項目と bundle `all` の 2 行
- `references/self-verification.md` の自己検証の対象から daily-report・weekly-report を外した（対象は 4 スキル）。README の参照元の説明も合わせた
- `templates/auto-merge/README.md` の展開の記録への参照を、個人版を使うときはそちらを見る書き方にした
- ルート直下の README のプラグイン一覧から 2 行を消し、CONTRIBUTING の Skill の例、CLAUDE.md・AGENTS.md の LLM ログの節の skill の例と関連の行、`docs/worktree-recovery.md` の冒頭を、個人版の部品の名前を出さないか「個人版が入っていれば」の書き方にした
- `docs/public-private-split.md`: 仕分けの表から移した 8 行を外し、新しい節「個人版に移した部品」（部品・移した先・写し元の commit）に移した
- `tests/injection-budget.txt`: 常時注入の実測が 41626 バイトから 38118 バイトに減った（`rules/plugin-editing.md` の 2226 バイトと、2 つのプラグインのスキル・エージェント・コマンドの description）ので、予算を 43506 から 40023（実測 + 約 5%）に下げた

検査: `tests/public-private-split.bats` が節「個人版に移した部品」の表からパスと見出しを読み、公開版の `git ls-files` に無いこと・`marketplace.json` の `plugins[]` と bundle に無いこと・SKILL.md に見出しが無いことを確かめる。公開版に個人版の固有名が残っていないことは、個人版の `scripts/check-public-leak.sh <公開版の作業ツリー>` で確かめる。

オーナーの切り替えの手順（各 PC で、公開版のこの PR をマージする前に）:

1. `/plugin marketplace add oratta/claude-harness-oratta`
2. 個人版の `weekly-report`・`daily-report`・`capability-registry-oratta` を install する
3. 公開版の `weekly-report@oratta-claude-harness`・`daily-report@oratta-claude-harness` を uninstall する
4. `~/.claude/rules/plugin-editing.md` を `~/.claude/plugins/marketplaces/claude-harness-oratta/rules/plugin-editing.md` への symlink に張り替える
5. `/reload-plugins`

全 PC が済んでからこの PR をマージする。先に公開版から消すと、`/weekly-report` の定期実行が止まり、`scripts/sync.sh` が `~/.claude/rules/plugin-editing.md` を壊れた symlink として消す。
