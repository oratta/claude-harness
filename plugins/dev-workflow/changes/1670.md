# エピックの子が毎ターンの状態と入力情報を記録する（#1670）

別セッション方式（Orca・tmux）の子が、通常ターンの最後の非空行に `状態: <主の返事待ち|作業報告|完了> — <中身>` を書く。Stop フックは欠落・不正を修正するまで終了を拒否し、正しい状態を既存の子ごとの JSON に保存する。

- UserPromptSubmit で入力の送り手（owner / parent / startup）・受付時刻・セッション・世代を `turn_input` に記録し、新しい通常入力と同時に `turn_state` を無効にする。Stop は同じ世代・セッション・ログ境界を照合し、古い発言で新しい入力の状態を上書きしない。
- 既存の番号・URL 検査を共通の Stop 入口から先に実行し、拒否された発言を終了状態として公開しない。声かけ予約文の往復は元のターン情報を保つ。対象外のセッションでは既存の Stop の振る舞いを保つ。
- 子の手順に毎ターンの状態行を記し、依存待ちの判定は旧末尾形式と状態行の直前の停止理由を両方扱う。
- 新しいフックの入口を `.github/workflows/auto-merge.yml` の SACRED に追加し、接続・世代競合・保存失敗・既存 Stop・依存待ちの互換性をテストする。
- OpenSpec change `epic-child-turn-state` を archive し、現行仕様へ反映した。

この変更は子の状態記録と依存待ちの互換対応まで。記録を読む親の判断・送信抑止・起動し直しは #1744、時間による知らせは #1745 で扱う。送り手の分類は権限の証明ではなく、状態行の意味と実作業の一致は検査しない。既存 JSON の任意拡張なので移行は不要。戻すときは本 PR を revert する。version は上げない。
