# #1596 軽い通し方の無関係な CI 失敗で判断を保持する

- 軽い通し方の `ci-fail` から起きた新しい spec 段 W は、通常の仕様化判断を投稿し直す前に、共有手順の 2 条件で失敗ログと PR 差分の関係を確認する。
- 無関係なら判断再投稿・artifact 作成・修正・push・ラベル操作へ進まず、チェック名と根拠を返す。最新の軽い判断を保持し、本体が既存の `next --unrelated <チェック名> --after-fix` を使う。
- 関係あり・判断不能・競合では従来の通常復帰へ進む。仕様化する場合の R1 の APPROVE、テスト作成、既存 W の implement 再開と見張りの続行は維持する。
- decision-criteria・worker/spec・ci-watch の接続と、判断投稿前の確認・無関係時の早期 return を関係テストで確かめる。
