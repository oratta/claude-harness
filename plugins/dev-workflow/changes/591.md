# チーム機能が有効なまま develop を回すと、セッション開始時に警告する（#591）

チーム機能（環境変数 `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`）が有効だと、名前付きで起こした担当が teammate として起動し、`subagent_type` の道具制限・本文が無視される（#330）。develop は W / G を名前付きで起こすので、設定が戻ったり別の PC で有効だったりしても気づけなかった。

- `scripts/team-mode-warning.sh` を足し、`hooks/hooks.json` の SessionStart（`startup|clear|compact`）に別エントリで登録した。値が有効なとき、`systemMessage`（利用者に表示）と `additionalContext`（モデルに伝える）を含む JSON を 1 件出す。未設定・空・`0`・`false`（大文字小文字は区別しない）では何も出さない。それ以外は有効とみなして警告する。常に exit 0 でセッション開始は止めない
- 警告は有効なときだけ出るので、常時注入の固定分は増えず、`tests/injection-budget.txt` は動かしていない
- `tests/team-mode-warning.bats` に 7 件足して固定した
- 仕様は `dev-workflow-role-agent-types` に要件を 1 つ足す（change: `team-mode-warning`）
