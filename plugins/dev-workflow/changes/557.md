## `$RANDOM` の実測と結論

手順 1 の `nonce="${base#codex-}"` だけを `nonce="$(printf '%016d' "$RANDOM")"` に替え、同じブロックを 10 個連結した `random-driver.sh` を各シェルの 1 プロセスで実行した。16 文字に整えるのは長さ検査による失敗と重複検査を分けるため。ディレクトリの生成と prompt の保存は元の手順のまま。実測スクリプトが一時コピーと driver を生成・削除する。

コマンド: `TMPDIR=<tmp> /bin/sh <tmp>/random-driver.sh`、`TMPDIR=<tmp> /bin/bash <tmp>/random-driver.sh`、`TMPDIR=<tmp> /bin/zsh <tmp>/random-driver.sh`。

出力（`nonce=` の値を列挙）:

- sh: `0000000000027414 0000000000012393 0000000000030140 0000000000015119 0000000000017844 0000000000019662 0000000000004641 0000000000022387 0000000000007366 0000000000010092`、exit 0、unique=10/10。
- bash 3.2.57: `0000000000029173 0000000000014152 0000000000031899 0000000000017786 0000000000003674 0000000000005491 0000000000007308 0000000000025964 0000000000028690 0000000000030507`、exit 0、unique=10/10。
- zsh 5.9: `0000000000021175` が 10 回、exit 0、unique=1/10。

既存の「同一プロセスで 10 回」の bats もコピーの `$RANDOM` 版に対して実行した:

```text
bats --filter 'step 1 template (yields|uses)' <copy>/tests/subagent-waiting.bats
not ok 1 step 1 template yields a distinct 16+ char alphanumeric nonce on every call in one process
# hint: 同一プロセス内の複数回呼び出しで nonce が重複した（zsh）
not ok 2 step 1 template uses the exclusively created directory name as its nonce
# hint: nonce must come from the exclusively created directory: nonce=0000000000011234 dir=.../codex-277k9Ad79c7wb9Ft
exit=1
```

正本の過去の実測（zsh は同値、sh / bash 3.2.57 は別値）と一致した。**結論: `$RANDOM` への退行の検出を実行時検査に移す。** 既存の zsh の重複検査を維持し、生成したディレクトリ名の suffix と nonce の一致を調べる実行時検査を追加した。これにより zsh のない環境でも、乱数を nonce にする変更を sh で検出できる（衝突確率には依存しない）。既存の文言検査は排他生成の方針と禁止例の説明を守る補助として残す。
