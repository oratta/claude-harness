- 候補の順を `CLAUDE_PLUGIN_ROOT` → `~/.claude/plugins/marketplaces/oratta-claude-harness/plugins/dev-workflow`（固定）→ marketplaces の glob → installed の glob に変えた。glob は固定候補が無い環境の最後の手段として残す。#955 の nullglob 退避は変えない
- `openspec/specs/dev-workflow-issue-entry` の issueify 探索順の要件を、同じ順に直した（change `align-plugin-search-order-1480`）
- `tests/develop-startup-budget.txt` の `commands/develop.md` を 11176 → 11366 に上げた（固定候補 2 行ぶん）
- 検査: `plugins/dev-workflow/tests/command-search-zsh.bats` に、`aaa-stale` と `oratta-claude-harness` を並べた HOME で候補の順を確かめるケースを足した（bash は常に、zsh は有るときだけ）
- 戻し方: 各文書の固定候補 1 行と、足したテストを消す
