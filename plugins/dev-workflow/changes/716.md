# hooks.json の `${CLAUDE_PLUGIN_ROOT}` を引用符で囲み、lint.sh に公式の検証を足す（#716）

`hooks/hooks.json` の 6 つの command（`session-tripwires.sh` / `prompt-tripwires-refresh.sh` / `agent-model-guard.sh` / `context-tripwire.sh` ×2 / `subagent-stop-guard.sh`）を、`${CLAUDE_PLUGIN_ROOT}` を含むパス全体を二重引用符で囲んだ形（`"\"${CLAUDE_PLUGIN_ROOT}/scripts/<name>.sh\""`）にした。`claude plugin validate` が「引用符なし」と警告していたもので、展開後のパスに空白があるとコマンドが複数の語に割れて hook が起動しない。変えたのは引用符だけで、並び・timeout・matcher は変えていない。

- `tests/subagent-stop-guard.bats` の command の完全一致の期待値を引用符付きに合わせた
- 同じ変更を capability-registry / cost-ledger / worktree の hooks.json にも入れた（各プラグインの `changes/716.md`）
- リポジトリ直下の `scripts/lint.sh` が、shellcheck のあとに直下と各プラグインへ `claude plugin validate` を走らせるようになった（`--strict` なし。`claude` が無い環境では理由を出して飛ばす）。テストは `tests/lint-plugin-validate.bats`
- 仕様 `dev-workflow-execution-strategy` の要件「model 未指定の Agent spawn は hook が拒否する」の記述を `agent-model-guard.sh` の実際の動きに合わせた（fork の共有枠判定だけがセッション記録と snapshot を読む）。hook の動作は変えていない
