# Codex の phase の prompt に一時ファイルの置き場を入れる（#1608）

Codex のゲートが作業メモをワークツリー直下の `scratchpad/` に作って残し、未追跡のフォルダがあるので親の片付け（`epic-dispatch.sh reap`）が子のワークツリーを残していた。原因は、prompt が作業場所を cwd に限る（`Work only in <cwd>.`）だけで、一時ファイルの置き場を指定していなかったこと。

- `scripts/codex-develop.py` の `prompt()`: 書く役（`WRITER_ROLES`。phase は spec / implement / finish / gate）の prompt だけに、作業メモ・取得データ・下書き・ログ・使い捨てのスクリプトは cwd の外（`$TMPDIR` の下、無ければ `mktemp -d`）に置き、cwd に作業メモ用の `scratchpad/` などのフォルダを作らず、本物の作業ファイルは今までどおり cwd に置く、という 3 行を足した。読み取り専用の phase には入れない（書けない場所を指示しない）
- `references/codex-develop.md` には書かない: 起動時の読込量の予算（`tests/develop-startup-budget.txt`）が実測と同値で、足すと予算ファイル（聖域）を動かすことになる。規則は prompt の文面そのものが正本。`.gitignore` で隠さないのは、本当に残った作業が片付けの判定から見えなくなるため
- `tests/test_codex_develop.py`: 書く phase で入ること、読む phase（review / spec-review / decider / explore / summarize）で入らないことを検査する
- 戻し方: この変更の差分を戻す。状態や設定の移行は要らない
- 実機の記録: 使い捨ての linked worktree で phase gate を 1 回走らせ、前後の `git status --porcelain` が空、作業メモは `$TMPDIR` の下に置かれたことを #1608 に記録した
- 受け入れること: Codex 向けの prompt が 262 バイト増え、`tests/gate-reading-budget.txt` の codex の 72 profile が予算超過になる（予算ファイルは別途、主の承認で動かす）

予算を動かす理由: Codex の書く役の prompt に一時置き場の指示を足した分を反映するため、全156 profile を再実測して `tests/gate-reading-budget.txt` を実測の1.0倍に取り直した。codex の72 profile が各 +262 バイト、claude の78 profile と codex/review 系の6 profile は変更なし。予算の余裕を増やす変更ではない。計測の基準は、PR のブランチ `54015371` と main `f38e31aa` を取り込んだマージ commit `36f4c94999d9b40ca2cadbce2b93a240197e8dbd`。再現コマンド: `python3 -B tests/gate_reading_budget.py measure .`。
