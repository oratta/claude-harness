# Codex の phase の prompt に一時ファイルの置き場を入れる（#1608）

Codex のゲートが作業メモをワークツリー直下の `scratchpad/` に作って残し、未追跡のフォルダがあるので親の片付け（`epic-dispatch.sh reap`）が子のワークツリーを残していた。原因は、prompt が作業場所を cwd に限る（`Work only in <cwd>.`）だけで、一時ファイルの置き場を指定していなかったこと。

- `scripts/codex-develop.py` の `prompt()`: 全 phase の prompt に、作業メモ・取得データ・下書き・ログ・使い捨てのスクリプトは cwd の外（`$TMPDIR` の下、無ければ `mktemp -d`）に置き、cwd に `scratchpad/` などの未追跡フォルダを作らない、という 2 行を足した
- `references/codex-develop.md` には書かない: 起動時の読込量の予算（`tests/develop-startup-budget.txt`）が実測と同値で、足すと予算ファイル（聖域）を動かすことになる。規則は prompt の文面そのものが正本。`.gitignore` で隠さないのは、本当に残った作業が片付けの判定から見えなくなるため
- `tests/test_codex_develop.py`: 全 phase の prompt にその文が入ることを検査する
- 戻し方: この変更の差分を戻す。状態や設定の移行は要らない
