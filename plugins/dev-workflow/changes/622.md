# pr-review-gate: 区画の判定の入力を 2 段にし、取得失敗を「合計 0 行」と取り違えない（#622）

`stages/prepare.md` の区画の判定は `gh api … | review-partitions.sh` の 1 本パイプで、`gh api` が失敗しても空の入力が渡り、「合計 0 行」と区別できなかった。

- `gh api` の出力を一時ファイルに書き、失敗したら区画を推測せず止める
- `review-partitions.sh < ファイル` の `合計:` を `gh api repos/$R/pulls/$N --jq '.additions+.deletions'` と比べ、一致しなければ止める
- `tests/pr-review-gate-skill.bats` に上の記述の検査を足した
- `review-partitions.sh` 本体の挙動と版は変えていない
- 戻し方: この PR の差分を戻す
