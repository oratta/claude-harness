# git-destructive-guard: 算術の << と $'...' の中の \' のあとに書いた破壊的 git 操作を止める（#981）

- `scripts/git-destructive-guard.sh` の `read_heredocs`: 区切り語の行が見つからないとき、末尾まで本文として捨てず、本文の開始位置に戻して後ろの行を通常のコマンドとして読む。`(( x << 2 ))` や `let y=1<<2` の後ろの `git reset --hard` が通っていた退行（#852）を直した
- 字句読みの `$'...'`: `\` とその次の 1 文字を飛ばして閉じの `'` を探す。`$'it\'s'` のあとの `; git reset --hard` が通っていたのを直した
- `tests/git-destructive-guard.bats`: 上の 3 入力の `expect_stopped` と、区切り語の行がある本物のヒアドキュメントの本文が止まらない `expect_silent` を足した
- 戻し方: この PR の差分を戻す。区切り語の行が無いヒアドキュメントは、これまで末尾まで本文とみなして通していたが、今は後ろをコマンドとして判定する（止める側に倒れる）
