# pr-review-gate: 候補探しの手順書と spec のずれを直し、再実行が失敗したときの扱いを決め直す（#1517）

#1012（PR #1507）の独立レビューで出た、`stages/triage.md` と spec のずれを直した。

- 候補探しのコマンド形に `[--exclude <エピック番号>]` を足し、見出しと本文の「1 回」に、打ち切りの再実行だけが例外であることを書いた
- spec の「`--children-only` は付けない」に、打ち切りの再実行だけは付けると書いた
- 再実行は 1 回目と同じ `--repo` と `--exclude`（記録先の issue とエピックの番号を含む）のまま、パスを絞って `--epic <エピック番号> --children-only` を付ける、と書いた
- 挙動の変更: 再実行が失敗したとき、打ち切られたパスの指摘を、これまでは既存 issue に相乗りさせず新しい子 issue にしていた。今後は 1 回目に出た候補だけで振り分ける（相乗りも許す）。仕分けの PR コメントに失敗と終了コードを書くのは変えない。15 件の外の子の見落としは、再実行でも打ち切られたときと同じく許す
- main の spec の要件「候補探しのスクリプトは 1 回だけ走らせ、失敗を候補なしと読まない」に、守備範囲の段落を足した
- 戻し方: この PR の差分を戻す。移行は要らない
