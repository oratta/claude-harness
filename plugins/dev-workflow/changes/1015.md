# pr-review-gate: 1 周目の段 A の指摘を、切り出しのあとと順 3 との混在でも W に戻す（#1015）

PR #1002 は、1 周目の段 A の指摘（止める指摘ではないが W が直す指摘）を止める指摘と同じ 1 回の failed に含めると決めた。切り出しの確認の復帰と順 3 の再レビュー不要の文はこの決定に触れておらず、段 A の指摘が W に戻らない、または直しが再レビューされずに閉じると読めた。

- `stages/hold.md`: 主が「切り出す」と答えたあと、ほかに止める指摘も、1 周目の段 A に当たる未解決の指摘も無いときだけ手順 3 以降へ進む。1 周目の段 A に当たる未解決の指摘が残っていれば `agent-review:failed` で W に戻す
- `stages/hold.md` の保留の解除: 1 周目かは前の段の Gate Result の `周回:` で、段 A の有無は仕分けの PR コメントの「段 A・この PR で直す」の印で読む。印が無ければ段 A の指摘は無いものとして扱う。failed の欄は `stages/triage.md` の「failed のとき」を使う
- `stages/hold.md` の保留の return: 1 周目の段 A に当たる指摘が混ざっていれば、仕分けの PR コメントと仕分け欄に同じ印を付ける
- `stages/triage.md`: 順 2・順 4 または段 A の指摘が同じ failed に含まれていれば、差分限定の再レビューを行い、周を 1 つ消費する。failed の `次の段:` は `前提確認と重さ判定`
- 変えていないもの: 順 3 だけで戻したときの再レビューの省略、未処理の順 6 を先に扱う処理順、2 周目以降の段 A を段 B から当てること、`gate-runner.md`・develop の `SKILL.md`・`dev-workflow-develop` の spec の「切り出して残りが無いとき」の文
