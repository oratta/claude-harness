# 恒久要件の「issue の対象条件」を記録先 issue に書いた対象条件と明示する（#619。#617 F2 の切り出し）

`openspec/specs/dev-workflow-develop/spec.md` の要件「W の 1 周目モデルの変更は過去 PR の再実行による比較記録に基づく」で、再実行の対象にする過去 PR の選定基準が「issue の対象条件」と書かれていて、どの issue かが読み取れなかった。「記録先 issue に書いた対象条件（例: 聖域パス・スキル本文・hooks などに触れる）」に直した。要件の意味は変えていない（1 文の言い換えのみ）。openspec change `clarify-model-change-target-condition` として起こし、アーカイブ済み。
