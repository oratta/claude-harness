# pr-state: --unrelated の名前をチェック名と同じ規則で正規化してから比べる（#535）

`pr-state.sh observe` はチェック名のタブ・改行・カンマを空白に置き換えて比べるが、`--unrelated` の値はそのまま比べていた。マトリクスのジョブ名はカンマを含むことが多く（例 `test (ubuntu, 3.11)`）、渡しても一致せず `real` になって直しに回っていた。

- `scripts/pr-state.sh`: `--unrelated` の名前にも同じ置き換え（タブ・改行・カンマを空白）をしてから比べる
- `openspec/specs/dev-workflow-pr-state/spec.md`: `unrelated` の項にその旨と Scenario を足した
- `tests/pr-state.bats`: カンマ入りの名前を `--unrelated` に渡すと `unrelated` になるケースを足した
- 受け入れること: `--unrelated` にカンマ・タブ・改行を含む名前を渡した場合、チェック名側と同じ置き換え後の名前で一致する。出力の形は変えていない
- 戻し方: この PR の差分を戻す。状態ファイルの形は変えていないので移行は要らない
