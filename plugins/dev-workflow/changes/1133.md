# git-destructive-guard: 拒否された子のコマンドを、親が一時領域の中に限って 1 回だけ通せるようにする（#1133）

#1108 で子（サブエージェント）の破壊的 git 操作は確認画面を出さずに拒否されるようになったが、子が自分の scratchpad に作った検証用 repo を戻すだけの操作でも、親が代わりに打つと主の確認画面が出て、主が画面を押すまで作業が止まっていた。

- `scripts/git-destructive-guard.sh`: 子を拒否するたびに、拒否の記録を `${TMPDIR:-/tmp}/dev-workflow-git-guard/denied/<key>.json` に書き（`<key>` は session_id・agent_id・cwd・コマンド全文を NUL でつないだ sha256）、そのパスを子への拒否理由に載せて「親に返す報告にこのパスを書く」と案内する。`permits/<key>.json` に一致する期限内の許可があり、使う時点の一時領域の判定も満たせば `allow` を返す（回数は数えない・許可は 1 回で消える）。許可はあるが行き先を確かめられないときは `deny` で「許可はあるが行き先を確かめられない」を理由に書く。子が `git-guard-permit.sh` を直接、または `bash` / `sh` / `zsh` / `dash` / `ksh` / `source` / `.` 経由で呼んだら `deny`（主の呼び出しと `cat` で読むだけのものは止めない）。主の呼び出しは許可を見ない
- `scripts/git-guard-permit.sh`（新規）: `git-guard-permit.sh <拒否の記録のパス> <理由>`。記録が `<base>/denied/<key>.json`（`<base>` の名前が `dev-workflow-git-guard`、中身から計算した key がファイル名と一致）にあり、記録のコマンドが一時領域の判定を満たすときだけ、`permit-log.jsonl` に追記してから 15 分・1 回限りの許可を置き、その子の拒否の回数を 0 に戻す。`<base>` は記録のパスの 2 つ上で、TMPDIR は見ない
- `scripts/git-guard-scratchpad.py`（新規）: hook とスクリプトが共通に読む判定。コマンドは引用符・変数・リダイレクト・グロブなどを含まない `cd`（引数 1 つ）と `git`（大域オプションは `-C` だけ。サブコマンドは checkout・restore・reset・clean・branch・switch・status・add・commit・rev-parse）に限り、`.git` を git を動かさずに辿って、作業ツリー・git ディレクトリ・共通の git ディレクトリがすべてそのセッションの scratchpad（`claude-<uid>/<slug>/<session_id>/scratchpad` の形で、`claude-<uid>` の親が `/tmp`・`/private/tmp`・`TMPDIR`・`tempfile.gettempdir()` のどれかの realpath、`claude-<uid>` が今の uid の持ち物でグループ・他者に書き込み権が無いもの）の中にあり、config に worktree・include の設定が無いことを確かめる。判定する側の環境に `CDPATH`・`GIT_DIR`・`GIT_WORK_TREE`・`GIT_CONFIG*` など cd や git の行き先・設定を変える環境変数があれば満たさない
- 範囲外: Claude Code 本体の rm の確認画面への親の許可（#1134）、develop の手順書に親がいつ許可を書いて子を再開するかを書くこと・記録先への記録（#1135）、2 回目の拒否で打ち切られた子の空の return（#1117）
- 受け入れること: 子や他のプロセスが `permits/` に直接書いた許可は親の同意を経ずに使われうる（通るのは一時領域の判定を満たす scratchpad の中だけ）。hook の判定からコマンドの実行までの間の symlink の差し替えは見ない。子が自分の Bash の中だけで設定した環境変数は見えない（hook とスクリプトの環境にあるものは拒む）。引用符やグロブを使ったコマンドは scratchpad の中でも許可できない
- 戻し方: この PR の差分を戻す。一時ディレクトリの `denied/`・`permits/`・`permit-log.jsonl` は残っても使われない
