# sync.sh: rules を出どころごとのサブディレクトリに張り、別の Harness（overlay）を重ねる（#1130）

オーナーの環境で公開版と個人版の両方の rules・output style を読めるようにした。

- `scripts/sync.sh`: 公開版の `rules/*.md` を `~/.claude/rules/` 直下ではなく `~/.claude/rules/claude-harness/` に張る。旧位置（直下）の、公開版を指す symlink は新位置に張ったあとで消える（実ファイルと他所を指す symlink は残る）
- overlay: 利用者が許可ファイル `~/.claude/harness-overlays`（1 行に 1 つ、`~/.claude/plugins/marketplaces/` 直下のディレクトリ名。空行と `#` 行は無視）に書いた marketplace だけを、同じ sync.sh が重ねる。許可した marketplace の直下の `.harness-overlay`（1 行目がサブディレクトリ名）に従い、その `rules/` を `~/.claude/rules/claude-harness/<名前>/`、`output-styles/` を `~/.claude/output-styles/` に張り、pull もする。許可に無い marketplace は印があっても張らず pull もしない（入れただけの第三者の marketplace に常時読まれる指示を張らせないため）。許可ファイルが無い環境（客の Mac）では何も出さず公開版だけを張る。sync.sh は個人版の名前を知らない
- 規則の名前がぶつかったとき: rules は張り先が別なので両方読まれる。output style は公開版優先で、重なる側を警告して非 0。許可したのにディレクトリや印が無い・名前が不正・重複・実ファイルとぶつかる overlay は警告して飛ばし、終了コードを 0 にしない
- 壊れた symlink の掃除: 行き先が公開版か `~/.claude/plugins/marketplaces/` の下のものを消す（外した overlay の後始末）。空になった `claude-harness/<名前>/` も消す
- 許可の取り消し: 許可ファイルから外した overlay（許可ファイルを消した場合も）の symlink は、リンク先が残っていても次の sync.sh の実行で消える。対象は `claude-harness/<名前>/` と `output-styles/` の、行き先が今回張られた overlay でも公開版でもない marketplace の下の symlink。marketplace の外を指す symlink と実ファイルは残す。出力はなく、終了コードにも影響しない
- `tests/rules-sync.bats`: 新しい張り先に直し、overlay・衝突・移行・掃除のテストを足した
- 仕様: `openspec/changes/harness-overlay-rules-sync/`（新 capability `harness-overlay-sync`）
- 影響: flatmate の `scripts/agent-status.sh` が `~/.claude/rules` 直下の symlink を数えているため、張り先の移動後は「未配線」と表示される（flatmate 側で直す）。#1226 の改名後は旧名のパスを指す旧位置の symlink が片付け対象から外れる（#1226 の手順で扱う）
- 戻し方: この PR の差分を戻して sync.sh を再実行すると、直下に張り直される（`claude-harness/` の下の symlink は壊れたものだけが掃除される）
