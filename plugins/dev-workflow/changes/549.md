# 修正後も検索語を含む「直した」行を補助表で照合する（#549）

- 順 3 の補助表 `### 書き換えた該当しない行` が、主表の「直した」行も参照できるようになった。主表は修正前本文を保ち、補助表に載せた修正後本文と一致する HEAD のヒットを各 1 件だけ許す。見出し・列はそのまま使える
- 未記載の「直した」行の旧本文・新本文、記載した修正後本文との不一致、許容件数を超えるヒットは従来どおり `unmatched:` で検出する。混在組の削除必要数は「直した」の件数と補助表に載った「該当しない」の件数の和を保ち、二重計上しない
- triage と worker の記録手順を揃え、成功・未記載・本文不一致・件数超過・混在組の回帰テストを追加した
