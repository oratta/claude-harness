# レビュアーを道具を絞った種別 dev-workflow:reviewer で起こす（#650）

pr-review-gate のレビュアーは `general-purpose` で起こされ、全部の道具の定義を起動時に読み込んでいた。W / G と同じく frontmatter の `tools:` で道具を絞った種別 `dev-workflow:reviewer`（`agents/reviewer.md`）を足し、本体がレビュアーを起こす既定の種別をこれに替える。

- 道具は `Read, Bash, Grep, Glob, TaskStop`、定義の `model` は `opus`。`Edit` / `Write` / `NotebookEdit` を持たない。本文は `skills/pr-review-gate/stages/reviewer-brief.md` を指し、ファイルを編集しない・サブエージェントを起こさない・コメントを投稿せず三表と指摘を起こした側に返す、だけを書く
- 既定の種別を替えた箇所: `stages/prepare.md` の needs-reviewer の段落と推奨モデル、`stages/review-run.md` 2-1 のフォールバックとモデルの節（develop 以外から回すときもこの種別）、develop `SKILL.md` の Agent ツールの行・(4) の ③・モデル表、`references/codex-develop.md` の Claude role、README
- Fable に上げるときは従来どおり `dev-workflow:decider`。`agent-model-guard.sh` の判定は変えず（`dev-workflow:reviewer` に `model: fable` は今の判定で拒否される）、ヘッダーのコメントだけ直した
- `subagent-context-audit.sh --by-role` は `agentType` が `dev-workflow:reviewer` の個体を decider の次の優先順で `Reviewer` に数える（`description` が `Reviewer:` で始まらなくても数えられる）。`docs/usage-audit.md` の分類表も合わせた
- plugin.json の `agents` に `./agents/reviewer.md` を足し、description にレビュアーの種別を足した。marketplace.json の description を plugin.json と同じ文に揃えた（以前から `agents/worker.md` と `pre-classification.md` の 1 語がずれていたのも同時に揃えた）
- 戻すときは上の文書の既定の種別を `general-purpose` に戻せば、定義ファイルが残っていても使われない
- openspec change `reviewer-agent-type`
