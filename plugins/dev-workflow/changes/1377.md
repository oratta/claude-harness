# develop: エピックの親の報告を、全部の子と親の状態表（確かめた時刻つき）で締める（#1377）

エピックの親が、知らせが来た子の件だけを報告して前に聞いた件が流れる問題と、主が子のタブで直接答えても子が issue の記録を書き直さないため報告が子の実際の状態とずれる問題（oratta/mac-mini-migration のエピック #33）への対応。

- `references/epic.md`: 親が主に出す報告すべての最後に、閉じていない全部の子と親自身の状態表（列 `issue 番号・内容・ステータス・確認内容・推奨・答え方`、上に確かめた時刻 JST、下に答えが要る子の URL、前回の報告から片付いたもの）を付けると規定する。表の前に子の会話ログの末尾を読み、食い違えば会話ログを優先し、読めない子は `確かめられなかった` と書く
- `scripts/epic-dispatch.sh child-log <child>...`: 読み取り専用の新しいサブコマンド。子ごとに会話ログの最後の主の発言と子の発言の時刻と冒頭を出す
- 受け入れること: 親の報告の最後に毎回表が付く。主が子のタブで答えたあとの表が、子の会話ログの最後のやり取りと一致する（実機の確認はマージ後に主が行う）
- 戻し方: この PR の差分を戻す。状態の記録の形は変えていないので移行は要らない
