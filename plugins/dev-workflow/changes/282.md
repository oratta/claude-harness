# 字下げした frontmatter の description を書式検査で拒否する（#282）

frontmatter 全体を半角 2 つ分字下げすると、書式検査を通り `description` の集計が 0 バイトになっていた（字下げした frontmatter は YAML ではトップレベルと読まれ、skill としても登録される）。`tests/injection-budget.bats` の `check_frontmatter_shape_z` が `^  description:` の行を違反にする。

- 入れ子の `description` は注入対象ではないので許可しない。`metadata:` 下の他の入れ子キーは従来どおり通る
- 負例テスト 2 件と、入れ子キーが通る確認 1 件を足した
- `openspec/specs/injection-budget-gate/spec.md` の「frontmatter は限定した書式だけを受理する」に条件とシナリオを追記（change `indented-frontmatter-description`）
- 予算値は変わらない
