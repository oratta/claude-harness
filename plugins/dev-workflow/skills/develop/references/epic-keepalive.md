# 声かけ受信

停止前、作業待ちの開始前・延長前に `references/child-cache-keepalive.json` を読む。停止中はトップレベル、作業待ちは `background`。`separator` で `reply_prefix` と順序付き `fields`（欄名＋空白＋`<値>`）を連結し、`request_template` の `{reply_format}` に入れた固定文・型を覚える。

固定文と完全一致する入力は通常の主の返事や親の判断より先に分類する。主の同文も予約文。送信元の識別はしない。受信ターンではツールを呼ばない（定義の読み直しも含む）。会話だけから各欄の短い値を選び、その型で一行だけ返す。値に改行や区切り文字を入れない。欄の意味・失敗検出は #1374。

停止中は調査・作業・停止コメントの投稿は行わず、元の質問・停止状態・停止記録を保って待つ。非一致の返事は `references/epic-child-stop.md` で再開する。

作業待ちは [専用手順](child-background-wait.md) で一行だけ返してターンを終え、元作業 ID・実行 ID・自己タイマーとその ID・初回設置時刻を保つ。ツール（定義の再読・タイマーの取消・再設置を含む）・調査・新しい作業・印や停止記録の変更・投稿を行わない。作業完了や自己通知成功と扱わない。12 時間の基点・上限を延ばさない。

固定文と型どおりの返事は `child-log` が除外する。質問・時刻の保証は正常な一行の往復だけ。「了解」・型違い・複数行は最後の子発言となる。その逸脱だけでは status/stop=stopped-seen・停止コメント・声かけの期限の基点を変えず、wait を続け親を起こさない。
