# workflow テンプレートの多バイト文字直前の変数展開を修正（#902）

`deploy-on-merge.yml.template` と `deploy-production.yml.template` のスモークチェック失敗メッセージで、全角の閉じ括弧の直前にある `$STATUS` を `${STATUS}` にした。bash 3.2 が多バイト文字を変数名に含めて読み、`set -u` で停止するのを防ぐ。

`ci.yml.template` と `weekly-full.yml.template` の lsof 失敗メッセージも、全角の閉じ括弧の直前にある `$lsof_rc` を `${lsof_rc}` にして、同じ問題を防ぐ。

再発防止のガードに `*.yml.template` / `*.yaml.template` を加え、通常の YAML と同じく `run:` の値だけを走査する。テンプレート内の波括弧なし展開を検出するフィクスチャテストを追加した。
