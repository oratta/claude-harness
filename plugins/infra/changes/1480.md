# コマンドの探索で、名前順で先の古い marketplace dir を拾わないようにする（#1480）

`agents/infra-phase-4-github-actions.md`（`CLAUDE_PLUGIN_ROOT` を候補に持たない代替ループ） の探索ループは `~/.claude/plugins/marketplaces/*/plugins/infra` を名前順に見ていた。旧運用の worktree の残りが `oratta-claude-harness` より先に並ぶと、古い版の手順やスクリプトが黙って使われた。#1152 で `/statusline:setup` だけ直した同型の探索を揃える。

- 候補の順を `~/.claude/plugins/marketplaces/oratta-claude-harness/plugins/infra`（固定）→ marketplaces の glob → installed の glob に変えた。glob は固定候補が無い環境の最後の手段として残す。#955 の nullglob 退避は変えない
- 検査: `plugins/infra/tests/phase4-search-zsh.bats` に、`aaa-stale` と `oratta-claude-harness` を並べた HOME で候補の順を確かめるケースを足した（bash は常に、zsh は有るときだけ）
- 戻し方: 各文書の固定候補 1 行と、足したテストを消す
