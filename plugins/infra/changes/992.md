# infra の CI 雛形にジョブの上限時間（timeout-minutes）を足す（#992）

- `ci.yml.template` の `test` ジョブ（10 分）と `weekly-full.yml.template` の `full` ジョブ（30 分）に `timeout-minutes` を足した。決め方（普段の所要時間の約 2 倍）はコメントに書いた
- `infra-setup` の `SKILL.md` に、上限時間の決め方と、既に雛形から CI を入れたリポジトリへの反映のしかた（両ファイルに手で書き足す。再実行では `weekly-full.yml` が Phase 4 の確認対象の列挙に無いため確認なしで書き直されることがある）を足した
- `weekly-full.yml.template` の `report-failure` を、`full` が上限で打ち切られた（`cancelled`）ときも issue を起票する条件に変えた（上限を置いたことで、正常だが 30 分を超える週次実行が起票されなくなるのを防ぐ）
- 既存のリポジトリへの反映と、セルフホスト時の取り残しの掃除（#994）は含まない
- 戻し方: この PR の差分を戻す
