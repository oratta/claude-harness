# infra の CI 雛形にセルフホスト時のジョブ終了時の掃除を足す（#994）

- `ci.yml.template` の `test` ジョブと `weekly-full.yml.template` の `full` ジョブの最後に、`if: always() && runner.environment == 'self-hosted'` の手順を足した。作業ディレクトリ（`$GITHUB_WORKSPACE`）の下に cwd を持つプロセスを、自分と祖先を除いて TERM → 5 秒待ち → KILL で止める。止められない PID があれば赤になる。GitHub のランナーでは動かない
- 止めるのは作業ディレクトリの下だけで、同じ Mac のほかのジョブは止めない。cwd を作業ディレクトリの外へ移したプロセスは止まらない（ランナーの Mac の見張りは flatmate#1567）
- `infra-setup` の `SKILL.md` に、掃除の意味と、既に雛形から CI を入れたリポジトリへの反映のしかた（両ファイルの最後の手順に手で書き足す。再実行は勧めない）を足した
- 既存のリポジトリ（suimei など）への反映そのものは含まない。上限超過のあとに手順が起動するかは未確認で、最初の打ち切りの run のログで確かめる
- 戻し方: この PR の差分を戻す
