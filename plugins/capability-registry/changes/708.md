# bundles all に capability-registry・casting・cost-ledger を足す（#708）

`.claude-plugin/marketplace.json` の bundles `all`（説明は「全プラグインをインストール」）に、後から作られた capability-registry・casting・cost-ledger が入っていなかった。意図して外した記録は無く、bundle を足し忘れていた。3 つを足した。

- bundles `all` の `plugins` に 3 つを足した。telegram は bot トークンの設定が要るので入れない。説明を「全プラグインをインストール（bot トークンの設定が要る telegram を除く）」にした
- 変更の記録は 3 プラグインにまたがるため、このファイル 1 つにまとめた（casting・cost-ledger 側には書かない）
- 検査は `tests/marketplace-sync.bats` の S140（bundles `all` が `plugins[]` から telegram を除いた集合と一致する）と S140b（3 つが入っている）。件数は固定せず集合で縛るので、telegram を解散する PR #841 がマージされても、そのまま通る
- 戻し方: 3 つの名前と説明の追記を消し、S140・S140b を消す
