# hooks.json の `${CLAUDE_PLUGIN_ROOT}` を引用符で囲む（#716）

`hooks/hooks.json` の `browser-guard.sh` の command を、`${CLAUDE_PLUGIN_ROOT}` を含むパス全体を二重引用符で囲んだ形（`"\"${CLAUDE_PLUGIN_ROOT}/scripts/browser-guard.sh\""`）にした。`claude plugin validate` が「引用符なし」と警告していたもので、展開後のパスに空白があるとコマンドが割れて hook が起動しない。変えたのは引用符だけ。経緯は `plugins/dev-workflow/changes/716.md`。
