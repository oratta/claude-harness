# browser-guard.sh の python3 を隔離モードで起動する（#847）

`scripts/browser-guard.sh` の python3（2 か所。`python3 -c` と `python3 <<'PY'`）に `-I` を付けた。どちらもカレントディレクトリを import の検索先に入れる呼び方で、hook が走る作業リポジトリに `json.py` があるとそれを実行していた。

- hook が出す文面と、出す条件は変えていない
- 検査は `tests/hook-python-isolation.bats`（偽の `json.py` をカレントと `PYTHONPATH` に置いても読まれず、出力が変わらない）
- 戻し方: 2 か所の `-I` を外す
