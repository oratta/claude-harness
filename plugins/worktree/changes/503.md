# session-proc-cleanup.bats の TZ テストを tzdata に依存しない指定にする（#503）

`start_token: identical under …` のテストが `TZ=Asia/Tokyo` を使っていた。tzdata の無い Linux コンテナでは UTC として扱われ、修正前のコードでも jst と utc が同じ値になって壊れを検出できない。POSIX 形式の `TZ=JST-9`（tzdata 不要）に置き換えた。テスト名も合わせた。macOS で当該テストが pass することを確認した。

- 戻し方: 該当 2 行を `TZ=Asia/Tokyo` に戻す
