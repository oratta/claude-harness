# wt-clean: コマンド名の正規化を proc_comm 1 関数に一本化（#190）

wt-clean が対象 worktree 配下のプロセスを調べるとき、検出側と停止側でコマンド名の取り出しが別々に書かれていた。片側だけ直って、生きた端末を「死んだプロセス」と誤認する事故が起きうる形だった。

- `skills/wt-clean/SKILL.md`: コマンド名の正規化を `proc_comm` 1 関数にまとめ、検出側（`detect_active_procs_under`）と停止側（`kill_devserver_under`）の両方がこの関数だけを通るようにした。ログインシェルの `-/bin/zsh` のように先頭が `-` の名前でも除外リストに一致する
- `tests/devserver-kill.bats` ほか: 上の同一性を、コマンド名の形（先頭 `-`、パス付き、`.exe` 付きなど）を変えて固定するテストに更新
