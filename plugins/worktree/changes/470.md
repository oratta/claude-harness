# セッション終了時に、そのセッションが起動したプロセスを止める（#470）

Claude のセッションが動作確認のために起動した `wrangler dev` が、セッション終了後も 21 本（配下を含め 105 プロセス・約 1.1GB・最古 10 日前）残っていた。wt-clean はワークツリーを消す直前にしか配下のプロセスを止めないため、作業が終わってからワークツリーを片付けるまでの数日から数週間は何も止まらなかった。

- **目印を付ける**: SessionStart フック `session-proc-mark.sh` が、親をたどってセッションの持ち主の Claude Code を見つけ、`export CLAUDE_SESSION_PROC_MARK=<claude_pid>.<start_token>` を `CLAUDE_ENV_FILE` に追記する。`start_token` は `LC_ALL=C ps -o lstart=` から英数字以外を除いたもの（ロケールで書式が変わるのを防ぐ）
- **終わったときに止める**: SessionEnd フック `session-proc-end.sh` が目印を計算し、`perl` の fork＋`POSIX::setsid` で切り離した後始末 `session-proc-reaper.sh --session-end` を起動してすぐ戻る（SessionEnd の持ち時間 1.5 秒に収める）。後始末は持ち主の Claude Code の終了を最大 30 秒待ち、終了していれば目印を持つ自分のユーザーのプロセスと、そこから環境変数が読めないプロセスだけを経由して届く子孫を TERM → 3 秒 → KILL で止める。`/clear` や `/resume` で同じプロセスが続いていれば止めない
- **落ちたセッションの分を拾う**: SessionStart フックが、前回から 10 分以上たっていれば `session-proc-reaper.sh --sweep` を切り離して起動し、持ち主がもういない目印のプロセスを同じ手順で止める
- **止めない側に倒す**: 環境変数が読めて目印を持たないプロセス（無い・空・別の値）に当たったら、そのプロセスも配下も見ない。目印を空にして起動したもの（`CLAUDE_SESSION_PROC_MARK= nohup <cmd> &`）はセッションが終わっても残る
- **ログ**: 止めた各プロセスの時刻・信号・PID・コマンド名・目印・起動の種類を `${CLAUDE_PLUGIN_DATA}/session-devserver-cleanup.log`（無ければ `~/.claude/logs/`）に 1 行ずつ残す
- **文書**: `references/session-devserver-cleanup.md` に仕組み・止まるもの止まらないもの・目印の外し方・ログの読み方を書いた
- wt-clean の `kill_devserver_under` はそのまま残す（最後の保険）
