# wt-setup が、追跡されている .githooks を core.hooksPath に設定する（kg-recruit#126 / PR #298）

`scripts/wt-setup.sh` の Step 4 に `wt_enable_repo_githooks` を追加した。`.githooks/` を git で追跡していて、実効の `core.hooksPath` が未設定か global / system のときだけ、その clone のローカル設定に `core.hooksPath .githooks` を書く。local / worktree / command、および include 経由のローカル値があるときは無出力で触らない。`.git/hooks/`（別ディレクトリへの symlink でもよい）に `.sample` 以外のフックがあるときは触らず、注意を 1 行出す。書き込んだ場合や見送った場合は `=== git フック:` の行を出し、`scripts/wt-setup-guard.sh` がそれを残タスクに載せる。依存チェックは Step 5 に繰り下げた。

テストは `tests/setup-script.bats` と `tests/hooks.bats` に追加した。版は上げない（version を書かない運用）。
