# wt-create-hook.sh の python3 を隔離モードで起動する（#847）

`scripts/wt-create-hook.sh` が hook の入力から値を取り出す `python3 -c` に `-I` を付けた。`python3 -c` はカレントディレクトリを import の検索先に入れるので、hook が走る作業リポジトリに `json.py` があるとそれを実行していた。

- 取り出す値と、python3 が無いときに sed で読む扱いは変えていない
- `scripts/wt-setup-guard.sh` の `python3 -c` には付けていない（マージ待ちの PR #298 が同じファイルを変えているため。その PR のマージ後に直す）
- 検査は `tests/hook-python-isolation.bats`（hooks.json に登録されたスクリプトの python3 の呼び出しが `-I` で始まること。`wt-setup-guard.sh` は上の理由で対象から外してある）
- 戻し方: `-I` を外す
