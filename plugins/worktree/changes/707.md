# wt-setup の frontmatter に background: false を明記する（#707）

Claude Code 2.1.218 から `context: fork` のスキルは既定でバックグラウンド実行になった。`plugins/worktree/skills/wt-setup/SKILL.md` は `context: fork` だけを書いていたため、スキルとして呼ばれたとき、呼び出し側がセットアップ（`.env` のコピー・symlink 作成）の完了を待たずに後続へ進みうる。wt-setup は Step 1〜5 のセットアップを終えてから Step 6 で後続作業へ着手する直列の手順なので、完了を待つ前提で `background: false` を足した。

`plugins/worktree/tests/skill-safety.bats` に、frontmatter が `context: fork` のとき `background` の指定があること、`background: false` であることの検査を足した。

版（`version: 1.7.1`）は上げていない。
