# session-proc-reaper の未使用関数 srp_env_readable を削り、判定を srp_select_targets の出力で検査する（#494）

`srp_env_readable` は reaper.sh の本体では呼ばれず、bats からだけ呼ばれていた（本体の判定は `srp_select_targets` の awk が持つ）。実際の判定と別の実装を検査しても、awk 側の変更を検出できない。

- `srp_env_readable` を削除し、判定の定義（`NAME=` の形の語が 1 つも無ければ読めない）は `srp_select_targets` の awk にあることをコメントに残した
- bats の旧 `readable:` 4 ケース（`/bin/sh -c esbuild --service`、`node server.js PATH=/bin`、`/bin/sh -c FOO=1 cmd`、`tool 1=2 a.b=c`）を、固定出力の `srp_select_targets` の出力（対象になる子孫とならない子孫）で検査する 1 テストに置き換えた
- 戻し方: この commit を revert する
