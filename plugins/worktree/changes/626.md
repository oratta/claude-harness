# wt-clean の稼働シグナル検出が noclobber 下で黙って飛ばされる不具合を直す（#626）

`plugins/worktree/skills/wt-clean/SKILL.md` の稼働シグナル検出は `mktemp` で作った空ファイルへ `2>"$ORPHAN_NOTE_TMP"` で書いていた。zsh で `noclobber` が有効だと既存ファイルへの `2>` が拒否され、コマンド置換の中身（`detect_active_procs_under`）が実行されないまま `ACTIVE_PROCS` が空になり、「稼働中プロセスなし」と区別がつかなかった。

- `2>"$ORPHAN_NOTE_TMP"` を `2>|"$ORPHAN_NOTE_TMP"` に変えた（bash・zsh とも `>|` は noclobber を無視して上書きする）
- 「コード片の実行シェルは zsh も含む」の表に、`mktemp` のファイルへ `>` / `2>` で書くと noclobber 下でコマンドが走らない旨を追加した
- 他のコード片に `mktemp` は無いことを `grep` で確認した（`plugins/worktree` 配下で該当は 1 箇所のみ）
- 検査は新規 `plugins/worktree/tests/noclobber-detect.bats`（SKILL.md から該当 3 行を取り出し、検出関数を差し替えて noclobber 下の bash / zsh で結果が空にならないことを確認。zsh が無い環境では zsh 側は skip）
- 戻し方: `2>|` を `2>` に戻し、表の 1 行と新しい bats を消す
