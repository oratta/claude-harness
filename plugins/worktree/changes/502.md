# session-devserver-cleanup の正本 spec に start_token の TZ=UTC を足す（#502）

実装（`scripts/session-proc-reaper.sh:107`）は `LC_ALL=C TZ=UTC ps -o lstart=` で `start_token` を計算しているが、正本の spec と design の定義には `TZ=UTC` が無く、定義と実装が食い違っていた。

- `openspec/specs/session-devserver-cleanup/spec.md:8`: `start_token` の定義を `LC_ALL=C TZ=UTC ps -o lstart= -p <claude_pid>` にし、SHALL の文言を「`LC_ALL=C` と `TZ=UTC` を付ける」に変更
- `openspec/changes/archive/2026-09-25-session-devserver-cleanup/design.md:32`: 同じ定義を `LC_ALL=C TZ=UTC` に揃えた（34 行目の理由文は既に TZ=UTC に触れている）

動作の変更は無い。
