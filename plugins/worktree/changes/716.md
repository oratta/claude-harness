# hooks.json の `${CLAUDE_PLUGIN_ROOT}` を引用符で囲む（#716）

`hooks/hooks.json` の `wt-create-hook.sh` / `wt-setup-guard.sh` / `session-proc-mark.sh` / `session-proc-end.sh` の command を、`${CLAUDE_PLUGIN_ROOT}` を含むパス全体を二重引用符で囲んだ形にした。`claude plugin validate` が「引用符なし」と警告していたもので、展開後のパスに空白があるとコマンドが割れて hook が起動しない。変えたのは引用符だけ。

- `tests/session-proc-cleanup.bats` の command の完全一致の期待値を引用符付きに合わせた
- 経緯は `plugins/dev-workflow/changes/716.md`
