# session-proc-reaper が停止済み（ゾンビ）の子孫を停止対象に含めない（#495）

`plugins/worktree/scripts/session-proc-reaper.sh` の停止対象選びが、ゾンビ（`ps` の stat が `Z` で始まる行）まで対象にして TERM/KILL を送り、ログにもその pid が出ていた。ゾンビは kill しても残るので、送る意味がなくログも汚れる。

- `srp_ps_comm_list` の実機出力を `ps -o pid=,stat=,comm=` にし、`srp_select_targets` の awk が stat が `Z` で始まる行を対象から外す。comm は stat の後ろの残り全部として扱うので、空白を含んでも壊れない
- 検査は `plugins/worktree/tests/session-proc-cleanup.bats` に追加（ゾンビ行は対象に出ず同じ形の stat=S は出る / comm の空白を保つ / session-end のログにゾンビの pid が出ない）。既存の固定出力は stat 列を足した形に更新
- 戻し方: スクリプトの 3 箇所（`ps` の列・awk の分岐・`srp_proc_comm` の sed）と bats の追加分を戻す
