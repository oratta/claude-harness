# wt-clean: dev-workflow の hook に `git branch -D` を拒否されたときの扱いを書く（#710）

dev-workflow に、破壊的 git 操作を Bash の実行前に止める hook を足した（`plugins/dev-workflow/changes/710.md`）。主の `cld` セッションも `--unattended` の cron も確認画面が出ないモードなので、wt-clean のブランチ削除は拒否される。何も書かなければ wt-clean が拒否のたびに言い換えて再実行するか、黙って止まる。

- `skills/wt-clean/SKILL.md` の squash 済みの扱いの段落の直後に、`git branch -D` が拒否されたら言い換えて再実行せず、worktree の削除までで止めてブランチを `HELD` に入れ、完了レポートに主が打つコマンド（`git -C <メインリポ> branch -D <ブランチ>`）を載せることを足した
- cron への載せ方の節に、ジョブの環境に `DEV_WORKFLOW_GIT_GUARD=off` を入れること（入れなければブランチ削除が保留に載る）と、そのジョブでは hook が外れるので wt-clean の禁則が唯一の歯止めになることを足した
- `tests/skill-safety.bats` に両方の文面の検査を 2 件足した
