# wt-clean: dev-workflow の hook に `git branch -D` を止められたときの扱いを書く（#710）

dev-workflow に、破壊的 git 操作を Bash の実行前に止める hook を足した（`plugins/dev-workflow/changes/710.md`）。主の `cld` セッションでは wt-clean のブランチ削除のたびに確認画面が出て、主が承認すれば削除される。確認画面で断られたときと、`--unattended` の cron（`claude -p` で確認画面が出ない）では止まる。何も書かなければ、止まるたびに wt-clean が言い換えて再実行するか、黙って止まる。

- `skills/wt-clean/SKILL.md` の squash 済みの扱いの段落の直後に、`git branch -D` が止められたら（確認画面で断られた、または確認画面が出ないセッションで止まった）言い換えて再実行せず、worktree の削除までで止めてブランチを `HELD` に入れ、完了レポートに主が打つコマンド（`git -C <メインリポ> branch -D <ブランチ>`）を載せることを足した
- cron への載せ方の節に、ジョブの環境に `DEV_WORKFLOW_GIT_GUARD=off` を入れること（入れなければブランチ削除が保留に載る）と、そのジョブでは hook が外れるので wt-clean の禁則が唯一の歯止めになることを足した
- `tests/skill-safety.bats` に両方の文面の検査を 2 件足した
