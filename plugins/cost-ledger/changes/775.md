# 775: GitHub にコストの行を書くのを、許可の一覧に載っているリポジトリだけにする

節目ごとの自動投稿（PR / issue のコメントに積む「ここまでのコスト」の行）を、利用者が手元のファイルに列挙したリポジトリにだけ書くようにした。これまでは作業中のリポジトリの PR / issue なら、公開リポジトリでも他人のリポジトリでも書いていた。**更新した時点で、一覧を作るまでどのリポジトリにも行が付かなくなる。**

- 一覧は `$HOME/.config/cost-ledger/write-repos`（環境変数 `COST_LEDGER_WRITE_REPOS_FILE` が空でなければその絶対パス）。1 行に `owner/repo` を 1 つ書く。空行と `#` で始まる行は読み飛ばし、ホスト付き・ワイルドカード・URL・末尾コメント付きの行はその行だけを無視する。照合は大文字と小文字を区別しない
- 一覧として扱わないファイル: 作業中のリポジトリの中にあるもの（`cwd` と `CLAUDE_PROJECT_DIR` から上の `.git` を持つディレクトリのどれか、worktree・submodule の元のリポジトリを含む。実体の場所で見る）・グループやほかの利用者が書ける・持ち主が自分でない・通常のファイルでない・1 MiB を超える・UTF-8 でない・場所が相対パス。どれも一覧が無いのと同じ
- 環境変数に名前を書いても効かない（`.claude/settings.json` の `env` から設定できるため）
- 判定は `scripts/write_allow.py` の `allowed()` 1 つ。hook（`gate-report.sh`）は一覧のファイルが無い・空なら標準入力を読まず `python3` も起動せずに抜ける。裏の処理（`gate_report.py` の `work()`）は、`cwd` の origin とコマンドが名指ししたリポジトリ、GitHub が返したリポジトリ名の 3 か所で判定し、一覧に無ければ `gh` を呼ばない
- `COST_LEDGER_GATE_REPORT=off` は一覧より先に効く（off なら一覧も読まない）
- `write-allow.bats` が、`plugins/cost-ledger/scripts/` の `gh` を起動する `*.py` がすべて `write_allow` を読み込んでいることを検査する（後から足すスクリプトも対象）
- 既に付いたコメントを一覧して消す手順を README の「既に付いた行を消す」に書いた（スクリプトにはしていない）
- 反映に `/reload-plugins` は要らない（`hooks.json` を変えていない。スクリプトは実行のたびに読まれる）
