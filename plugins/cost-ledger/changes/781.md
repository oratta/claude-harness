# cost-ledger: /cost が台帳未設定を stderr の 1 行で知らせ、案内の判定をその行に寄せる（#781）

- `scripts/cost_ledger.py` の `cmd_cost` 冒頭で、台帳が未設定なら stderr に `台帳: 未設定（会話ログを直接読みました）` を出す。標準出力と終了コードは変えない
- `commands/cost.md` の「台帳が未設定なら」の条件を、プラグイン設定の有無（モデルからは確かめられない）ではなく、出力にこの行があるかどうかにした
- `tests/cost-command.bats`: この行の有無を確かめるテストを 1 件足し、順序テストの案内行の特定を `"台帳が未設定なら"` に変えた。stderr の行が出力に混ざるため、`cost` を呼ぶ既存テストは `run --separate-stderr` にし、エラー文言の検査は `$stderr` を見る
- `tests/epic.bats`・`tests/issue-total.bats`・`tests/ledger.bats`: 同じ理由で、`cost` の 1 行目や出力全体を比べる既存テストを `run --separate-stderr` にし、3 ファイルに `bats_require_minimum_version 1.5.0` を足した
- 戻し方: stderr の 2 行とテストの変更を戻す
