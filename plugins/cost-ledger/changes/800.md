# テストと spec に残る別リポジトリの名前を架空の名前に置き換える（#800）

- `tests/gate-report.bats`・`openspec/specs/cost-ledger-gate-report/spec.md`・`openspec/specs/cost-ledger-cost-command/spec.md`: 実在しうるリポジトリ名を `acme/...` に、出力例のブランチ名を `example/...` に置き換えた。同じ旧名には同じ新名を対応させた（1 本の対応表）
- テストの期待値の構造と、spec の規範の文は変えていない（例の名前の置き換えのみ）
