# cost-ledger: pricing.json に claude-sonnet-5-5 と claude-haiku-5-5 の単価を足す（#1100）

- `pricing.json` に `claude-sonnet-5-5`（入力 2・出力 10・5 分書込 2.5・1 時間書込 4・キャッシュ読 0.1、$/MTok）と `claude-haiku-5-5`（入力 0.1・出力 0.5・5 分書込 0.125・1 時間書込 0.2・キャッシュ読 0.01）を足した。出典は Anthropic 公式の料金ページ
- 足す前は、sonnet-5-5 は `claude-sonnet-5` の前方一致で引かれ（キャッシュ読の単価が 0.2 で 2 倍になる）、haiku-5-5 は単価が引けず未知モデルとして 0 円扱いだった
- haiku-5-5 は公式でプロンプト 100,000 トークン超の単価が別（入力 0.5・出力 2.5・5 分書込 0.625・1 時間書込 1・キャッシュ読 0.05）。料金表は段階単価を持てないので、100,000 トークン以下の単価を入れた。超える呼び出しは安く出る
- `tests/pricing.bats` に 2 モデルの検算を足した
- 戻し方: 足した 2 行とテスト 2 本を消す
