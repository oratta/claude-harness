# コマンドの探索で、名前順で先の古い marketplace dir を拾わないようにする（#1480）

`commands/cost.md` の探索ループは、`CLAUDE_PLUGIN_ROOT`（slash command の本文では空）の次に `~/.claude/plugins/marketplaces/*/plugins/cost-ledger` を名前順に見ていた。旧運用の worktree の残りが `oratta-claude-harness` より先に並ぶと、古い版の手順やスクリプトが黙って使われた。#1152 で `/statusline:setup` だけ直した同型の探索を揃える。

- 候補の順を `CLAUDE_PLUGIN_ROOT` → `~/.claude/plugins/marketplaces/oratta-claude-harness/plugins/cost-ledger`（固定）→ marketplaces の glob → installed の glob に変えた。glob は固定候補が無い環境の最後の手段として残す。#955 の nullglob 退避は変えない
- 検査: `plugins/cost-ledger/tests/cost-command-zsh.bats` に、`aaa-stale` と `oratta-claude-harness` を並べた HOME で候補の順を確かめるケースを足した（bash は常に、zsh は有るときだけ）
- 戻し方: 各文書の固定候補 1 行と、足したテストを消す
