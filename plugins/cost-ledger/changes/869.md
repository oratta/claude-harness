# hook の 3 本が python3 を -E -s で起動する（#847）

`scripts/backfill.sh`・`scripts/gate-report.sh`・`scripts/ledger-hook.sh` の python3 に `-E -s` を付けた。`PYTHONPATH` などの `PYTHON*` の環境変数とユーザー site を検索先に使わない。

- `-I` は付けていない。3 本は隣の `.py` を直接実行し、`backfill.py` と `gate_report.py` は同じディレクトリの `write_allow.py`・`cost_ledger.py` を import する。`-I` はスクリプトのディレクトリも検索先から外すので、import できなくなる（`python3 -I` で `backfill.py` を読むと `write_allow` が見つからないことを bats で固定した）
- `.py` を直接実行する形はカレントディレクトリを検索先に入れないので、作業リポジトリに置いた `json.py` は直す前から読まれない。`-E -s` で塞いだのは `PYTHONPATH` とユーザー site の経路
- `scripts/cost_ledger.py` は触っていない（マージ待ちの PR #880 が変更中）。hook が何を記録するかは変えていない
- 検査は `tests/hook-python-isolation.bats`
- 戻し方: 3 か所の `-E -s` を外す
