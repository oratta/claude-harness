# 736: `/cost <issue番号>` でも、閉じた PR の分を合わせた合計を出す

子 issue を持たない issue に `/cost <issue番号>` を実行すると、その issue を閉じた PR があれば、2 行目に閉じた PR の分を合わせた合計と内訳（PR ごとの額と PR の外の額）が出る。今までは `gh issue close` の hook が積むコメントでしか見られなかった。

- 1 行目は変わらない（金額は区間だけ、種別は `区間`）。PR に貼るのは引き続き 1 行目だけ
- 閉じた PR が 0 件なら、通常出力は変わらない。`--json` には `closing_prs_error` の鍵が増える
- 閉じた PR を読めなかったとき（問い合わせの失敗・形の崩れ・100 件超）は、終了コード 0 のまま区間の分を返し、「閉じた PR を読めなかったため、PR の分は合計に入っていません。」の行を足す（`--json` は鍵 `closing_prs_error` が `true`）
- `/cost <issue番号>` 1 回につき GraphQL（`gh api graphql`）が 1 回増える。PR 番号・子 issue を持つ issue・番号なしの `/cost` では増えない
- hook の動作（`gate_report.py`）は変えていない。反映に `/reload-plugins` は要らない
