# cost-ledger: /cost の issue・epic 経路と cost.md で、未知モデルの名前が利用者に届くようにする（#1102）

- `cost_ledger.py issue <番号>` と、子 issue を持つ issue の `cost` の通常出力に、ブランチ・PR の経路と同じ文言の `  未知モデル: <名前> N 行（料金表に単価が無いため 0 円として扱っている）` を出す。文言は `render_breakdown()` から切り出した `render_unknown_models()` 1 か所にあり、`cmd_branch`・`cmd_report` の出力は変わらない
- 数える範囲は、issue 経路は issue に帰属した区間の行、epic 経路は合計に入れた行（`assign_epic_rows()` の `counted`。ヘッドブランチの行も含む）。リポジトリ不明の行と、`--closing-pr` で足す閉じた PR の行は数えない
- 位置は、epic が `数えていない子 issue:` と `リポジトリ不明` の間、issue が `リポジトリ不明` のあと・`推定で数えた行:` の前。1 行目は変えない
- `issue --json` と epic の `--json` に `unknown_models`（`{モデル名: 行数}`）の鍵を足した（既存の鍵は変えていない）。`assign_epic_rows()` の戻り値にも同じ鍵を足した
- `commands/cost.md` に、`未知モデル:` の行があれば 1 行目に続けて見せる指示と、`<synthetic>` だけなら額に影響しない旨の添え書きを足した。`<synthetic>` の行そのものは消していない（branch の出力が変わるため）
- テスト: `tests/unknown-model.bats`（issue 経路と cost.md）、`tests/epic.bats` の末尾 6 本（epic 経路）、`tests/helper.bash` に `cl_row_unknown`
- 戻し方: 変更した `cost_ledger.py` の呼び出し 3 か所と `cost.md` の一文を戻す（鍵を足しただけなので、戻しても既存の出力は変わらない）
