# 760: 後追いの台帳パスの解決・空の一覧の控え・bats の取りこぼし（#762・#764 も同じ変更）

#691 の後追い（SessionStart の `backfill.sh` / `backfill.py`）のレビューで出た指摘を、1 つの変更で直した。

- **#760**: 台帳の場所を userConfig の `LEDGER_PATH`（環境変数 `CLAUDE_PLUGIN_OPTION_LEDGER_PATH`）だけで設定した環境では、後追いが `COST_LEDGER_PATH` しか見ないので毎回何もせず終わっていた。`backfill.sh` が `ledger-hook.sh` と同じ形（`CLAUDE_PLUGIN_OPTION_LEDGER_PATH` を優先し、空なら `COST_LEDGER_PATH`。解決した値を `COST_LEDGER_PATH` に写して export）で解決するようにした。控えとロックは解決後の台帳の隣にできる。`gate_report.py` と `cost_ledger.py` は変えていない
- **#762**: 一覧が成功して 0 件で、控えにそのリポジトリの値が無い回は、その回の一覧の `since`（実行した時刻の 24 時間前）を控えに書くようにした（`backfill.py` の `sweep()`）。値があれば変えない。一覧が失敗した回は書かない。一覧が空の回が続いても 24 時間の窓がずれない。#691 の「手元の時計で値を書かない」とは逆になるが、初回の `since` は元から手元の時計で決めている。壊れた控えで一覧が 0 件のときも、控えは読める形に直る
- **#764**: `backfill.bats` の取りこぼし 6 件。F1・F2 `[[ ]]` に `|| return 1`／F3 20 件上限のテストの一覧を新しい順にして `candidates()` の並べ替えを固定（`sorted()` を外すと落ちることを確認）／F4 `GH_HOST` が gh に渡らない検査／F5 使っていなかった `FAKE_COMMENTS_FAIL`・`FAKE_PATCH_FAIL` のテストを足した／F6 `teardown() { wait_for_workers || true; }`
- 仕様: `openspec/specs/cost-ledger-backfill/spec.md`（台帳の場所の解決、一覧が空のときの控えの進め方）。README の「動く条件」「手元に増えるファイル」「入れた直後」と、`691.md` の `COST_LEDGER_PATH` の記述を直した
- テスト: `backfill.bats` に 9 本足した（userConfig だけ・両方を別の場所に設定・空の userConfig・一覧が空で値が無い・空の回が続く・壊れた控え＋空・一覧失敗で値が無い・コメント取得の失敗・PATCH の失敗）
- 戻し方: `backfill.sh` の 3 行を元の 1 行（`[ -n "${COST_LEDGER_PATH:-}" ] || exit 0`）に戻し、`backfill.py` の `elif seen_until(...) is None:` の節を外す。`hooks.json` は変えていないので `/reload-plugins` は要らない
