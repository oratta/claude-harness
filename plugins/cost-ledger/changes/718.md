# cost-ledger-pricing: シナリオ「timeline は突き合わせない」に終了コードの定めを足す（#718）

- `openspec/specs/cost-ledger-pricing/spec.md` のシナリオ「timeline は突き合わせない」に、終了コードは 0 で、出力の 1 行目は `コスト: ` で始まる通常のコスト行である、という AND を 1 行足した。今までの THEN は `単価表のずれ:` の行が無いことだけで、`timeline` が失敗して何も出さない場合にも通り得た
- 実行物は変えていない（spec の Scenario に定めを 1 つ足しただけ）。足した定めに対応する検査は、`tests/drift.bats` の「drift: timeline does not compare」が既に持っている（終了コード 0・1 行目 `コスト: `）ので、テストは足していない
- 戻し方: 足した AND の 1 行を消す
