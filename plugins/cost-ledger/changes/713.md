# 713: 台帳パスを userConfig で宣言し、プラグインの有効化時と /config から設定できるようにする

台帳の置き場所を、settings.json の `env` に `COST_LEDGER_PATH` を手で書く代わりに、plugin.json の `userConfig`（項目 `LEDGER_PATH`、`type: file`、`required: false`、既定値なし）で設定できるようにした。hook のプロセスにはこの値が環境変数 `CLAUDE_PLUGIN_OPTION_LEDGER_PATH` で渡る。

- `scripts/ledger-hook.sh` は `CLAUDE_PLUGIN_OPTION_LEDGER_PATH` を優先し、空なら従来の `COST_LEDGER_PATH` を使い、見つけた値を `COST_LEDGER_PATH` に写して python に渡す。どちらも空なら今までどおり python を起動せずに抜ける
- `scripts/cost_ledger.py` の `ledger_path()` も同じ優先順位にした（hook 以外の入口との食い違いを避けるため）
- `COST_LEDGER_PATH` だけの利用者は何も変えずに動く。両方設定したときはプラグイン設定が勝つ
- `/config` の行は Claude Code v2.1.269 以降。`/cost` のコマンド本文の Bash 実行にこの環境変数が渡るかは未確認で、`commands/cost.md` の案内文は変えていない（別 issue）
- plugin.json の `description` は変えていない（常時注入の予算は動かない）。`version` は上げていない
- 戻し方: `userConfig` の追加、hook の 2 行、`ledger_path()` の 1 行、`tests/userconfig.bats` を戻す
- LLM のトークンは使わない
- テスト: 新規 `tests/userconfig.bats`（7 件）。`tests/helper.bash` で `CLAUDE_PLUGIN_OPTION_LEDGER_PATH` も unset する
