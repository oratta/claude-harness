# 753: `/cost` の出力に、GitHub から取った文字列の制御文字が出ないようにする

- `cost <PR番号>` の `PR #N (<ブランチ>)` と、`対象: ブランチ …` の行（`timeline --pr` の表示を含む）で、ヘッドブランチ名を表示の前に #690 の `_display_text` に通す。U+202E などの書式文字は空白になる。ブランチを探す側の値は変えない
- `--json` を出す 5 か所（`facts`・`report`・`issue`・ブランチ別の区間・エピック）は、新しい `_json_dumps` を通す。日本語はそのまま残し、一般カテゴリが `Cc`・`Cf`・`Zl`・`Zp` の文字（U+007F・C1 の制御文字・U+2028・双方向制御文字など）だけを `\uXXXX` にする。`ensure_ascii=True` にしなかったのは、日本語の題名がすべてエスケープされて人にもエージェントにも読みにくくなるため。`json.loads` で読んだ値は変わらない
- 制御文字を含まない出力は、変更の前後で一致する
- 反映に `/reload-plugins` は要らない（スクリプトは実行のたびに読まれる）
- 仕様: `openspec/specs/cost-ledger-cost-command/spec.md`（題名とリポジトリ名の表示）
- テスト: `plugins/cost-ledger/tests/epic.bats`（末尾の 2 件）
