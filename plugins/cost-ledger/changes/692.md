# 692: 本体のセッションコストと突き合わせて単価表のずれを警告する

`cost_ledger.py` の `cost`・`branch`・`issue` が、答えに行が含まれたセッションのうち statusline プラグインの記録（`${CLAUDE_CONFIG_DIR:-~/.claude}/.session-cost/<セッション ID>`）があるものについて、Claude Code 本体のセッションコストの増分と、同じ時間の範囲の行を `pricing.json` の単価で計算した合計を比べるようにした。差が $0.50 を超え、かつ大きい方の 10% を超えたセッションがあると、出力の 2 行目以降に `単価表のずれ:` の行を 1 行出す。料金表に単価の無いモデルの行がその範囲にあれば、差の大きさにかかわらず別の 1 行を出す。1 行目と終了コードは変えない。

- ブランチの経路は、比べるためにセッションの行をブランチで絞らずに読み直す。読み直しは既定 1 秒で打ち切り、打ち切ったときは `単価表のずれ: 未確認` の行を出す。上限は環境変数 `COST_LEDGER_DRIFT_BUDGET_SECONDS`（0 以上の秒数か `inf`）で変える
- `cost` に `--no-drift-check` を足した。ゲート通過時の自動投稿（`scripts/gate-report.sh`）は 1 行目しか使わないので、この引数を付けて呼ぶ
- `issue` の経路の JSON に `price_drift` を足した（知らせることが無ければ `null`）
- LLM のトークンは使わず、`gh` の呼び出しも増やさない。スラッシュコマンドの本文は変えていない
- 仕様: `openspec/specs/cost-ledger-pricing/spec.md` に Requirement 5 件
- テスト: `plugins/cost-ledger/tests/drift.bats`（31 件）、`plugins/cost-ledger/tests/gate-report.bats` に 1 件
- 注意: 記録は statusline プラグインが書く。`/statusline:setup` を再実行するまで記録が無く、警告は出ない

**実機の 1 セッションでの差**

`claude -p --session-id <UUID> --model haiku --output-format json` で、ファイルを 1 つ読んで 1 行答える作業を実行した（2 ターン、サブエージェントなし）。実行の前（値 0）と後（返ってきた `total_cost_usd`）の 2 回、変更後の `statusline.sh` に、その `session_id` と `cost.total_cost_usd` を持つ入力を流して記録を作った（`-p` では statusline が描画されないため、描画の入力は手で流した。本体の値そのものは Claude Code が返した値）。

| 項目 | 値 |
|---|---|
| モデル | claude-haiku-4-5-20251001 |
| 本体の値（記録の増分） | $0.0512107 |
| 自前の計算（会話ログの 2 行を `pricing.json` の単価で計算） | $0.0512107 |
| 差額 / 割合 | $0.000000 / 0.0% |

警告は出ない。Haiku 4.5 の単価（入力・出力・キャッシュ読み出し・1 時間キャッシュの書き込み）は本体の計算と一致している。ほかのモデルの単価と、サブエージェントを使うセッションでの差は測っていない。
