# 274: 会話ログが消えてもコストが残る台帳

環境変数 `COST_LEDGER_PATH` が指すリポジトリ外の append-only JSONL 台帳を足した。応答が終わるたびに `Stop` の hook（`scripts/ledger-hook.sh`）が会話ログの増えた分を台帳へ追記し、`/cost` と `cost_ledger.py` の集計系サブコマンドは読む前に同じ追記を 1 回行ってから台帳だけを読む。会話ログが既定 30 日で消えたあとも同じ値が返る。未設定なら従来どおり会話ログを直接読み、`/cost` は利用者に台帳の場所を聞く。

- 重複排除は `requestId`。会話ログごとの読み終え位置と、台帳に書いた `requestId` の索引を台帳の隣の `<台帳>.state.sqlite` に持つ（消えても壊れても台帳から作り直す）
- 台帳がこのリポジトリの配下を指していると終了コード 2 で止まる（hook は無出力で抜ける）
- #276 の `PostToolUse` hook（ゲート通過時のコメント）とは役割が重ならない。そちらは `cost_ledger.py cost` を呼ぶだけなので、変更なしで台帳の値を貼る
- 仕様: `openspec/specs/cost-ledger-persistence/spec.md`（新設）
- テスト: `plugins/cost-ledger/tests/ledger.bats`
- 注意: `hooks.json` に `Stop` を足したので、反映には `/reload-plugins` か再起動が要る。初回の追記は全履歴を読むので数十秒かかる（`python3 scripts/cost_ledger.py ledger-sync` で先に済ませておける）
