# cost-ledger: cost-command.bats のテスト名から非 ASCII を外し、Bats 1.11 以降で 1 件が実行されない問題を直す（#1346）

- `tests/cost-command.bats` のテスト名「cost: an unset ledger prints the 台帳: 未設定 line on stderr, a set one does not」を「cost: an unset ledger prints the unset-ledger notice line on stderr, a set one does not」に変えた。Bats 1.11 以降はテスト名の英数字以外を 1 文字ずつ関数名に符号化し、macOS の /bin/bash 3.2・UTF-8 ロケールでは多バイト文字で実行側と食い違い、`unknown test name` で 1 件が実行されず `Executed 29 instead of expected 30 tests` で exit 1 になっていた（1.10.0 は 30 件通る。CI は 1.10.0 固定）
- テスト本体の検査対象の文言 `"台帳: 未設定"` と、行末の日本語コメントは変えていない
- 確認: Bats 1.10.0・1.11.0・1.13.0 のそれぞれで `bats plugins/cost-ledger/tests/cost-command.bats` が exit 0・30 件。変更前は 1.11.0・1.13.0 が exit 1・29 件
- 実行コードは変えていない（テスト名の 1 行だけ）。戻し方: テスト名を元の文字列に戻す
