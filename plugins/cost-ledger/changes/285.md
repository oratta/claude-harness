# 285: 番号なしの `/cost` がブランチ集計をリポジトリで絞る

`cost_ledger.py` の `cost` を番号なしで呼んだとき、現在のブランチの集計を作業ディレクトリのリポジトリ識別子で絞るようにした。`main` や `develop` のように別リポジトリにも同名で存在するブランチの金額を合算しなくなる。リポジトリ不明に落ちた行（cwd が削除済み）は、除外も合算もせず「リポジトリ不明: N 件 $X」として別立てで出す。PR 番号の経路は従来どおりブランチ名だけで引く（削除済み worktree の行を落とさないため）。

- 仕様: `openspec/specs/cost-ledger-cost-command/spec.md` に Requirement 追記と Scenario 2 件
- テスト: `plugins/cost-ledger/tests/cost-command.bats` に 3 件
- 注意: 番号なしの数字は絞り込みで以前より小さくなりうる。`prototypes/branch-cost.py` との突き合わせ（#273）は測り直しになる
