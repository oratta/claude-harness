# コマンドの探索ループが、置換されないときルート直下を見ない（#808）

#793 で探索ループの先頭候補を `"${CLAUDE_PLUGIN_ROOT}/..."` にしたが、本文で置換されない経路では変数が空になり、先頭候補が `/skills/develop` のようなルート直下を指していた。そこに同名ファイルがあると誤って選び、後続候補（marketplace / installed）へ進まない。

- `commands/cost.md` のループの前に `plugin_root="${CLAUDE_PLUGIN_ROOT}"` を置き、先頭候補を `"${plugin_root:+$plugin_root/...}"` にした。空のときは空文字列になり、既存の `[ -n "$dir" ]` で飛ばされる。置換されるときは従来どおり先頭候補が選ばれる
- 検査は `tests/command-plugin-root.bats`（未置換でルート相当に同名ファイルがあっても選ばれないこと、置換時は選ばれること。7 コマンド 8 ループ）
- `plugins/*/changes/793.md` の「存在しないパスになり後続候補に落ちる」を実態に合わせた
- 戻し方: 該当ループを #793 の形（`"${CLAUDE_PLUGIN_ROOT}/..."` を先頭に直接置く）に戻す
