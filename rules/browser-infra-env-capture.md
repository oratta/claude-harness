# ブラウザでインフラを触ったら生成物を即 env ファイルに保存する

ダッシュボード操作（Cloudflare / GCP / Stripe / Supabase / Vercel 等）で認証情報・ID・URL が生成/表示されたら、
**その場で**作業 repo の `.env.local` 等に保存する。「あとでまとめて」は禁止 —
ワンタイム表示のシークレットは、クリップボード上書きと再表示廃止で永遠に失われた実績がある。

- 一度しか表示されないシークレットは**表示された次のアクションで**保存
- 保存前に `git check-ignore` で gitignore を確認。シークレット値は echo せず `pbpaste` → 変数経由、確認は形式チェックのみ
- キーにはコメントで日付・発行元・スコープを添える。env に入れない判断をしたら、どこに設定済みか・再発行方法をコメントかメモリに残す
- repo に残らないインフラ事実（アカウント名・リージョン等）は env ではなく**メモリ**に記録する
