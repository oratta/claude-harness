# 人間に確認/操作を要求するときは必ずクリック可能なリンクを添える

PR・issue・ダッシュボードの操作依頼は番号だけで済ませず、フル URL を毎回添える（直前のメッセージに貼っていても再掲）。
ローカルファイルは `file_path:line` 形式。目的はユーザーの手数ゼロ化 — 開けないリンクは番号だけより悪い。

## リンクを壊さない書式

- 推奨: Markdown リンク `[PR #61](https://github.com/org/repo/pull/61)`（リンクテキストの左右に半角スペース 1 個）
- 裸 URL を使うなら: 括弧・鉤括弧で囲まない／直後に句読点を続けない／1 行 1 リンクで行末に置く
  （ターミナルは空白で URL 終端を判定するため `（URL）` は `）` まで URL に含まれ 404 になる）
