## ADDED Requirements

### Requirement: エピックの親は主への報告の最後に、全部の子と親自身の状態表を付ける

`references/epic.md` は、エピックの親が主に出す報告すべて（別セッション方式の「親が別セッション方式でターンを終えるときに主に出す発言すべて」と、サブエージェント方式の主への報告）の最後に、次の表を付けると規定しなければならない（MUST）。

- 表の上に、確かめた時刻（JST）を書く
- 行は、まだ閉じていない全部の子 issue と、親自身（エピックの番号）を 1 行ずつ
- 列は `issue 番号・内容・ステータス・確認内容・推奨・答え方`。確認内容は主に聞いていることの中身、答え方はどの画面で何を打つか。答えが要らない行は `なし`
- 表の下に、答えが要る子の issue（または停止の記録）の URL を 1 行 1 本で置く
- 前回の報告から片付いた件（子のタブで答え済みの件を含む）を「前回の報告から片付いたもの」に書く

表は 1 行目と最後の行の書き分けを置き換えない（MUST NOT）。1 行目は今回いちばん先に答えてほしい 1 件の質問（なければ `主がすること: なし`）で、表は本文の最後に付く。

この要件の守備範囲で入力として扱うのは `references/epic.md` の文面である。拾いたい誤りは、主が最新の 1 通だけで、閉じていない子の状態と自分がすることを読み取れないことである。次は通ってよく、この要件では止めない: 内容・確認内容の文の良し悪し／子が 1 件も残らない報告で表が空になること。

#### Scenario: epic.md が表の列と付ける場所を規定する
- **WHEN** `references/epic.md` の別セッション方式の「主に出す発言すべて」の段落とサブエージェント方式を読む
- **THEN** 報告すべての最後に、列 `issue 番号・内容・ステータス・確認内容・推奨・答え方` の表を付けると書かれ、確かめた時刻（JST）・親自身の行・答えが要る子の URL・前回の報告から片付いたものを書くと書かれている

### Requirement: 親は表を書く前に、子の会話ログの末尾で子のタブで進んだ分を確かめる

`references/epic.md` は、親が状態表を書く前に、閉じていない子ごとに会話ログの末尾を読み、子のタブで進んだ分を表に反映すると規定しなければならない（MUST）。子のタブで主が直接答えても子は issue の停止の記録を書き直さないので、記録だけを見て書くと表が子の実際の状態とずれる。会話ログの末尾と issue の記録が食い違うときは会話ログを優先する。会話ログを読めない子のステータスは `確かめられなかった` と書き、記録から推測して書いてはならない（MUST NOT）。別セッション方式の親は、読む部品として `scripts/epic-dispatch.sh child-log` を使う。

#### Scenario: epic.md が会話ログの確認を表より前に置く
- **WHEN** `references/epic.md` の状態表の規定を読む
- **THEN** 表を書く前に子の会話ログの末尾を読むこと、食い違えば会話ログを優先すること、読めない子は `確かめられなかった` と書くことが書かれている

### Requirement: epic-dispatch.sh child-log は子の会話ログの最後のやり取りを読み取り専用で出す

`epic-dispatch.sh child-log <child>...` は、子ごとに、その子の状態の記録の `worktree` から会話ログの置き場を引き、最新の会話ログ（サブエージェントのものを除く）の最後の「主の発言」と最後の「子の発言」の時刻と冒頭を 1 行（タブ区切り）で出さなければならない（MUST）。列は `<child>`・主の最後の発言の時刻（JST、`YYYY-MM-DD HH:MM`）・その冒頭（改行を空白にして先頭 80 文字）・子の最後の発言の時刻・その冒頭。該当が無い列は `-`。「主の発言」は、ツールの結果でも親からの指示でもない user の発言（`親エピック` で始まる返事と最初の `/develop` の指示を除く）で、「子の発言」は assistant のテキストである。記録も会話ログも書き換えてはならず（MUST NOT）、LLM を呼んではならない（MUST NOT）。記録が無い・読めない、会話ログの置き場が無い・読めない子は `unreadable <child>` を出して他の子を続ける。`jq` が無い・今のワークツリーを読めないときは stdout 空で exit 1、それ以外は exit 0。

#### Scenario: 最後のやり取りを出す
- **WHEN** 記録のある子の会話ログに、主の発言 → 子の発言 → ツールの結果、の順の行がある
- **THEN** 主の最後の発言と子の最後の発言の時刻と冒頭が 1 行で出て、ツールの結果は主の発言に数えられない

#### Scenario: 読めない子は unreadable で続ける
- **WHEN** 会話ログの置き場が無い子と読める子を一緒に渡す
- **THEN** 置き場が無い子は `unreadable <child>`、読める子は通常の行が出て、exit 0 である
