## ADDED Requirements

### Requirement: 本文途中の `[[ ]]` アサーションは偽ならテストを失敗させる
`git ls-files '*.bats' ':(exclude)_longruns/')` で見つかる bats ファイルのうち、テスト本文の途中（最後の文以外）に置かれた `[[ ... ]]` はすべて、偽のときテストを失敗させなければならない（SHALL）。ガードには `|| return 1` を用いる。テスト本文の最後の文はガード不要（bats がその終了コードをそのまま合否判定に使うため）。

#### Scenario: 途中のアサーションが偽ならテストが落ちる
- **WHEN** テスト本文の途中に置かれた `[[ ... ]]` が偽になる
- **THEN** そのテストは fail する（`not ok` として報告される）

#### Scenario: 途中のアサーションが真なら後続の文が実行される
- **WHEN** テスト本文の途中に置かれた `[[ ... ]]` が真になる
- **THEN** テストは後続の文に処理を進め、最終文の結果で合否が決まる

### Requirement: ガードの効果を固定する見張りテストがある
このガード規約が効いていることを確認する見張りテストが存在し、意図的に偽の `[[ ... ]]` を途中に置いたテストが実際に fail することを検証しなければならない（SHALL）。

#### Scenario: 見張りテストが green
- **WHEN** `bash scripts/test.sh` で見張りテストを実行する
- **THEN** 「途中の偽アサーションを含む fixture テストが fail する」ことを見張りテスト自身が確認し、見張りテスト自体は green で終わる
