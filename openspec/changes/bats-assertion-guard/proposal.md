## Why

bats のテスト本文の途中に置いた `[[ ... ]]` は偽でもテストを落とさない（bats 1.13.0 実測）。落ちるのは本文の最後の 1 文だけなので、複数のアサーションを並べたテストのうち途中の `[[ ]]` は「書いたのに検査されていない」状態になる。cost-ledger は #273 で `|| return 1` を付けて対処済みだが、それ以外の 24 本の bats ファイルには同じ穴が残っている。

## What Changes

- 対象 24 ファイル（`git ls-files '*.bats' ':(exclude)_longruns/'` のうち行頭 `[[ ` を含み、`plugins/cost-ledger/` 配下（#273 で対応済み）を除いたもの）で、テスト本文途中の `[[ ... ]]` すべてに `|| return 1` を付ける。cost-ledger が #273 で採った形をそのまま踏襲し、新しい依存（bats-assert 等）は導入しない。
- ガードが効いていることを固定する見張りテストを 1 件追加する（意図的に偽のアサーションを途中に置いたテストが実際に落ちることを確認する）。
- 各テスト本文の最後の文（bats がそのまま終了コードとして使う 1 文）にはガードは不要だが、統一のため付けても害はない。

## Capabilities

### New Capabilities
- `bats-assertion-guard`: bats テスト本文中の `[[ ... ]]` アサーションが偽のとき必ずテストを失敗させるための規約（`|| return 1` を付ける）と、その規約が効いていることを固定する見張りテストを定義する。

### Modified Capabilities
（既存 capability の要件変更なし。今回のテスト修正はいずれも「書いたとおりに検査されるようにする」修正であり、外部から観測される振る舞いの変更ではない）

## Impact

- 対象: `plugins/*/tests/*.bats`・`tests/*.bats` のうち 24 ファイル（`plugins/cost-ledger/` は対象外）。
- 新規依存なし。既存の `bash scripts/test.sh` 実行方式・bats のバージョンも変更しない。
- ガードを付けた結果として現在 green だが実際は壊れていたアサーションが露呈し落ちるテストが出た場合は、それは実装側の欠陥なので別途 issue を切って対応する（本 change の受け入れ条件外）。
