## ADDED Requirements

### Requirement: 主のリスク許容が必要な宣言は、論点の有無で書き分け、リスクを作文しない
pr-review-gate の `declarations.md` の手順 3 は、「主のリスク許容が必要」の雛形の 4 行目を次の 2 つの形のどちらか 1 つにしなければならない（MUST）。

- `論点なし — 分類に当たったので決まりで主の OK が要る。この変更を入れることで新たに生じるリスクは無い。`: 7 観点の分類に当たっただけで、この変更を入れることで新たに生じるリスク（他の案や見送った場合には無いもの）が無いとき。リスク内容を作文しない
- `論点あり — この変更を入れることで新たに生じるリスク: <誰に何が起きうるか>`: 新たに生じるリスクがあるとき

手順 3 は「この形式以外で主にリスク承認を求めない」を持ってはならず（MUST NOT）、主への依頼文は宣言を写さず `~/.claude/output-styles/readable.md` の節 3 の型で書くと定めなければならない（MUST）。宣言の行頭の `リスクなし` / `主のリスク許容が必要`、2 行目の `対象 HEAD:`、`- 該当する観点:` などの項目、返事の照合に使う `主の回答: 許容` は変えてはならない（MUST NOT。自動マージの判定と `owner-reply-check.sh` が照合している）。`stages/hold.md` は、宣言が論点なしのときは依頼も論点なしの 3〜4 行で書くと定めなければならない（MUST）。

#### Scenario: 分類に当たっただけの変更
- **WHEN** 資格情報の分類に当たるが、変更を入れることで新たに生じるリスクが無い PR の宣言を書く
- **THEN** 宣言は `主のリスク許容が必要。` の行のあとに `論点なし — ` の行を持ち、リスク内容を書かない

#### Scenario: 照合される行は変わらない
- **WHEN** 手順 3 の雛形を読む
- **THEN** 1 行目は `## リスク宣言`、2 行目は `対象 HEAD: <$HEAD_SHA 40桁フル>` のままで、`この形式以外で主にリスク承認を求めない` の文は無い
