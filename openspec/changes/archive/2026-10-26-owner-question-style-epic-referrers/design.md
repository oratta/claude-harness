## Context

検査の一覧は 2 か所にある。テストの `referrers()` と、spec の要件の箇条書き。テストのコメントは spec の一覧を指しているので、片方だけ足すと食い違う。

## Decisions

- 両方の一覧に `epic.md` と `epic-child-stop.md` を足す。理由: テストのコメントが「spec の一覧」を指しており、一覧を 2 つに増やさないため。却下案: テストだけ足す（spec とテストの一覧が食い違う）。
- spec の SKILL.md の項目の説明文は変えない。#1241 が spec 側の名指しの食い違いを扱うので、範囲を分ける。
- 3 文書の参照の直しは、issue の表のとおり機械的な置き換えにする。

## Risks / Trade-offs

- #1241 が同じ要件の SKILL.md の項目を直すと、同じ箇所の変更が重なりうる。後からマージされる側が main に追従して解く。
- 移設先 2 ファイルは `~/.claude/output-styles/readable.md` を既に参照しているので、足した直後にテストが通る見込み。
