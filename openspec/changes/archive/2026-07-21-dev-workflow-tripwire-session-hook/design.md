## Context

Claude Code プラグインはルート直下の `hooks/hooks.json` を自動ロードする（plugin.json への宣言不要）。SessionStart hook は stdout の JSON `{"additionalContext": "..."}` でセッション文脈にテキストを注入できる。`${CLAUDE_PLUGIN_ROOT}` がコマンドパスに使える（公式 docs plugins.md / hooks.md で確認済み、2026-07-21）。

## Goals / Non-Goals

**Goals:**

- トリップワイヤー常駐を「プラグイン更新だけ」で全セッションに配布する
- テンプレートを single source of truth のまま保つ（hook はテンプレートから抽出する。本文の複製を作らない）

**Non-Goals:**

- unmanned 層の変更（憲法テンプレートは既に組み込み済み）
- opt-out 機構（必要になったら env で足す）

## Decisions

1. **matcher は `startup|clear|compact`**。resume は直前の文脈に注入済みテキストが残っているため再注入しない（重複を避ける）。compact は文脈が圧縮され消えている可能性があるため注入する。
2. **スクリプトはテンプレートから節を抽出する**（`## 昇格トリップワイヤー` 以降）。テンプレートと注入内容が自動で一致し続け、更新は1ファイルで済む。JSON エンコードは python3（macOS 標準・依存追加なし）。
3. **fail-soft**: テンプレートが見つからない場合は無出力・exit 0（セッション開始をブロックしない。hook の失敗でセッションが壊れるのが最悪ケースのため）。
4. **手動コピー導線は削除せずオプションに降格**: プラグイン未導入の環境や、閾値をユーザー好みに改変したいケースで引き続き有効。hook 注入とグローバルルールコピーが併存した場合は同文が2回文脈に載るだけで無害だが、テンプレートに注記する。

## Risks / Trade-offs

- [全セッションに約20行が常駐しトークンを消費] → グローバルルールにコピーした場合と同等のコスト。常駐こそが機能の本体なので許容
- [hooks スキーマの将来変更] → bats がスキーマ実在と JSON 妥当性を検査するため、破損はテストで検出できる
