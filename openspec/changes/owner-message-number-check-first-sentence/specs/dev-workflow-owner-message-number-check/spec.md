## MODIFIED Requirements

### Requirement: 主に判断・確認・操作を求める発言だけを対象にする

上の要件で対象外にしなかった発言は、1 行目の末尾の文字が `？` か `?` であるか、1 行目の最初の文の終わりが `？` か `?` であるか（最初の文は、1 行目から URL と引用の中身を除いたもので数える。引用は `「」` `『』` `“”` `""` で囲んだ範囲、最初の文の終わりは、`。` `！` `!` `？` `?` のうち最初に現れるもの。前者は従来の条件で、狭めない）、区切りより上の最後の行が `と打って`・`と打つ`・`を押して`・`と返して`・`と答えて` のどれかを含むときだけ対象にしなければならない（MUST）。対象にしない発言では何も出力してはならない（MUST NOT）。

守備範囲: ①入力は、メインセッション（`claude -p` の子を含む）の `Stop` の payload。②拾いたいのは、正本の 1 行目の書き分けに従って書いた主への依頼。③通してよい例は、1 行目が質問でなく答え方の行も無い依頼と、ツールで送った発言。`と書いて` は「…と書いてある」で当たるので入れず、「…と書いてください」の依頼は 1 行目の質問で拾う。答えの 1 行目が問い返しで入る害は理由の最後の文で抑える。④見分け切ることを完了条件にしない。

#### Scenario: 1 行目が質問でも答え方の行でもない発言は対象にしない
- **WHEN** `last_assistant_message` が「テストは通った。」の行と「#1712 を直した。」の行だけを持つ入力を渡す
- **THEN** 終了コードは 0 で、標準出力は空である

#### Scenario: 答え方の行で対象に入る
- **WHEN** `last_assistant_message` が「次の変更を入れる。」の行、「#1712 の続き。」の行、「よければ『OK』と打ってください。」の行を持つ入力を渡す
- **THEN** 差し戻しの JSON が出る

#### Scenario: 1 行目の質問のあとに文が続くマージの依頼で対象に入る
- **WHEN** `last_assistant_message` が「PR #1330 を GitHub でマージしてもらえますか？ マージすると、子 #1303 の修正が main に入ります。」の行と「よければ下の PR のページでマージしてください。」の行を持ち、URL を持たない入力を渡す
- **THEN** 差し戻しの JSON が出て、`reason` は `行 1: #1330 #1303` を含む

#### Scenario: 質問を引用した答えは対象にしない
- **WHEN** `last_assistant_message` が「表示は「PR #1330 をマージしますか？」です。」の行だけを持つ入力を渡す
- **THEN** 終了コードは 0 で、標準出力は空である

#### Scenario: 質問を引用した作業報告は対象にしない
- **WHEN** `last_assistant_message` が「#1330 に「マージしますか？」という確認を追加しました。」の行だけを持つ入力を渡す
- **THEN** 終了コードは 0 で、標準出力は空である

#### Scenario: 報告の文が先に来て末尾が質問の 1 行目は従来どおり対象にする
- **WHEN** `last_assistant_message` が「#1330 をマージした。続けて #1303 も見ますか？」の行だけを持ち、URL を持たない入力を渡す
- **THEN** 差し戻しの JSON が出る
