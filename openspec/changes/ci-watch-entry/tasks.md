## 1. 入口のテストと実装

- [ ] 1.1 PR URL・番号の受付、対象を解決できない場合の停止、共有 CI 見張りへの接続を先にテストにする。
- [ ] 1.2 `/ci-watch <PR>` のコマンドを追加し、メインセッションが `references/ci-watch.md` の開始判定・`wait`・`next`・一手の実行・終了記録を呼ぶ手順を書く。
- [ ] 1.3 `--unrelated` は共有 reference の 2 条件を満たすチェックだけに渡し、手がかりがなければ `fix` に回すことをコマンドの手順とテストで確かめる。

## 2. マージ経路と実機確認

- [ ] 2.1 条件付きの「マージして」の承認範囲、`ready` 後のゲート実施、直接 merge API の禁止と人間への依頼を手順とテストに反映する。
- [ ] 2.2 ゲート未通過 PR で CI を意図的に失敗させ、入口から `rerun` または `fix` へ進む実機確認を行い、実行の一手・結果・証拠をその PR にコメントする。
- [ ] 2.3 PR・push の CI workflow の検査コマンドを実行し、コマンドと exit code を記録する。
