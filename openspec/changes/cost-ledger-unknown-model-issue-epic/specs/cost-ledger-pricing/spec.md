## ADDED Requirements

### Requirement: issue と子 issue 込みの経路でも、未知モデルの名前と行数を示す
システムは、`cost_ledger.py issue <番号>` と子 issue を持つ issue の集計（`cost_ledger.py cost <番号>` の epic 経路）の通常出力にも、合計に入った行の中の未知モデルの名前と行数を、ブランチ・PR の経路と同じ文言で示 MUST す。未知モデルが無いときはその行を出してはなら MUST NOT ない。1 行目の書式と他の行は変えてはなら MUST NOT ない。`--json` には同じ内容を `unknown_models`（`{モデル名: 行数}`）として足 SHALL す。

数える範囲は経路ごとに違う。issue 経路では、issue に帰属した区間の行（`--closing-pr` で足す閉じた PR の行と、リポジトリ不明として別立てにした行は含めない）。epic 経路では、合計に入れた行（ヘッドブランチの行も含む。リポジトリ不明の行は含めない）。行数は応答の 2 行目以降の事実を数えない（ブランチ・PR の経路と同じ）。

#### Scenario: issue 経路に未知モデルの名前と行数が出る
- **WHEN** issue に帰属する区間に、料金表のどの鍵にも前方一致しないモデル名 `claude-nope-9` の行が 1 行ある状態で `cost_ledger.py issue <番号>` を実行する
- **THEN** 出力に `  未知モデル: claude-nope-9 1 行（料金表に単価が無いため 0 円として扱っている）` の行（未知モデルごとに 1 行、モデル名の順）があり、1 行目の書式は変わらない

#### Scenario: epic 経路に未知モデルの名前と行数が出る
- **WHEN** 子 issue の区間に未知モデルの行がある状態で、エピックの番号を `cost_ledger.py cost` に渡す
- **THEN** 出力に ブランチ・PR の経路と同じ文言の `未知モデル:` の行があり、位置は「未知モデルの行の位置」に従う

#### Scenario: epic 経路はヘッドブランチ上の区間に属さない行も数える
- **WHEN** 子 issue を閉じた PR のヘッドブランチ上の行に、どの区間にも属さない未知モデルの行がある
- **THEN** その行は未知モデルの行数に入る

#### Scenario: 区間にもヘッドブランチにも属する行は 1 回だけ数える
- **WHEN** 未知モデルの 1 行が、子 issue の区間にも、その issue を閉じた PR のヘッドブランチにも属している
- **THEN** 未知モデルの行数は 1 である

#### Scenario: リポジトリ不明の行は数えない
- **WHEN** リポジトリ識別子が不明で別立てにされた区間の行に未知モデルがある
- **THEN** その行は `未知モデル:` の行数に入らない

#### Scenario: 未知モデルが無ければ行を出さない
- **WHEN** 区間の行がすべて料金表に単価のあるモデルである
- **THEN** issue 経路・epic 経路の出力に `未知モデル:` の行は無い

#### Scenario: --json に unknown_models が足される
- **WHEN** 未知モデルの行がある状態で `cost_ledger.py issue <番号> --json` を実行する
- **THEN** 標準出力は JSON だけで、`unknown_models` に `{"claude-nope-9": 1}` が入っている

### Requirement: 未知モデルの行の位置
システムは、issue 経路と epic 経路の未知モデルの行を、次の位置に出 SHALL す。epic 経路では、spec `cost-ledger-cost-command`「子 issue を持つ issue では、子 issue ごとの内訳と合計を返す」の 2 行目以降の並びの項目 6（`数えていない子 issue:`）と項目 7（`リポジトリ不明`）の間。issue 経路では、区間の行と `リポジトリ不明` の行のあと、`推定で数えた行:`（`render_inferred` の出力）の前。

#### Scenario: epic 経路の位置
- **WHEN** 未知モデルの行と、`数えていない子 issue:` と `リポジトリ不明` の行がすべて出る
- **THEN** 出力の順は `数えていない子 issue:`、`未知モデル:`、`リポジトリ不明`

#### Scenario: issue 経路の位置
- **WHEN** 未知モデルの行と `リポジトリ不明` と `推定で数えた行:` がすべて出る
- **THEN** 出力の順は `リポジトリ不明`、`未知モデル:`、`推定で数えた行:`
