## ADDED Requirements

### Requirement: 未知モデルの行は利用者に見せる
`commands/cost.md` は、`cost_ledger.py` の出力に `未知モデル:` で始まる行があるとき、1 行目に続けてその行も利用者に見せるよう指示 SHALL する（1 行目だけを見せる既存の指示のままでは、単価が引けず 0 円として扱った分が利用者に届かず、額が黙って小さく出る）。PR に貼るのは引き続き 1 行目だけ。

#### Scenario: cost.md が未知モデルの行を見せる指示を持つ
- **WHEN** `commands/cost.md` の「出力の扱い」を調べる
- **THEN** `未知モデル:` の行があれば 1 行目に続けてその行も利用者に見せる旨の指示があり、PR に貼るのは 1 行目だけである旨が保たれている
