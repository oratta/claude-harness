## ADDED Requirements

### Requirement: 条件付き注入のルールは常時注入の合計から外す

`rules/*.md` のうち frontmatter に `paths:` を持つファイルは、常時注入されず、対象パスに一致するファイルを読んだときだけ載る。したがって内訳の `rules/*.md` の集計は、`paths:` を持つファイルを合計から除外しなければならない（MUST）。

除外したファイルは、合計から消えたことが分かるように内訳の出力で別行として示さなければならない（MUST）。0 バイトとして黙って消してはならない（MUST NOT）— 常時注入から外した量と、単に削除した量が区別できなくなるため。

この除外は、`paths:` による条件付き注入が実機で動くことを確認したうえでのみ適用する（正本は `always-on-injection-scope` の「path スコープは両方向の実機確認を経てから採用する」）。確認が取れず `paths:` を持つルールが 1 本も無い場合、この要件は集計に何の影響も与えない。

#### Scenario: paths を持つルールが合計から外れる

- **WHEN** 一時ディレクトリに frontmatter に `paths:` を持つルールと持たないルールを置き、集計ヘルパに渡す
- **THEN** `paths:` を持たないルールのバイト数だけが `rules/*.md` の合計に入り、`paths:` を持つルールは別行として内訳に現れる

#### Scenario: paths を持つルールが無いときは従来どおりの合計になる

- **WHEN** `paths:` を持つルールが 1 本も無い状態で `scripts/test.sh injection-budget` を実行する
- **THEN** `rules/*.md` の合計が README を除く全ファイルのバイト数の和と一致する（除外の行は 0 バイトとして現れるか、現れない）
