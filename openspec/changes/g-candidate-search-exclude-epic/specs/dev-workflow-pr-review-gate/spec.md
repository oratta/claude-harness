## MODIFIED Requirements

### Requirement: 候補探しのスクリプトは 1 回だけ走らせ、失敗を候補なしと読まない

G は、段 B を通った指摘（範囲で成り立つ・後で成り立つ）が 1 件以上あるとき、`plugins/dev-workflow/scripts/review-issue-candidates.sh` を、その周の振り分けにつき 1 回だけ走らせなければならない（MUST）。引数は次のとおりとする（MUST）:

- `--repo <owner>/<name>`
- `--exclude <PR 番号>` と、記録先が issue なら `--exclude <記録先 issue の番号>`、エピックに属する PR ではさらに `--exclude <エピック番号>`（エピックの本文に指摘のファイル名が書かれていると、エピック自身が `other` の候補として返るため）
- エピックに属する PR では `--epic <エピック番号>`。`--children-only` は付けない（1 回の実行で、候補がエピックの子か外かを各行の 3 列目 `child` / `other` で見分けるため）
- 段 B を通った指摘の場所のパス。指摘の場所が `ファイル:行番号` や `ファイル:行範囲` の形なら、`:` 以降を落としてファイルのパスだけを渡す（そのまま渡すと検索語が `"triage.md:53"` になり、ほぼ 0 件になるため）

出力は、`== <パス>` の見出し行ごとに、候補の行 `<番号><TAB><題名>[<TAB>child|other]`、`(該当なし)`、`(15 件で打ち切り。ほかにも一致あり)` として読む（MUST）。候補が「同じ場所を直す」かは題名で判断し、issue の本文を読むのは段 C で外の issue の受け入れ条件を確かめるときだけとする（MUST）。

出力に「(15 件で打ち切り。ほかにも一致あり)」が出たパスがあり、PR がエピックに属するときは、そのパスだけに `--epic <エピック番号> --children-only` を付けて、もう 1 回走らせ、子の候補を足さなければならない（MUST）。打ち切りでエピックの子が 15 件の外に落ち、G が新しい子 issue を作ることを防ぐため。この再実行は、1 回だけの規則の例外であり、打ち切りが出たパスごとに 1 回を超えて繰り返さない。

終了コードが 0 でないとき（1 は検索の失敗、2 は引数の不備）、G は標準出力が空であることを「候補なし」と読んではならない（MUST NOT）。引数を直して 1 回だけ走らせ直し、それでも 0 にならなければ、仕分けの PR コメントに「候補探しに失敗した」と終了コードを書いたうえで、既存 issue への相乗り（段 C の上 3 行と段 D）をせずに段 C の「当たる issue が無い」と段 E へ進む（MUST）。

#### Scenario: 行番号を落として渡す

- **WHEN** 段 B を通った指摘の場所が `plugins/dev-workflow/skills/pr-review-gate/stages/triage.md:53-57` である
- **THEN** G がスクリプトに渡すパスは `plugins/dev-workflow/skills/pr-review-gate/stages/triage.md` である

#### Scenario: エピックに属する PR

- **WHEN** 記録先 issue #985 の親エピックが #973 で、PR が PR #N（番号 N）で、段 B を通った指摘が 2 つのファイルを指す
- **THEN** G は `review-issue-candidates.sh --repo <owner>/<name> --exclude <N> --exclude 985 --exclude 973 --epic 973 <パス 1> <パス 2>` を 1 回だけ走らせ、`--children-only` を付けない（打ち切りが出なければこの 1 回で終わる）

#### Scenario: 打ち切りが出たパスがある

- **WHEN** エピック #973 に属する PR で、1 回目の結果の `== <パス 1>` が「(15 件で打ち切り。ほかにも一致あり)」で終わり、`<パス 2>` は打ち切られていない
- **THEN** G は `review-issue-candidates.sh --repo <owner>/<name> --exclude <N> --exclude 985 --exclude 973 --epic 973 --children-only <パス 1>` をもう 1 回だけ走らせ、返った子の候補を `<パス 1>` の候補に足す。`<パス 2>` は走らせ直さない

#### Scenario: エピックに属さない PR で打ち切りが出た

- **WHEN** エピックに属さない PR で、結果が「(15 件で打ち切り。ほかにも一致あり)」で終わるパスがある
- **THEN** G は再実行せず、1 回目の結果だけで振り分ける

#### Scenario: 検索が失敗した

- **WHEN** スクリプトが 2 回とも終了コード 1 で終わる
- **THEN** G は仕分けの PR コメントに候補探しの失敗と終了コードを書き、既存 issue へのコメントも受け入れ条件への追記もせず、指摘を段 C の「当たる issue が無い」または段 E に当てる
