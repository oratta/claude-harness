## ADDED Requirements

### Requirement: statusline が本体のセッションコストをセッションごとに書き残す
`plugins/statusline/scripts/statusline.sh` は、stdin の `cost.total_cost_usd`（Claude Code 本体が計算したそのセッションのコスト。以下「本体の値」）と `session_id` の両方が使える形で渡された描画で、本体の値をセッションごとの記録ファイルに書き残さなければならない（SHALL）。この記録は cost-ledger プラグインが読む。

記録ファイルの場所は `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/.session-cost/<session_id>` とする（SHALL）。会話ログ（`${CLAUDE_CONFIG_DIR:-$HOME/.claude}/projects`）と同じ設定ディレクトリの下に置くことで、読み手は自分が読む会話ログと同じアカウントの記録だけを見る。

記録は次の 5 項目を半角スペースで区切った 1 行でなければならない（SHALL）。

```
1 <区間の最初の観測時刻> <区間の最初の観測値> <最後に値が変わった観測時刻> <最後の観測値>
```

先頭の `1` は形式の版。時刻は epoch 秒の整数、値は USD の 10 進表記（stdin で受け取った表記のまま）とする。「区間」は本体の値が単調に増えている間のひと続きで、`/clear` などで本体の値が 0 に戻ると新しい区間になる。

書く条件は次のとおりとする（SHALL）。

- 記録ファイルが無い・読めない・上の形でないとき: 4 項目を「今の時刻・今の値・今の時刻・今の値」として書く
- 今の値が記録の最後の観測値と等しいとき: 何も書かない
- 今の値が記録の最後の観測値より小さいとき（本体の値が戻った）: 区間を始め直し、4 項目を「今の時刻・今の値・今の時刻・今の値」として書く
- 今の値が記録の最後の観測値より大きいとき: 区間の最初の観測時刻と観測値は残し、最後の観測時刻と観測値だけを今の時刻と今の値に差し替える

`session_id` が半角英数字・`_`・`-` だけの 1〜128 文字でないとき、または本体の値が 0 以上の数値として読めないときは、記録を書いてはならない（MUST NOT。`session_id` をそのままファイル名に使うため）。

記録を書くかどうかは、セッションコストの表示を消す設定（`STATUSLINE_SESSION_COST=0`）に左右されてはならない（MUST NOT）。

#### Scenario: 最初の描画で記録ができる
- **WHEN** 記録ファイルが無い状態で、`session_id` が `abc-123`、`cost.total_cost_usd` が `0.25` の入力を時刻 1000 に描画する
- **THEN** `<設定ディレクトリ>/.session-cost/abc-123` の中身が `1 1000 0.25 1000 0.25` になる

#### Scenario: 値が増えたら最後の観測だけを差し替える
- **WHEN** 記録が `1 1000 0.25 1000 0.25` の状態で、同じ `session_id` の `cost.total_cost_usd` が `1.5` の入力を時刻 1300 に描画する
- **THEN** 記録が `1 1000 0.25 1300 1.5` になる

#### Scenario: 値が同じ描画では書かない
- **WHEN** 記録が `1 1000 0.25 1300 1.5` の状態で、同じ `session_id` の `cost.total_cost_usd` が `1.5` の入力を時刻 1400 に描画する
- **THEN** 記録ファイルの中身は `1 1000 0.25 1300 1.5` のままで、ファイルは書き換えられていない

#### Scenario: 値が下がったら区間を始め直す
- **WHEN** 記録が `1 1000 0.25 1300 1.5` の状態で、同じ `session_id` の `cost.total_cost_usd` が `0` の入力を時刻 2000 に描画する
- **THEN** 記録が `1 2000 0 2000 0` になる

#### Scenario: 壊れた記録は作り直す
- **WHEN** 記録ファイルの中身が 5 項目の形でない状態で、`cost.total_cost_usd` が `0.4` の入力を時刻 3000 に描画する
- **THEN** 記録が `1 3000 0.4 3000 0.4` になる

#### Scenario: ファイル名に使えない session_id では書かない
- **WHEN** `session_id` が `../evil` の入力を描画する
- **THEN** `.session-cost` の下にも、その外にも記録ファイルは作られない

#### Scenario: 本体の値が無い入力では書かない
- **WHEN** `cost.total_cost_usd` が無い、または数値でない入力を描画する
- **THEN** 記録ファイルは作られない

#### Scenario: 表示を消していても書く
- **WHEN** `STATUSLINE_SESSION_COST=0` で、`session_id` と `cost.total_cost_usd` のある入力を描画する
- **THEN** 記録ファイルが作られる

### Requirement: 記録の書き込みは statusline の表示を変えず、読み手に書きかけを見せない
記録を足す前と後で、同じ入力に対する statusline の標準出力は同じでなければならない（SHALL）。記録ディレクトリの作成や書き込みが失敗しても、標準出力を変えたり、エラーを出したり、0 以外で終了したりしてはならない（MUST NOT）。

書き込みは、記録ディレクトリ内の一時ファイルに書いてから置き換える形で行わなければならない（SHALL。読み手が書きかけの 1 行を読まないため）。

400 日より古い記録ファイルは、新しい記録ファイルを作る描画のついでに消してよい（会話ログの保持期間を 365 日にする運用より長く残す）。それ以外の描画では消す処理を走らせてはならない（MUST NOT。描画のたびに走るスクリプトなので）。

#### Scenario: 記録の有無で表示が変わらない
- **WHEN** 同じ入力を、記録ディレクトリに書ける状態と書けない状態（ディレクトリの位置に通常ファイルがある）でそれぞれ描画する
- **THEN** 2 回の標準出力は同じで、どちらも終了コードは 0、標準エラーは空である

#### Scenario: 一時ファイルが残らない
- **WHEN** 記録を書く描画が終わった
- **THEN** 記録ディレクトリにあるのは `session_id` と同じ名前のファイルだけである

#### Scenario: 古い記録を消すのは新しい記録を作るときだけ
- **WHEN** 更新時刻が 400 日より前の記録ファイルがある状態で、別の `session_id` の最初の描画を行う
- **THEN** 古い記録ファイルは消えている

#### Scenario: 値が同じ描画では古い記録に触らない
- **WHEN** 更新時刻が 400 日より前の記録ファイルがある状態で、既に記録のある `session_id` の、値が同じ描画を行う
- **THEN** 古い記録ファイルは残っている
